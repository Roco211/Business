# 为什么修改云店logo图片后手机端分享还是原图？

官方页面: https://www.zhihuiji.cn/help/doc/3321

**问题：** 修改了云店logo，为什么手机端云店推广还是显示的智慧记图标

**原理：** 手机端云店推广二维码图片对应的是小程序基础信息里面的图片，需要去小程序后台修改。 **（只有专属版才有自己的专属小程序可以修改，订货版不支持修改）**
