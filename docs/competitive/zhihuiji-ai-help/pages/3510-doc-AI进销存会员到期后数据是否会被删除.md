# AI进销存会员到期后数据是否会被删除?

官方页面: https://www.zhihuiji.cn/help/doc/3510

智慧记AI进销存的会员采用年结方式，年结日期为开通付费会员之日起的第365天，智慧科技在会员期限不足30日时，会向您提供续期提醒，如您未在年结日之前续费，则向您提供的增值服务到期将随之取消，智慧科技将提供最长**7个自然日** 的免费数据存储服务，您应在7个自然日内将数据和文件迁移到本地或共他信赖处，或者另行付费委托智慧科技代为保管，否则智慧科技有权将相关数据和文件清理。
