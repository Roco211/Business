# 导入改价

官方页面: https://www.zhihuiji.cn/help/doc/2885

操作路径：点击左侧栏客户-报价管理-导入改价

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/81b0e69299270b595ee37ba9333fd7bb.png)

然后点击下载表格。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/e09b2e8208b5bd1ac8b9be22258c649b.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/24f354aa23b11f922039c8346b91f232.png)

打开表格，修改最新报价保存，然后再导入到软件里。

注意：只能修改导出的这些报价再导入回去，不能新增报价。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/6a1a4fbdfb395aedfa81669111983672.png)
