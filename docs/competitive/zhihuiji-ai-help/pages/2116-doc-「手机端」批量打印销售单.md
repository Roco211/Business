# 「手机端」批量打印销售单

官方页面: https://www.zhihuiji.cn/help/doc/2116

**操作路径：** 【销售】→【批量操作】→【批量打印单据】→ 选择单据 → 设置份数 → 打印

**批量操作指引：**

  * **选择单据** ：点击左下角【全选】可选中已加载单据，下滑可加载更多
  * **设置份数** ：可单独或批量设置每个单据的打印份数
  * **筛选单据** ：点击右上角【筛选】可修改筛选条件快速查找



![批量打印销售单流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/c990b750d870b3b58dc348f7a97cf191.png)

**打印预览页面：**

  * **顶部** ：选择打印模板和打印机
  * **中部** ：左右滑动可预览每份单据
  * **底部** ：显示已选单据数量和总打印张数



![打印预览页面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/a1d26207a3bff8343eb6101056021f21.png)

**💡 业务场景：**

前一天晚上开单，第二天早上批量打印销售单，便于快速配货和配送。
