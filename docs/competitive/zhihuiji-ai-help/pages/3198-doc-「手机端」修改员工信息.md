# 「手机端」修改员工信息

官方页面: https://www.zhihuiji.cn/help/doc/3198

## 修改基础资料

智慧记AI进销存手机端，可修改员工的名称、所属角色、所属门店、所属仓库等资料

路径：【我的】→【店铺管理】→【员工管理】-员工右下角【...】-编辑，修改信息后保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/da717c4c6e4de5f35874fef6efce31fc.png)

## 更换手机号

### 删除员工重新添加

**业务场景** ：原员工已离职或不再使用，需更换为其他员工的手机号

**操作路径** ：老板账号登录后，通过【我的】→【店铺管理】→【员工管理】-员工右下角【...】-【删除】，删除后重新添加要使用的员工信息

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/5ec6ca1bb9993a29484855753bc0d138.png)

### 员工本人更换号码

**业务场景** ：员工不变，但员工的手机号码有变更

**操作路径** ：员工登录自己的账号后，点击【我的】→【个人信息】→【手机号】→【更换手机号】-输入新手机号接收验证码完成更换

![更换手机号](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/0db107a76537d3ace1450b07894bb8cc.png)
