# 小程序二次授权新店

官方页面: https://www.zhihuiji.cn/help/doc/3290

微信小程序本身不存储智慧记的进销存数据，仅作为前端的一个“展示窗口”，二者完全独立。C端消费者通过小程序，访问**您指定并授权** 的店铺。如需更换绑定店铺，请按以下步骤操作：

**1、解除授权：** 登录小程序后台（<https://mp.weixin.qq.com/>），取消当前店铺的授权；

**路径：** 小程序后台，左下角【账号设置】-【第三方设置】-【第三方平台授权管理-智慧记】-【解除授权】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/535aa647512d96cbd8ad58f3db3a6e6e.png)

**2、重新授权：** 登录微店或云店后台，再次执行授权流程，关联至新店铺。

云店授权：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/386b5794cf7bce385af0802853ba2579.png)

微店授权：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/2d3c6f26416055e01b8a2c26f01062e8.png)

**注意：** 一个小程序只能授权绑定一个店铺，无法同时关联多个。如需管理多个店铺，建议注册多个小程序，为每个店铺单独配置。
