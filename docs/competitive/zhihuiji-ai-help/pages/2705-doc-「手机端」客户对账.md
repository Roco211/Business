# 「手机端」客户对账

官方页面: https://www.zhihuiji.cn/help/doc/2705

**路径** ：首页【对账】-顶部【客户对账】，可以查看到客户的欠款金额。

点击客户名称可以进入到客户对账单明细界面，支持：

  * 点击右上角的分享按钮，分享对账给客户；
  * 点击底部的收款按钮，跳转到收款单界面做收款。
