# 批量导入供应商

官方页面: https://www.zhihuiji.cn/help/doc/868

**供应商批量导入**

**路径** ：【进货】-【供应商】-【导入】

需要要下载一个供应商资料导入模板，为了方便您可以把文件下载到桌面；

按照模板重新梳理供应商的资料，然后再点击中间的符号上传文件；

上传过程中已经存在的供应商名称会自动跳过，不存在的则新增。

tips：请严格按照模板来，否则无法上传成功。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/f3acec274e16b68978248afb2d2543dd.png)

**供应商批量操作**

**路径：** 【进货】-【供应商】-【批量操作】

批量操作包括“删除”“启用/停用”“移至分类”“更改关联业务员”

先从列表中选择想要批量操作的对象，然后在批量操作的下拉框中选择执行操作的命令。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/afa4d5de13523c143cff044c1ecc3b0a.png)

以批量操作”启用/停用“为例，选择好供应商后，修改为”启用“，点击”确认“则选中供应商全部改为启用状态。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/5af4e9871a26f4806e088ea79033839e.png)
