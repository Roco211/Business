# 进货预订单

官方页面: https://www.zhihuiji.cn/help/doc/2709

## 新增进货预订单

（1）路径：底部【进货】-顶部【预订】-右下角【预订】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/5e0433f9281e0ea7314077f29ab26706.png)

（2）选择供应商名称，进货商品保存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/ab93a4a1788404965f64d68b9cc16655.png)

## 修改进货预订单

在进货预订单列表界面，点击对应的进货预订单进入到进货预订订单详情界面，然后点击底部第二个编辑按钮即可修改进货预订单。

**已经完成的进货预订单不支持修改。**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/843effa00da226744c9ae02b3e32f333.png)

## 关闭和作废进货预订单

进入到对应的进货预订单详情界面，然后点击右上角的【...】按钮，然后就可以点击复制本单，关闭和作废单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/fcd9014666a0795341fcbe69401222dc.png)

注意：没有完成的进货预订单才支持作废和关闭，如果已经完成的订单，需要先找到相关的进货单作废后才能关闭和作废进货预订单。
