# 设置销售单默认日期

官方页面: https://www.zhihuiji.cn/help/doc/3389

开销售单时，可提前设置单据的默认开单日期。

**操作路径：** 【设置】→【用户偏好设置】→【销售单默认日期】

**可选项：**

  * 开单当天
  * 开单前一天
  * 开单第二天



**说明：** 此设置仅对当前登录的账号生效，设置后开单时将自动填入所选的默认日期。
