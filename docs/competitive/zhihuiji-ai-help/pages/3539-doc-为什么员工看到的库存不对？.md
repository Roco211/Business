# 为什么员工看到的库存不对？

官方页面: https://www.zhihuiji.cn/help/doc/3539

员工看到的库存，是**自己有权限的仓库** 的库存。如果员工的仓库权限不包含某些仓库，就看不到这些仓库的库存数据。

如需让员工查看全部库存，可为员工勾选**所有仓库权限** 。

**路径：** 【设置】→【员工管理】→ 找到对应员工 → 点击【修改】→ 勾选全部仓库 → 确定
