# 挂单/取单教程

官方页面: https://www.zhihuiji.cn/help/doc/2207

视频描述

## 挂单

操作路径：左侧导航销售-销售-新增销售单，选中商品信息后，点击底部的挂单按钮即可挂单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/eff43033c4a741400dfbc5e6f923fdd4.png)

## 取单

在新开销售单界面没有选择商品的情况下，点击底部的取单按钮，可以查询到所有的挂单信息，可以删除和取单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/3f63790b0913b227e39025dae7a1a6ec.png)
