# 分享单据至微信

官方页面: https://www.zhihuiji.cn/help/doc/1569

智慧记AI进销存更新支持单据分享了，您的报价单、销售单、销售订单、收款单等，都支持分享到微信，供顾客查看，不需要截图或者导出发送给顾客了，更加方便快捷！

下面来看看具体是怎么操作的吧——

以**销售单** 为例，进入销售单列表，找到需要分享的销售单，点击右侧【分享】按钮

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202207/079d0e51ad343c7eef0270f9f5ec74ce.jpg)

或者进入需要分享的单据详情页，点击右上角的【分享】按钮

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202207/eac223581447bfe53fdbf2a92d6c28c9.jpg)

用微信扫码弹出页面的二维码

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202207/8483887b2fa4515dd86632a0bacda73e.jpg)

在手机扫码出来的页面中，点击【分享】，将销售单发送给需要查看的客户

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202207/c64163956f680144fffaa101e1b334e9.jpg)

客户点击小程序打开，即可查看核实销售单详情

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202207/8e4924bb1c3783799fb26a94cb6f6d81.jpg)

至此，您就完成了一次单据分享
