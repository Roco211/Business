# 怎么启用多仓库？

官方页面: https://www.zhihuiji.cn/help/doc/946

**启用多仓库**

**路径** ：【设置】-【系统设置】-【基础设置】-勾选【启用多仓库】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/d5d1d57b5913c6dca10f4ac12dfb1800.png)

**功能说明** ：

  1. 勾选后，可实现门店和仓库的库存分开管理。
  2. 若已有多仓库，则不能关闭多仓库设置。
