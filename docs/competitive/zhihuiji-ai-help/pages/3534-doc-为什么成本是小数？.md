# 为什么成本是小数？

官方页面: https://www.zhihuiji.cn/help/doc/3534

系统采用 **“加权平均法”** 计算成本，会动态计算商品的结余成本总额和平均成本价，因此成本可能是小数。

**举例：**

  * 第1次进货：10件，单价 10元
  * 第2次进货：20件，单价 9元



总数量：30件
总金额：100元 + 180元 = 280元
平均成本：280元 ÷ 30件 ≈ 9.33元/件


最终商品成本显示为 9.33元，不是整数。
