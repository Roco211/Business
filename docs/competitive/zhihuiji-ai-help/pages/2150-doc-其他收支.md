# 其他收支

官方页面: https://www.zhihuiji.cn/help/doc/2150

**新增其他收入：**

路径：右下角【更多】-【资金】-【日常收支】-底部【记收支】-顶部【其他收入】

输入客户名称，金额，选择结算账户和收入项目保存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/6d36b65d5c77250c231d9808b529859a.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/a9ef8f303ff949cd6269c912e3f0e4b0.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/5c05f355e7d187250f94188336b04536.png)

新增其他支出参考新增其他收入教程即可，不再重复描述。

**收入类型**

新增项目：点击收入项目右侧的【编辑】-【新增类型】，可以输入新的收入项目；

修改项目：点击收入项目后面的编辑按钮可以修改收入项目的名称；

删除项目：选中收入项目的名称左滑可以删除项目，没有发生过业务的项目才支持删除。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/9a7d814428bc384b4c5419d78b763afe.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/ff0aeaad46b3d88e20174dee58d6a3a6.png)

支出类型和收入类型的教程一样，不再重复描述。

**其他收支列表**

1.搜索框可以输入单号/备注查询。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/07fd51d9082a9ee3a861fb8749997b17.png)

2.点击筛选，可以选择日期，门店，收支类型，业务员，和是否显示作废单据查看。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/e7947e2e522403932a9a8c8a42878df2.png)
