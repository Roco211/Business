# 「手机端」商品如何设置多规格

官方页面: https://www.zhihuiji.cn/help/doc/1539

**视频教程** ：[点此查看【手机端设置多规格】](https://www.zhihuiji.cn/help/video/3300)

**操作路径** ：【商品】→【编辑/新增商品】→ 打开【多规格】开关

**操作步骤：**

  1. 进入商品编辑页，在【详情】中打开多规格开关
  2. 在规格管理中，选择或输入商品的具体规格（如颜色、尺寸）
  3. （可选）点击右上角批量按钮，快速设置各规格的价格与库存
  4. 确认无误，点击保存



![手机端设置多规格界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202209/ee848a664024a3a2d6f7c4e686d74a9f.jpg) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c660a743c720464244444a6db9801949.png)

**功能价值**
轻松管理同一商品的不同型号、颜色或尺寸，实现快速开单。
