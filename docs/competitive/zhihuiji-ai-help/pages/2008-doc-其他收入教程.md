# 其他收入教程

官方页面: https://www.zhihuiji.cn/help/doc/2008

视频描述  **1.新增其他收入**

路径1：点击【资金】-【其他收入】旁的【+】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/584dd5dd6dda28b0095ecf217b777f38.png)

路径2：点击【资金】-【其他收入】-【新增其他收入】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/379a3dab5485e3b4eec0d5efb1be5674.png)

（1）输入收入类型

（2）选择收款账户

（3）输入收入金额

（4）点击保存

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/765356616e97b82b0d56883cd1b4f5bb.png)

**2.其他收入列表**

路径：【资金】-【其他收入】

（1）可以根据单据日期，门店，收入类型，单据编号，业务员，备注查询其他收入单据。

（2）点击【导出】，可以导出到Excel表格。

（3）点击对应单据右侧可以【查看】【修改】【作废】单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/c94b41b6a31108b61d189e6c4630b66d.png)
