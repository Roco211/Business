# 库存预警批量设置

官方页面: https://www.zhihuiji.cn/help/doc/2340

视频描述

## 功能简介

当出现以下情况时，您可以使用“批量设置库存预警”功能：

  * 商品初次录入时未设置库存预警，后续需要统一补设。

  * 因销售策略、季节变化等原因，需要批量调整一批商品的库存预警值。

  * 希望为所有仓库设置统一的库存预警水平。




## 操作步骤

### 进入功能页面

依次点击【商品】-【商品】-选中要修改的商品-【批量操作】-【设置库存预警】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/6a3df760bd2cd2e608f6d4ec542f089e.png)

### 选择操作范围

您可以选择：

  * **仅修改选中商品** ：仅对当前手动选中的商品生效。

  * **修改当前查询条件下的所有商品** ：对通过筛选条件查询出的所有商品生效。




![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/28f4a96ed580352844f708f64b034505.png)

### 设置预警数值

您可以分别对每个仓库设置**最低库存** 、**安全库存** 和**最高库存** 。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/1fc62bf54f3b63d2ca8edb1c4cc9676b.png)

### （可选）统一设置所有仓库

若所有仓库预警值相同，请勾选 **“所有仓库预警值相同”** ，然后一次性填写最低库存，安全库存和最高库存数量的具体数值即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/5696cf583e61e7a31237ed4a011b7a69.png)
