# 设置商品分类/类别

官方页面: https://www.zhihuiji.cn/help/doc/905

视频描述

## 业务场景

（1）设置商品分类，便于按分类管理商品。
（2）商品错放分类时，可将其转移到正确的分类。

* * *

## 单个商品：设置或修改分类

**路径：** 【商品】→【商品】→ 新增或修改商品 → 「商品类别」

![新增或修改商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/1dc637cc829ddb3913cea1cd450330eb.png)

设置分类时，可选择以下任一方式：

  * **按层级选择** ：直接浏览并选择目标分类。
  * **搜索选择** ：输入关键词，搜索后快速选择对应分类。



![设置分类](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/ad180189a8c65232643a409c6db8e935.png)

* * *

## 批量修改：移动商品分类

**路径：** 【商品】→【商品】→【批量操作】→【移至分类】

在弹窗中，可根据需要选择移动范围：

  * **只修改选中商品** ：勾选此选项后，选择要移至的分类，点击确定。
  * **修改某分类下的所有商品** ：勾选此选项后，选择“现分类”和“移至为”分类，点击确定。



![批量移至分类](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/b056310c68b94e79107464010609f7e2.png)
