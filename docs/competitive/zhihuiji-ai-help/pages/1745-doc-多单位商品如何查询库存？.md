# 多单位商品如何查询库存？

官方页面: https://www.zhihuiji.cn/help/doc/1745

视频描述

## 业务场景

（1）下游客户来订货，订了5箱，商户想查询软件里的商品库存数量还有多少。

（2）下游客户询价（一箱多少钱？）

## 查询路径

路径1：【商品】-【商品】，单位栏手动选择辅单位可以查看到零售价，批发价，库存数量等信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/36369e9900c5fd3de06b58f98d13b738.png)

路径2：【库存】-【库存查询】-单位栏手动选择辅单位可以查看库存数量，库存金额等信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/a2b8b747b1b25e7a383b34d45c144002.png)
