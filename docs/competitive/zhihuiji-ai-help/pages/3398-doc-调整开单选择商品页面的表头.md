# 调整开单选择商品页面的表头

官方页面: https://www.zhihuiji.cn/help/doc/3398

开单时，在“选择商品”页面可自定义显示的字段，方便您快速查看关键信息。

**支持单据：** 销售单/销售预订单/销售退货单、进货单/进货预订单/进货退货单

**操作路径：** 开单时点击【选择】→ 点击页面左上角齿轮图标【设置】→ 调整显示字段 →【确定】
