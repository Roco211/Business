# 「手机端」AI批量录入商品

官方页面: https://www.zhihuiji.cn/help/doc/3463

操作路径：进入APP首页【**商品** 】 -> 点击右上角 **“+”** -> 选择【**AI批量录入** 】。

  * **支持方式** ：
    1. **图片识别** ：直接拍摄或上传供应商的货单照片。
    2. **文件识别-选择微信文件** ：从微信聊天记录中选择文件，快速跳转识别。
    3. **文件识别-其他App导入** ：从支持分享到其他应用的App导入文件
  * **文件格式** ：图片、Excel、PDF
  * **后续处理** ：AI会自动解析品名、规格、价格等信息，生成商品列表，您只需核对信息即可完成建库。 ![AI批量录入流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/a66e3975fad2604ad951997c49d2ebde.png)
