# 「手机端」盘点单

官方页面: https://www.zhihuiji.cn/help/doc/2703

## 新增盘点单

路径：点击右下角【更多】-【盘点】-右下角【盘点】，选择要盘点的商品信息，然后输入实际数量保存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/b2f65cddacc4f3749aa01d0bfb6ae134.png)

## 作废盘点单

路径：点击进入盘点单详情界面，然后点击底部的【作废】按钮即可作废盘点单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/db6150b5d1fd594ea5bb28a075162052.png)

注意：盘点单做错了是不支持修改的，只能作废后重新做盘点单。
