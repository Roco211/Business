# 商品类别管理

官方页面: https://www.zhihuiji.cn/help/doc/2838

## 新增商品类别

视频描述

### 业务场景

商品比较多时，用商品类别管理商品。

### 功能简介

可以通过以下2种方式新增商品类别：

• 从【商品】-【商品】-【新增类别】

• 从【商品】-【商品】-【导入新增】导入新类别的商品

注意：不支持快速导入商品类别分级

### 操作流程

**方式一：新增类别**

**路径：** 【商品】-【商品】，点击左侧“编辑”，要添加为哪个分类的下级，就在对应分类右侧点＋

注意：最多支持5级类别

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/3d147e62f9e4aa2446de2e3cb778e359.png)

**方式二：导入新类别的商品**

**路径：** 【商品】-【商品】-【导入新增】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/75046d2f14314d40c9197531e3eea71d.png)

在表格内填写要导入新增的商品信息和商品分类，若该分类在系统内不存在，则会自动新建。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/9bebd1bf758b1c31850b8f8c16f1cab4.png)

## 修改商品类别名称

### 业务场景

货品类别名称修改，是日常业务中不可或缺的功能。

### 功能说明

不支持批量修改类别名称，只能一个一个点击修改。

### 操作流程

**路径：** 【商品】-【商品】，找到商品类别，点击编辑的符号，修改类别名称后点击保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/56ea8859d472db261c92e36595ab80d3.png)

## 删除商品类别

**路径：** 【商品】-【商品】，找到商品类别，点击删除的符号，确认删除商品类别

更多详情点此查看→ [分类删除指南](https://www.zhihuiji.cn/help/doc/3204)
