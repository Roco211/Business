# 在开单界面显示单位换算结果

官方页面: https://www.zhihuiji.cn/help/doc/3396

**适用单据：** 销售单/销售订单/销售退货单、进货单/进货订单/进货退货单

**设置路径：** 开单时点击齿轮图标【表头设置】→ 添加「单位换算结果」字段，系统将自动计算并显示“1箱3瓶”等多单位组合结果。

![添加单位换算结果字段](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/65939d3e7e61225c80c20438558e9a22.png)

![显示示例](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/f3666dbab83502fa4101c6e7919e055c.png)

**换算显示规则：**

  1. **优先区分大小单位** （仅支持换算辅单位1，如箱为大单位，瓶为小单位）。
  2. **开单选择小单位时** ：
     * 若输入数量 > 换算率，则显示 **【X大单位Y小单位】** （如：1箱3瓶）
     * 若输入数量 = 换算率，则显示 **【X大单位】** （如：1箱）
     * 若输入数量 < 换算率，则显示 **【Y小单位】** （如：3瓶）
  3. **开单选择大单位时** ：
     * 若输入数量 > 1且非整数，则显示 **【X大单位Y小单位】**
     * 若为整数，则显示 **【X大单位】**
     * 若输入数量 < 1，则换算为小单位显示 **【Y小单位】**
