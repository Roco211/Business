# AI开单教程

官方页面: https://www.zhihuiji.cn/help/doc/2266

**用户背景：**

1.客户通过微信/QQ等平台，在线向客户下单。

2.客户发手写单的图片来下单/商户把手写单录入系统中。

视频描述

**操作路径：** 【销售】-【销售】-【新增销售单】，进入到新增销售单界面，然后点击【AI开单】按钮。支持文字识别和者图片识别。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/3c5c1e909377cc2ee922ff8f26e704c5.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/157199e202c6ba5b31c94870af3e7aea.png)

## 文字识别：

把文字粘贴到搜索框里，然后点击开始识别。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/423590da84ecbe73d98e8ff28c376495.png)

## 图片识别

点击添加上传图片，支持拖拽上传和复制粘贴上传。支持jpg，png格式，识别出商品后点击下一步。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/1b74849e6a1322151fc87d9731bd8dc8.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/1ca6c40768ee90d59b0db877d1f65730.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/a64434fc860cbbbc93065aea06e48844.png)

（1）识别完成后，若匹配到唯一商品，则提示匹配成功；

（2）若一个都未命中，则提示未匹配，录入单据会自动创建为新商品；

（3）若命中了多个商品，则系统自动选中一个，并且支持更换。在操作栏，点击【更换】，弹出更换商品页面，可选择要更换的商品，顶部支持搜索商品、规格、货号等信息定位商品;

（4）操作栏鼠标移入，可删除该行匹配结果。

（5）确定商品无误后点击录入商品，然后保存商品信息即可。
