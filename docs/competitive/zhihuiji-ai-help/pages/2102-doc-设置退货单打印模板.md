# 设置退货单打印模板

官方页面: https://www.zhihuiji.cn/help/doc/2102

**销售单和退货单模板默认是共用同一个模板的，如果需要区分销售单和退货单抬头，要单独设置退货单模板。**

视频描述

1.路径：点击【设置】-【打印设置】-点击销售单默认模板进入到编辑界面-右上角【复制】-输入模板名称-确定。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/bb488d22be85d9bc90dad52c877afd09.png)

2.把抬头的销售单改成退货单，保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/6004814d0a7ee54b26c82277966efb22.png)

3.到销售退货单点击打印时候选择新增的销售退货单模板。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/03f4db27f5e47d3f8efc63108c0b6864.png)

4.预览效果如下：
