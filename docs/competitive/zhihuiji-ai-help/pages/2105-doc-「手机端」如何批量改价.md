# 「手机端」如何批量改价

官方页面: https://www.zhihuiji.cn/help/doc/2105

视频描述

**操作路径** ：【商品】→【批量操作】→【批量改价】

**操作步骤：**

  1. 进入商品列表，点击「批量操作」，选择「批量改价」
  2. 勾选需要调价的商品，点击底部「批量改价」按钮
  3. 在改价界面，选择按**比例** （百分比）或按**金额** 进行上调/下调
  4. 设置好调价幅度后，点击保存即可



**按比例：** ![批量改价入口界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/f7306d5595536881eeea84f65949472d.png) **按金额：** ![按金额调价界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/bf53023e30dc46e3eb01712e78eabcdb.png)

**适用场景**

因进货价变动、市场波动或促销活动，需要一次性调整多个商品售价。
