# 保质期计算：“天”与“月/年”的区别

官方页面: https://www.zhihuiji.cn/help/doc/3340

为商品设置保质期时：

**1\. 保质期按“天”计算**

到期日期 = 生产日期 + X天

**示例** ：1月1日生产，保质期30天，则于**1月31日** 到期。

**2\. 保质期按“月”或“年”计算**

到期日期 = X月/年后的“当天”，系统按**自然月/自然年** 计算。

**核心规则** ：不考虑每月具体天数（如2月只有28天）或闰年。

**示例** ：1月1日生产，保质期1个月，则于**2月1日** 到期。
