# 如何为规格上传专属图片

官方页面: https://www.zhihuiji.cn/help/doc/3301

**操作路径** ：【商品】→【编辑商品】→【启用多规格】后

**操作步骤**

  1. 启用多规格时，勾选【设置规格图片】
  2. 为每个规格内容（如“红色”）上传对应的商品图片
  3. 保存后，开单时将显示规格图片



![设置规格图片界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/45bf6c872290a3936bdd4cb1c28ea681.png)

![开单时图片显示](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/ad78dba65b08c9efc290be66c9dbf31a.png)

**核心价值** 开单时视觉化区分不同规格，避免错选，提升效率与专业性。
