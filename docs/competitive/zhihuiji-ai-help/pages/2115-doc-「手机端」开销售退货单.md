# 「手机端」开销售退货单

官方页面: https://www.zhihuiji.cn/help/doc/2115

**操作路径：** 【销售开单】→ 顶部切换至【销售退货单】→ 选择客户与商品 →【收款】或【保存】

![开退货单流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/b539b341fb75ab161e154b0085b05697.png)

**保存后支持操作：**

  * **再来一单** ：继续开退货单
  * **打印** ：打印当前退货单
  * **查看详情** ：进入详情页进行修改、作废、分享等操作



![退货单详情](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/f7ca6e91fc577b23cecd783e17121ca8.png)

**💡 温馨提示：**

退货单开单流程与销售单相似，保存后原商品库存将自动恢复。
