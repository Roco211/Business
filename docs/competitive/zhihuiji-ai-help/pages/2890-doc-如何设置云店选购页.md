# 如何设置云店选购页

官方页面: https://www.zhihuiji.cn/help/doc/2890

**操作路径** ：左侧栏点击 **【云店】** \- **【云店装修】** \- 顶部 **【选购页】**

在此页面，您可以对云店选购页进行以下设置：

  * **公告** ：控制是否显示公告，并可编辑公告具体内容。
  * **列表样式** ：选择 **“标准”** 、**“展开二级分类”** 或 **“展开三级分类”** 。



![选购页装修界面入口截图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/d7f2444540f048b92c03f552a9bbdad8.png)

**管理分类图片** 点击分类列表后的 **“+”** 号按钮，即可为该分类设置展示图片。

![分类列表后方加号按钮位置示意](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/225e9f35089932dfed32e35c97e734a2.png)
