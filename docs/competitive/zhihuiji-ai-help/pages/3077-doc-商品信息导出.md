# 商品信息导出

官方页面: https://www.zhihuiji.cn/help/doc/3077

商品导出教学视频

## 功能简介

商品信息导出功能让您能够快速将商品数据导出为表格文件，便于本地存档、数据分析或批量处理。

## 操作步骤

### 进入导出页面

**操作路径** ：【商品】-【商品】-【导出】

![导出入口位置](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/deffb111294197ae5b2e9da86ccc3865.png)

### 下载导出文件

  * 系统处理完成后，点击【下载】按钮
  * 将表格文件保存至本地



![下载导出文件](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/01533c5e7242150cf04a06522984ed85.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/2b57101e99142773ea6a5cf8d416dc76.png)

## 查看历史记录

  1. 点击导出按钮右侧的**下拉箭头**
  2. 选择【导出记录】
  3. 查看30天内的所有导出任务
  4. 可以重新下载之前的导出文件



![导出记录入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/9923bd5e055c1c1cd04928627febab21.png)

![导出记录界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/faecdf02453f974bda6018fe825fc319.png)

## 重要说明

  * **数据保留期限** ：系统仅保存30天内的导出记录
  * **数据字段** ：导出的数据字段为系统默认，不支持自定义设置
