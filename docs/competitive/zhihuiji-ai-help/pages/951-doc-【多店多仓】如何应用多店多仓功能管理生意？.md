# 【多店多仓】如何应用多店多仓功能管理生意？

官方页面: https://www.zhihuiji.cn/help/doc/951

李先生有3家门店，2个仓库，他如何用智慧记AI进销存的**【多店多仓】**功能管理生意呢？

**一、添加门店/添加仓库** ：

首先，需要添加门店和仓库

操作路径：在【首页】-【设置】-【门店管理】里面，把3个门店添加上；

在【首页】-【设置】-【仓库管理】里面，把2个仓库添加上，并且设置好门店与仓库是否关联。

如果关联，门店就能够售卖关联仓库的货品。

像李先生3家门店，A店,B店位于深圳市，关联了仓库1；C店位于广州市，关联了仓库2。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202203/abb9161591b1495edfb71540c1e809f7.jpg)

**二、进货/销货** ：

开进货单/销售单的时候，要选择对应的门店，以及和该门店已关联的仓库。

这样，仓库和门店的库存数据就能一致。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202203/f8fe75ac31ac3b473b0283f56ed0aed6.jpg)

**三、库存盘点** ：

盘点的时候，可以选择不同的仓库来盘点，确保每个仓库的库存数据的精准。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202203/0db9ecadc1baa7022c0a3dface80ecaa.jpg)

**四、查看报告** ：

可以按门店查看销售统计/利润统计/进货统计等报告。

支持按仓库查看库存统计报告。

**注：智慧记AI进销存高级版支持多店多仓，购买智慧记AI进销存高级版后，可开启多店多仓，并可单独增购门店数和用户数** 。
