# 进货退货单

官方页面: https://www.zhihuiji.cn/help/doc/2710

## 新增进货退货单

（1）路径：底部【进货】-顶部【退货】-右下角【退货】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/35c969ede0b2a75c89aeac04e5fad00b.png)

（2）选择退货的供应商和退货商品信息，然后点击保存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/07a3290a1a18d7f4a79b8f8012ee6510.png)

（3）保存成功后可以点击【打印标签】，就可以打印商品的标签，点击底部的打印按钮可以打印该单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/1f3b404a5ba92b3816c8a0e90b700af9.png)

## 修改进货退货单

进货退货单列表点击对应的退货单，然后进货到退货单详情界面，然后点击底部的修改按钮即可修改单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/c0619332092ac6048c931f11ee72d823.png)

## 复制和作废进货退货单

在进货退货单详情界面，点击右上角的【...】按钮，就可以点击复制本单和作废单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/d9e61ef0c282511df31e1dba635ce2ff.png)
