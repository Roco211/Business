# 如何使用保质期管理

官方页面: https://www.zhihuiji.cn/help/doc/2861

视频描述

**操作路径** ：【设置】-【系统设置】-【商品设置】- 勾选【启用保质期管理】 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/4ef3ac48d723d09bfedb1b36b944336e.png)

**1\. 为商品启用保质期**

路径：【商品】-【商品】-【新增/修改商品】-【商品库存】

  * 勾选【启用保质期管理】
  * 设置**保质期** （正整数）与**单位** （天/月/年）
  * 建议同时勾选【保质期预警】并设置预警时间，了解[如何查看保质期预警](https://www.zhihuiji.cn/help/doc/3345)。



![商品设置保质期](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/9e66ade5e8765af0f2f9bba46bdedcc8.png)

**2\. 进货时录入信息**

启用后，在【进货单】中选择该商品，**必须填写生产日期** 。

**3\. 查询保质期库存**

路径：【库存】-【保质期查询】，可查看所有带保质期库存的详细情况。

**💡 核心规则**

  * **计算方式** ：保质期从**生产日期次日** 开始计算。
  * **单位说明** ：“月/年”按自然月/年计算，不区分每月天数。
