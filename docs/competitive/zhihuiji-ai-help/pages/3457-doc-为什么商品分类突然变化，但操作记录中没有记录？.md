# 为什么商品分类突然变化，但操作记录中没有记录？

官方页面: https://www.zhihuiji.cn/help/doc/3457

**操作路径：** 【商品列表】 → 【批量操作】 → 【移至分类】

目前，通过此路径进行的批量分类移动，**操作记录中不会显示** 。

![批量移至分类](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/235526dc7957df3b8726b3058f3734f8.png)

**建议与解决方案：**

  1. **内部确认** ：建议先与团队内有商品修改权限的同事沟通，确认是否有人使用过此批量功能。
  2. **同步信息** ：进行重要的批量分类调整后，建议操作者在团队内简单同步，方便追溯。
  3. **替代方法** ：如果某次分类调整必须留下可查的操作记录，目前建议使用编辑单个商品的方式进行调整，系统会记录此类操作。
