# 如何设置打印单据时尺码横排

官方页面: https://www.zhihuiji.cn/help/doc/3503

**操作路径** ：【设置】→【打印设置】→ 编辑已有模板或新增模板 → 勾选【尺码横排】，并选择要展示的尺码（默认展示前5个，最多可选20个）
