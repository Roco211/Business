# 如何安装打印控件

官方页面: https://www.zhihuiji.cn/help/doc/1001

**打印单据前，需要先安装智慧记AI进销存打印服务，下面来看看是怎么操作的吧**

视频描述

安装Web打印服务

**路径** ：【设置】-【基础设置】-【打印设置】-【打印模板】-【模板】-点击进入模板-【编辑打印模板】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/91a3e269a391a739eaca79e94f34fb80.png)

**功能说明** ：

  1. 需先安装Web打印服务（CLodop_Setup_for_Win32NT.exe ），才可以启动打印。

  2. 打印服务安装成功后，请刷新打印模板编辑页面。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/9c80f2674f9ad8b4eb6624adfc996606.png)
