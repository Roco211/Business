# 单位换算结果详解

官方页面: https://www.zhihuiji.cn/help/doc/3374

**场景：** 开单、拣货、交货、对账时，通常按商品拆分成整件和零头的方式进行沟通，提升操作效率，更符合商业习惯，比如冻鸡翅“几大件零几小个”。

  * 包装食品出入库，仓库人员**直接按“2箱3瓶”拣货，客户提货或验收一目了然** ，免去人工换算；
  * 大件商品对账与结算，与客户或供应商核对往来数量，避免因理解偏差产生纠纷，比如“5板零8件”是158个散件还是几整板。



## 添加单位换算结果

**路径：** 开单界面，点击左上角“齿轮”图标设置【自定义表头】-【可选表头-单位换算结果】找到并添加-【已显示表头】将显示在列表中。

以销售单为例： ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/f99f399b113420473ef3f3d8e24b2b54.png)

## 换算显示规则

在销售和进货业务单据中，系统将根据商品的主辅单位关系自动换算数量，为现场作业与对账提供直观的复合单位。换算结果显示依据：**开单数量能否凑足【一个大单位】**

  * **凑足时，换算显示【大单位+小单位】的组合格式** ，若以“箱”计量更大为例（1箱=10瓶）：



销售23瓶，换算显示2箱3瓶；

销售1箱，换算仍显示1箱，而不显示10瓶。

  * **未凑足，换算仅显示【小单位】格式** ，若以“件”相对重量小为例（1件=0.6吨）：



销售0.3吨，换算显示0.5件；

销售1.5件，换算仍显示1.5件，而不显示0.9吨。

**仓库拣货核对实例：** 若需精确统计散装数，建议直接使用散装单位开单（如“瓶”）

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/462a567681a5e0de8624850cd59f35ca.png)

**重量应用实例：** 若需精确统计纯重量，建议直接使用重量单位开单（如“吨”）

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/fae9b29957ccc9ca7393361acb922818.png)

**路径：** 导航栏【设置-打印设置】-【打印模板】编辑界面-点击表格区域，勾选右侧【列设置-换算结果】-【保存】
