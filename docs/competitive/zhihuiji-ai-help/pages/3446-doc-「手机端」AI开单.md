# 「手机端」AI开单

官方页面: https://www.zhihuiji.cn/help/doc/3446

AI开单能通过语音、图片或文字，快速识别并添加商品，简化开单流程。

**操作路径** 首页点击【销售开单】→ 进入后点击右上角【AI开单】。

**三大识别方式**

  * **语音识别** ：直接说出商品信息（如“两箱可乐”）。
  * **图片识别** ：拍摄或从相册上传包含商品信息的单据、货架照片。
  * **文本识别** ：将商品文字信息粘贴到搜索框后，点击开始识别。 ![语音/图片/文本识别界面示意图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/597f878a360719fef415fc9e4a3b5cd0.png)



**后续操作**

  1. 识别成功后，确认或更换系统匹配的商品。
  2. 商品信息将自动填充至销售单。
  3. 核对并修改其他信息（如数量、价格），点击收款/保存即可完成开单。
