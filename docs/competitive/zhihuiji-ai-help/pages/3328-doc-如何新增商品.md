# 如何新增商品

官方页面: https://www.zhihuiji.cn/help/doc/3328

创建新商品操作视频

**操作路径：** 【商品】-【商品】-【新增商品】

![新增商品入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202602/d2413ebb5c776beab351589854468b08.png)

  1. **选择录入方式**

     * **扫码录入** ：用扫码枪扫商品条码，自动填充信息。
     * **智能录入** ：在“商品名称”输入关键词，双击推荐结果快速填充。
     * **手动录入** ：自由填写所有信息。
  2. **填写核心信息**

     * **商品名称** 为必填项。
     * 完善价格、库存等信息。
  3. **点击【保存】或【保存并新增】** 商品即添加成功，可用于开单和库存管理。
