# 「手机端」批量设置库存预警

官方页面: https://www.zhihuiji.cn/help/doc/3376

**操作路径：** 【商品】→【批量操作】→【批量设置库存预警】→ 勾选商品 →【批量设置】

![批量设置库存预警](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/ae03bacfeac229379deb71e7bf08028c.png)

**进入设置页面后，您可以：**

  1. **填写预警值** ：统一设置「最低库存」、「安全库存」与「最高库存」
  2. **按仓库设置（若启用多仓库）** ：可按仓库分别设置，或启用「所有仓库预警值相同」进行统一设置
  3. **保存生效** ：点击【保存】后，设置将应用到所有已选商品



* * *

**💡 温馨提示：**

批量修改将**覆盖** 所选商品原有的预警值，请谨慎操作。
