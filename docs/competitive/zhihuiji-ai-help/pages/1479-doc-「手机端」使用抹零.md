# 「手机端」使用抹零

官方页面: https://www.zhihuiji.cn/help/doc/1479

## 开启抹零功能

**路径：** 【我的】-【设置】-【开单设置】

  * 启用【销售单抹零】功能
  * 选择抹零方式：抹分、抹角、四舍五入到"角"、四舍五入到"元"



![设置抹零](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/e8a3eaf82ec74f7cdf6d14183b49161f.png)

## 开单时使用抹零

**路径：** 【销售开单】-【添加商品】-【抹零】

  * 点击【抹零】按钮，系统自动按设定规则减去零头
  * 确认金额后，完成收款或保存单据



![使用抹零](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/10cf86f0d5ba4291eac0a130873d321b.png)

**💡 温馨提示：**

抹零功能开启后对所有销售单生效，开单时可根据需要选择是否使用。
