# 「手机端」新增进货单

官方页面: https://www.zhihuiji.cn/help/doc/1478

**操作路径** ：首页【进货】→右下角【进货】 → 选择/填写供应商、时间、业务员 → 添加商品 → 【付款】或【保存】 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/1baf70a99e2555c95d50f1c911d4fae2.png)

**保存后支持操作：**

  * **再来一单** ：继续开进货单
  * **打印标签** ：打印进货的商品标签
  * **打印** ：打印当前进货单
  * **查看详情** ：进入详情页进行修改、作废、复制等操作
