# 云店订单维护

官方页面: https://www.zhihuiji.cn/help/doc/2771

**云店订单维护**

下游客户下单后，同步在小程序生成一笔云店订单，商家可进行接单/拒绝操作，确认接单表示同意此笔生意；接单后商家可进行发货，发货（转销售单）扣减库存

路径：智慧记AI进销存 销售-云店订单
