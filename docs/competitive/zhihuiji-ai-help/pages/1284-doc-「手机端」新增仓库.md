# 「手机端」新增仓库

官方页面: https://www.zhihuiji.cn/help/doc/1284

* 智慧记AI进销存单店版、多店版支持多仓库



**1\. 启用多仓库：** 【我的】→【设置】→【基础设置】→ 开启【多仓库】按钮。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/a57f6190277cea085689108eed10f2f2.png)

**2\. 新增仓库：** 【我的】→【店铺管理】→【仓库管理】-右上角【+】-填入仓库信息后，点击右上角【保存】。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/b5b62ddfe448a88b84c84661ec1151ff.png)
