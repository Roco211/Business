# 新增，修改和删除商品属性

官方页面: https://www.zhihuiji.cn/help/doc/1824

视频描述

## 新增商品属性

**操作路径一：** 左侧导航商品-商品属性-添加商品属性，最多可以添加6项属性。

选择型：是指新增商品时可以从下拉框直接选择属性值。

输入型：是指新增商品时每次都需要手动输入属性值。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/71c687ae3ba461ff064c853a40a446ef.jpg)

**操作路径二：** 商品列表点修改-点击设置

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/b2b8bdd784895cc39327fb01dd3c0956.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/ff5797c212a78d1472ba7d44e865420b.png)

## 编辑/删除商品属性名称

**操作路径：** 商品-商品属性，编辑/删除。

**编辑：** 支持编辑属性名称和属性值，属性类型不能修改，品牌和重量不能修改属性名称。

**删除：** 没有使用的属性可以删除，已经使用过的属性不支持删除，品牌和重量不支持删除。
