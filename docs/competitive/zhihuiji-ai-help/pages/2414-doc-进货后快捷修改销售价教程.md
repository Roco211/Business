# 进货后快捷修改销售价教程

官方页面: https://www.zhihuiji.cn/help/doc/2414

视频演示

**适用场景** ：进货后需要快速调整商品售价，避免亏本销售或优化定价策略。

* * *

## **新增进货单**

进入【进货】→【进货】→【新增进货单】，选择要进货的商品信息并保存。

## **查看提示并调整**

保存后进入进货单详情页，系统会提示：**“本次采购了X个商品，是否需要快速调整商品售价？”**
点击【立即调整】即可进入售价修改界面。

> 无论进货价是否变动，均可通过此功能快速调整售价。

![调整售价提示](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/a4889bb28c6a4bdca36dad5cb79f4936.png)

## **修改并保存售价**

进入售价调整界面，修改商品的售价后点击【保存】即可。修改后的价格将自动更新到商品列表中。

![售价调整界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/1969ec90dcd7d5b21b6e73e77da428d6.png)
