# 调整单是如何生成的？

官方页面: https://www.zhihuiji.cn/help/doc/3467

调整单在您手动调整客户欠款后自动生成。具体操作如下：

  1. **生成路径**
进入【客户】列表 → 点击对应客户【查看】→ 进入详情页后点击【去调整】。
  2. **如何查看**
调整完成后，在**客户对账单** 中会自动生成一条调整单记录。
  3. **注意事项**


  * 调整单**不支持删除或修改** 。
  * 如调整有误，可再次通过【去调整】操作进行修正。
