# 微信公众号跳转云店

官方页面: https://www.zhihuiji.cn/help/doc/2827

## 专属版

登录微信公众号后台[https://mp.weixin.qq.com/](http://)，菜单栏可以设置跳转小程序。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/e52385c2cd21c3b602ef94edef23c05a.png)

## 订货版

登录微信公众号后台[https://mp.weixin.qq.com/](http://)，菜单栏可以设置跳转小程序或设置自动发送商城入口链接。

**方式1（推荐）、直接跳转小程序**

智慧记AI进销存云店小程序路径：pages/index/index?corp_id=智慧记AI进销存店铺商户号

由于智慧记AI进销存云店属于平台开店，商家没有单独注册小程序，需联系智慧记客服获取智慧记AI进销存**店铺商户号** 。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202502/6ab406d715f3b14047836e33a8d303b3.png)

**关联【智慧记云订货】小程序（官方平台，非当前店铺）：**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202502/da29a20baf95be97a33e0af6b65313da.png)

**方式2、自动发送消息**

通过公众号菜单栏设置发送消息，自动回复小程序码图片或者小程序链接，用户再次识别或者点击进入云店小程序。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202409/1e5d09db9e29f85dd868de530655bc04.png)
