# 为什么销售统计中的利润与开单时看到的利润不一致？

官方页面: https://www.zhihuiji.cn/help/doc/3280

销售统计中的销售毛利与新增/修改销售单页面显示的毛利润不一致，是因为两者采用了不同的成本计算基准，属于正常现象。

| 销售统计报告 | 新增/修改销售单页面
---|---|---
计算基准 | 历史成本：按照销售当时的商品成本计算 | 实时成本：按照当前/结余的商品成本计算
目的 | 反映历史交易的真实盈利情况 | 基于最新成本，预估本次销售的利润

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/30e5d9bac67a897db8af37fab1390f45.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/16531c28d1f6ae27894be3ef02e5ef44.png)

**结论：** 当两者不一致时，说明在开单之后，商品的成本发生了变动（如：录入了新的进货单）

**如何核实？**

您可以通过以下路径查看商品的成本变动记录，追溯问题：

【库存】-【库存查询】- 搜索指定商品 -查看【成本明细】
