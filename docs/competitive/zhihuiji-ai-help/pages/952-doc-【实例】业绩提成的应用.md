# 【实例】业绩提成的应用

官方页面: https://www.zhihuiji.cn/help/doc/952

**业务场景**

将企业盈利按照一定的比例在企业和员工之间分成的方式，这种方式能够调动员工的积极性，提高公

司的人员效益。

**开通【业绩提成】订阅服务**

业绩提成为单独付费服务，不含在付费版本中。

【首页】左侧菜单【订阅】-【服务订阅】-【业绩提成】，付费之后可使用该功能。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202211/302fea5715c907da4fc908521946ed26.jpg)

**操作指引**

**例** ：李老板门店有3名员工，需要给员工们设置业绩提成的规则，方便每个月结算工资

  * **设定新的提成规则**



**路径** ：【销售】-【业绩提成】-【业绩设置】-【新增规则】

**说明** ：在此页面可以设置提成规则的【名称】、【提成方式】、【分账金额】、【计算规则】、【超额奖

励】、【适用员工】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/5368df1a633688552f86c86b3db83874.png)

  * **员工绑定提成规则**



**路径** ：【销售】-【业绩提成】-【业绩设置】-选择加入的提成规则-【修改】-【适用员工】

**说明** ：每一个提成规则都可以选择适用的员工。（可以选择多名员工绑定同一个规则）

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/ac518bf6123d0a2f2f7b73658a6195eb.png)

  * **系统自动计算提成**



**说明** ：系统会在业务员开单后，根据事先设定好的提成规则，自动计算出提成金额。同理，超额奖励也是同

等计算方式

  * **查看业绩提成表**



**路径：** 【销售】-【业绩提成】

**说明：** 可以清晰看出员工的【提成金额】等信息

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/7116122b5e68d746ac3c3c93074b1032.png)
