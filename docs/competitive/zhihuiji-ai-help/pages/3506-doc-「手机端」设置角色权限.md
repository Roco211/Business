# 「手机端」设置角色权限

官方页面: https://www.zhihuiji.cn/help/doc/3506

**手机端修改角色权限操作路径** ：【我的】→【店铺管理】→【员工管理】→【角色权限管理】

进入后编辑角色权限，保存即可生效。
