# 智慧记迁移智慧记AI进销存相关问题合集

官方页面: https://www.zhihuiji.cn/help/doc/3108

**问题一：智慧记迁移到智慧记AI进销存主要是迁移哪些数据呢？**

答：数据迁移，是将智慧记中的部分基础数据迁移到智慧记AI进销存或Ailit（国际版），如商品、客户、供应商、结算账号、营业员信息等（暂不支持单据、报表的迁移)

**问题二：智慧记迁移到智慧记AI进销存停用的商品和客户会迁移过去吗？**

答：停用的商品和客户都会迁移到智慧记AI进销存，迁移后智慧记AI进销存里面也是停用状态

**问题三：智慧记迁移到多店版智慧记AI进销存，数据会到哪一个门店呢？**

答：数据会迁移到智慧记AI进销存最开始创建的门店，如果最开始创建的门店停用了就依次往后推

**问题四：如果智慧记AI进销存里面有部分商品和客户信息与智慧记里面重复，迁移会覆盖吗？**

答：不会覆盖，重复的信息不会迁移

**问题五：智慧记迁移到智慧记AI进销存后，商品库存数量一致但库存金额对不上？**

答：智慧记迁移到智慧记AI进销存成本价取的是商品的进货价，而智慧记中的成本是通过移动加权计算出来的，所以会存在一定的差距

**问题六：智慧记迁移到智慧记AI进销存支持更换手机号码吗？**

答：支持。在智慧记点击迁移后输入新的号码即可。
