# 小程序开通——填写小程序信息

官方页面: https://www.zhihuiji.cn/help/doc/3032

小程序开通——填写小程序信息 提交了微信认证之后，下一步就是补充小程序**基本信息** ：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/72e19317dac18328b8dd59b9a79db00e.png)

基本信息的内容包括：名称、图标、简介、服务类目：①第一项是填写小程序名称。帐号名称长度为4-30个字符，一个中文字等于2个字符。提交名称前请检测名称是否可用。（小程序名称具有唯一性）

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/13a5006a99aa4cc0fcae866842f1ec4e.png)

备注：小程序改名规则

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/90e828862ce93287d88cf76ee0f5d542.png)

②接下来就是选择小程序的头像：图片格式必须为：png,bmp,jpeg,jpg,gif；不可大于2M；建议使用png格式图片，以保持最佳效果；建议图片尺寸为144px*144px。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/a1153d8d3dab8b3137490e81c312cb7d.png)

③完善小程序的介绍：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/e83400da3873c176046093d21275d0bd.png)

④最后请根据小程序自身的功能，**正确选择服务类目** 。如果类目比较多,还可以在添加。（**请注意！这一步非常重要，请正确选择服务类目，如果选择错误将导致小程序无法审核通过** ）

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/f78c2f3c23fbef57d08a55c0fe9d371a.png)

完成后，选择提交即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/c0bf3c24b3279744708681bac3d787f9.png)

提交后,会回到公众平台主画面。这时,再看小程序信息,已经变为已完成。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/ec859ffdca05ceb2ed984082fb6bb551.png)

下面开发者管理和发布不用商家操作。 附：*很多用户会忽略服务类目的设置，但是在微信审核过程中，服务类目审核是最重要的一个环节，请务必重视！！下面介绍审核失败后，如何修改服务类目：1.微信公众平台登录小程序账号 https://mp.weixin.qq.com2.进入设置 - 基本设置

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/1b209de105f6a854ae2ceb5527722821.png)

  3. 服务类目条目中进行修改



一个微信小程序最多关联5个服务类目，一个月内可申请修改3次。小程序官方服务类目参考：https://developers.weixin.qq.com/miniprogram/product/material/#非个人主体小程序开放的服务类目 注册认证完小程序后，接下去就需要小程序一键授权给智慧微店了。
