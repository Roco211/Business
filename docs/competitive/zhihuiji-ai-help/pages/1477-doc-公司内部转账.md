# 公司内部转账

官方页面: https://www.zhihuiji.cn/help/doc/1477

资金转账可以用来处理公司内部资金流转，下面来看看具体操作

**操作路径** ：【资金】-【转账】，选择【转出账户】和【转入账户】，输入金额和备注，点击【保存】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202207/e43b68856e2a80e340ee9644a472ae0f.jpg)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202207/69358bb2f71350ec07a092d665d7bf70.jpg)

即完成一次资金转账。
