# 如何修改商品

官方页面: https://www.zhihuiji.cn/help/doc/3329

**操作路径：** 【商品】-【商品】- 找到商品 - 点击【修改】

![修改商品入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/83f7e8edd9dd7457a1990f07f3ebc76d.png)

  1. 在商品列表中找到需要修改的商品。
  2. 点击该商品右侧的【修改】按钮。
  3. 在编辑页面更新商品信息。
  4. 点击【保存】完成修改。



**请注意**

修改商品价格后，**仅对之后新开的单据生效** ，不会影响已保存的历史单据，商品名称等基础信息的修改会同步更新至历史单据。
