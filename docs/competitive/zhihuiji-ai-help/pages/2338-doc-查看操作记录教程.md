# 查看操作记录教程

官方页面: https://www.zhihuiji.cn/help/doc/2338

视频描述

路径：任意界面里，点击软件右上角的账号信息，下拉框点击【操作记录】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/d52ce0e11a8c1592e669447eff16b4cd.png)

1.进入到操作记录界面，可以选择操作日期查看，也可以输入商品名称/单据编号/客户/供应商查询。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/51029d01a34b83d1dc065a39e0b448d4.png)

2.点击高级查询，可以选择操作人，操作端，操作模块，或者输入单据编号查询。

操作模块有：商品，套餐，客户，供应商，结算账户，销售单，销售退货单，销售预定单，进货单，进货退货单，进货预定单，收款单，付款单，收支单，盘点单，调拨单，转账单，组装拆分单，报价单，系统设置，初始化。

查询的结果可以显示操作人，操作模块，操作类型，单据编号，操作内容，操作端和操作时间。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/52d2200d2094fd8ce36691276f8b0adc.png)

注意；仅支持查看近180天内的操作记录。
