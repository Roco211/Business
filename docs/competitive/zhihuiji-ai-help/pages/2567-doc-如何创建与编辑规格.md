# 如何创建与编辑规格

官方页面: https://www.zhihuiji.cn/help/doc/2567

视频描述

**操作路径** ：【商品】→【规格管理】

  1. **新增规格** ：点击【新增规格】，输入名称（如“颜色”）和内容（如“黑”、“白”），完成编辑后点击保存



![新增规格界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e1f9f54bd7959eea59c3256da60c4e50.png)

  2. **修改规格** ：在规格列表中找到目标规格，点击右侧【修改】按钮，完成编辑后，点击保存



![修改规格界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/094b4e8a06bd8da5e2b49536c83de96d.png)

**核心价值** 统一管理商品属性，一次创建，多处复用。
