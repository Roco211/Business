# 开单自动新增商品

官方页面: https://www.zhihuiji.cn/help/doc/3151

**使用场景：** 新增单据支持输入新增的商品并自动保存到商品列表。（仅对销售/进货/报价/组装拆分的单据有效）

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202508/2c705682b79ab6f4c11b555987525d0e.png)

**备注：** 如果开单时不希望输入一些类似的商品名导致商品统计有误（比如心相印面纸巾，开单的时候输入心相印纸巾、心相印纸，实际都是同一个商品），可关掉此设置。
