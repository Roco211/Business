# 如何设置不让员工查看进货价/成本价？

官方页面: https://www.zhihuiji.cn/help/doc/3538

**路径：** 【设置】→【角色权限】→ 找到对应角色 → 点击【修改】

取消勾选以下权限：

  * **「进货价」**
  * **「成本价和利润」**



点击【保存】即可生效。
