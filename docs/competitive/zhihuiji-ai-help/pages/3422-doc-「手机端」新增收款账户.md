# 「手机端」新增收款账户

官方页面: https://www.zhihuiji.cn/help/doc/3422

**路径** ：【更多】→【资金】→【账户】→ 右上角【+】，输入账户信息后保存

**系统预设** ：现金、微信、支付宝

**可新增** ：自定义账户名称，如银行卡、信用卡、对公账户等其他收款方式 ![新增收款账户](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/93bfcfea50a797b9da9d1fe08f3d7853.png)
