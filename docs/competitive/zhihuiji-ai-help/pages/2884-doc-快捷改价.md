# 快捷改价

官方页面: https://www.zhihuiji.cn/help/doc/2884

操作路径：点击左侧栏【客户】-【报价管理】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/81cc491226a21b8eed00fa818a7a78b6.png)

输入商品名称查询，然后点击【快捷改价】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/07c9f2d077e14d7366026a26ffd5dfd7.png)

可以单独修改每个客户的价格

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/f455664b0eb8e7c324386735cb137f02.png)

或者勾选全部客户后，点击【批量改价】，可以选择按最新报价，进货价，原零售价，原批发价，上调或者下调百分之几的价格。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/2247a612ba9e751c33e290a90a6dfa9d.png)

设置好价格后点击【改价完成】即可。
