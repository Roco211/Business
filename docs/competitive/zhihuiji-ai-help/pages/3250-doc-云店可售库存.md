# 云店可售库存

官方页面: https://www.zhihuiji.cn/help/doc/3250

**云店库存展示：** 可售库存=系统库存-锁定库存

  * 系统库存：系统中商品关联云店仓库的合计库存；
  * 锁定库存：待接单/待支付/待发货/部分发货订单中的商品数量。



![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/23966ef7b000aea43c270eae6a92c1be.png)

**规则如下：** 1、下单占用锁定库存，继续下单累加锁定库存； 2、拒绝接单释放，库存自动还原； 3、发货时，系统库存和锁定库存同时变化，可售库存不变。
