# 如何查询保质期库存

官方页面: https://www.zhihuiji.cn/help/doc/2206

**操作路径：** 【库存】-【保质期查询】

进入页面后，您可以看到所有**已启用保质期且当前库存中录入了保质期信息** 的商品及其详细的效期信息，包括：

  * 生产日期、失效日期
  * 剩余有效天数
  * 库存



![保质期查询页面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/a836f233e0ef50946792f2b009a73061.png)

**1\. 如何筛选与查看**

  * 您可使用顶部的条件，按商品名称、仓库、剩余天数、保质期状态等快速筛选。
  * 点击商品行的【详情】，可查看该商品**在不同仓库的库存分布** 。



**2\. 核心条件说明**

要在此查看到商品，必须满足以下条件：

**(1)** 在商品资料中，已勾选【启用保质期管理】并设置保质期。

**(2)** 已通过【进货单】为该商品录入了生产日期。

![商品设置保质期](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/9e66ade5e8765af0f2f9bba46bdedcc8.png)
