# 新增业绩提成规格和绑定员工

官方页面: https://www.zhihuiji.cn/help/doc/893

视频描述  **新增提成规则**

**路径** ：【销售】-【业绩提成】-【业绩设置】-【新增规则】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/2548ed176d6411ffcb5093be7c441eb8.png)

**业务场景** ：制定业绩提成提成，能够更好的激励员工，提高工作的积极性，为店铺带来更好的效益

提成规则设定 **————————————————————**

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/5368df1a633688552f86c86b3db83874.png)

**规则名称** ：可自定义设定

**提成方式** ：可选择【按销售应收】或【按销售实收】或者【销售毛利】两种方式

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/c80a587afc20cefb3b11ee8e4628370e.png)

**分账金额** ：可勾选【扣除所含运费】，避免运费参与提成结算

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/777b8f6076a3e35a7849243592a73493.png)

**计算规则** ： 可选择【统一提成】，即输入固定提成比例（例如：6%）。 也可选择【阶梯提成】的形式，即区间计算提成（例如：设定业绩5000元以内，提成比例为5%，超出5000元的部分，提成比例为8%）

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/9aa05a158f6ad69786071768aba91269.png)

**超额奖励** ：启用后，可设置【超额目标】与【超额奖励】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/6103990fc51ec37d4b22e0b33c92cbfa.png)

**适用员工** ：可自行选择适用的员工（可多选）

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/bafc0c4346ad755abf07db7a0c5be12e.png)

**临时修改员工绑定提成规则**

**路径** ：【销售】-【业绩提成】-【业绩设置】-选择加入的提成规则-【修改】-【适用员工】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/ac518bf6123d0a2f2f7b73658a6195eb.png)
