# 进货单打印标签教程

官方页面: https://www.zhihuiji.cn/help/doc/2195

**使用场景：** 进货，商品入库前，商户核对完商品后，给所有进货的商品打印商品标签，贴完标签再入库，后续可以根据标签快速扫码开单。

**操作路径：** 库存-进货-新增进货单-保存。

（1）进货单详情左上角点击打印标签，若商品无条码，会自动生成随机条码；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/af47bacea27917bbf7327fd7af9c4665.png)

（2）勾选要打印标签的商品，勾选后点击下一步；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/8bb27fb2ea98ccc8323c941ffb5ad784.png)

（3）选择模板、打印机、打印份数，选好之后支持预览，点击打印标签即可完成打印；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/cd9677fc9f4b97e858bf42e0915333ae.png)
