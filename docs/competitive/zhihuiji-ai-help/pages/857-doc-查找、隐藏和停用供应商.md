# 查找、隐藏和停用供应商

官方页面: https://www.zhihuiji.cn/help/doc/857

**查找供应商**

**路径** ：【进货】-【供应商】

进入该页面，可看到所有的供应商名录；

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/345d34706f04afe6382d009e7d89fc9b.png)

右上角有个”查询“按钮，可以输入供应商名称，联系人，手机号以及备注信息来查找；

如输入联系人姓名”黄“，可出现对应的供应商。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/fdb71231ce7db8da3a48dcc02bd042bd.png)

**隐藏停用供应商**

**路径** ：【进货】-【供应商】

如有近期不再从那里进货的供应商，可以先做停用处理。

然后勾选左上角的”隐藏停用供应商“，那么在供应商列表中就不会再出现
