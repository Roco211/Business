# 销售统计教程

官方页面: https://www.zhihuiji.cn/help/doc/2074

视频描述

操作路径：点击【分析】-【销售统计】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/0ef667a4b0bc003e36e0fe629983fa03.png)

1.可以按单据/按商品/按客户分别统计销售额和利润。

2.可以输入单据日期，门店，客户名称，单据编号，营业员查询。

3.点击【导出】可以导出统计报告的信息。

4.点击【详细】可以看到单据的详细内容。
