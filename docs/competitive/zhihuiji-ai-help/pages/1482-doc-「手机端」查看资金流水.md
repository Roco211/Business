# 「手机端」查看资金流水

官方页面: https://www.zhihuiji.cn/help/doc/1482

**操作路径** ：首页【更多】→【资金】→【资金流水】

  * **按门店筛选** ：若已开启多门店，可查看指定门店流水
  * **按日期筛选** ：支持按**日、周、月** 切换查看周期
  * **实时同步** ：所有收支记录与电脑端实时同步，便于对账
