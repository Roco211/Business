# 主辅单位的换算原理

官方页面: https://www.zhihuiji.cn/help/doc/915

【主辅单位、多单位、换算率、修改】
**Q：** 能不能加个多单位？如何设置主辅单位？一大箱里有20小瓶果汁，如何设置？

答：勾选“支持多单位”才能使用主辅单位。开通主辅单位，方便您在开销售单/进货单时能自动计算价格，比如按箱或按瓶计算。以下是使用要点：

  * （1）例如：一整箱里有20小瓶果汁：一整箱=20小瓶果汁，设置主单位“小瓶” ，；辅单位“整箱”，换算率为20；若每小瓶果汁1元，则一整箱果汁20元=1元*20小瓶；——开单进货1整箱果汁时，价格会自动变成20元

  * （2）统计报告：全部自动转成主单位统计查看。上面的例子，统计报告仍显示为进货数量20小瓶果汁，而不是箱数1；

  * （3）换算率：以主单位为主，即填入需要多少个主单位数量，才能构成一个完整的辅单位。比如需要20小瓶（主单位）果汁，才能构成完整的一整箱（辅单位）果汁。注：换算率是固定数值，填入整数或者小数，且不能随意修改。




![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/b0a958d88fb1c7ecba9b368629928d03.png)
▲填入主辅单位，换算率填入整数或者小数数值。

**Q：** 单位：整件，辅单位：小瓶，换算率：12小瓶=一整件，换算率能像这样按照单件啤酒进行设置吗？

答：错误，换算率必须填入有限的整数或者小数数值。正确的换算率公式：主单位÷辅单位=1÷12=0.08333...为无限小数，以主单位为主，即数量为0.08333...的整件啤酒，才相当于1小瓶啤酒。

  * （1）若如题，设置主单位是大单位“整件”啤酒，按整件统计，则换算率0.8333...是除不尽的，而统计报告默认以主单位“整件”统计啤酒数量，数据就会有误差；

  * （2）为了数据准确性，建议设置主单位是小单位“小瓶”啤酒，按小瓶统计，则设置：主单位“小瓶” ，辅单位“整件”，换算率=12÷1=12；统计报告默认以主单位“小瓶”统计，数据准确。
