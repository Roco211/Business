# 客户预存款的调整和抵扣

官方页面: https://www.zhihuiji.cn/help/doc/1748

视频描述

**用户场景** ：为了减少交易风险，批发商户会要求客户提前支付一部分金额，这笔金额在后续开单、收款的时候可以抵扣单据金额和欠款。常见叫法包括：预存款、预收款、预付款、订金。

**功能介绍** ：在客户管理中存入客户的预存款，并在销售开单、收款时可以抵扣单据金额和客户欠款。

**目标客户** ：面向全部客户，常见于食品，建材，服装，五金，农资

**其他** ：可满足零售商户商户先储值，再消费的场景

1.操作步骤：点击客户-查看-去存款。输入存款金额，结算账户，确定。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/d128ad76f83a58e9e7aa7197141f981c.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/948d584c54ee3aea455e2ab93e030c68.png)

点击存款的金额可以查看到存款和消费记录。也可以点击调整，调整当前的存款金额。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/3e9b9931f0c76662229ce063177eb169.jpg)

2.销售单可以用客户的预存款抵扣单据金额。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/9683199a1cc3335f412ed4ce9c38b0ee.jpg)

3.在收款单中，可以使用预存款抵扣客户欠款或结清单据

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/a39f4ad33de22643ecffd5fba46f509f.jpg)
