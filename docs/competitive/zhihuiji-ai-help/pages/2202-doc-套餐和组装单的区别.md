# 套餐和组装单的区别

官方页面: https://www.zhihuiji.cn/help/doc/2202

智慧记AI进销存套餐和组装单的区别：

**1、业务场景不同。** 套餐偏营销，套餐中的商品本身都是独立可售卖的个体，只是组合在一起打包售卖；而组装偏生产转化过程，组装前的商品可能都不会单独售卖，只有组装在一起才有意义；

**2、开单方式不同。** 销售开单时选择套餐，套餐内商品库存自动减少；而组装需单独做组装单，不支持销售时自动增减组件和子件库存；

**3、组装过程可能会产生额外的加工费** （焊接、人工等），会计入成本，而套餐没有。
