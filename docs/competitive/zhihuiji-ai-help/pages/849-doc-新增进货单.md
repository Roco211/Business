# 新增进货单

官方页面: https://www.zhihuiji.cn/help/doc/849

新增进货单

**操作路径：** 【进货】→【进货】→【新增进货单】

**操作步骤：**

  1. **选择供应商**
选择供应商名称，点击“+”可快速新增供应商。
![选择供应商](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/3ad9bcf6db50fb4823aa46f10edfcaf7.png)

  2. **选择仓库**
若已启用多仓库，可为每个商品分别选择仓库。
_注：可通过[“设置-用户偏好设置”](https://www.zhihuiji.cn/help/doc/3388)设置进货单的默认仓库。_
![选择仓库](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/891667761421fcd3c3a9e22bf9806caf.png)

  3. **添加商品**
支持以下两种方式：



  * **手动添加** ：扫码或点击商品名称空白处添加。
![手动添加](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/73f4204c874274260ac43ea040e120ea.png)
  * **导入添加** ：下载模板 → 填写商品信息 → 上传文件 → 确认导入。
_注：请勿修改模板表头及文件格式。_
![导入模板](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/3b79193cc62b3e3ad023302415d759fc.png)
![导入界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/44a80704c65ba8e653a30db0ae30073a.png)


  4. **填写数量与价格**


  * 手动添加的商品：需在页面中输入数量和进货价。
  * 导入添加的商品：可在模板中预先填写数量和进货价。


  5. **保存单据**


  * 点击【保存】：直接保存单据；
  * 点击【保存并打印】：保存的同时打印；
  * 勾选左下角「保存后继续开单」可连续开单。
![保存选项](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/e9d25548c34e73b89f9ba7a22977445b.png)
