# 用新商品开单

官方页面: https://www.zhihuiji.cn/help/doc/1570

**新商品开单**

极致开单——没有录入过的商品，在开单时可以直接在销售单新增该商品；

减少跳转至新增商品操作步骤，提升开单速度；

**操作路径** ： 【销售】-【新增销售单】-直接输入商品名称- 如果是没有创建过的商品，会显示【新商品】标签，再依次输入 规格-单位-仓库-数量-单价 等信息，**开单的同时，即可创建新商品** 。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202209/9519095486864c1bf060e9c10cf45cfd.jpg)

**注意！** **开单创建的商品默认成本为0，需要做进货单后才会重新计算成本**

**若开单角色无新增商品权限，则不能在开单时创建商品**

**开单创建的商品只支持单规格**
