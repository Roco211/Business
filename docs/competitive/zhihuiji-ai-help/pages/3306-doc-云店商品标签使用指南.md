# 云店商品标签使用指南

官方页面: https://www.zhihuiji.cn/help/doc/3306

视频描述

## 功能简介

云店商品标签功能，支持您为商品打上自定义标签（如“清仓专区”、“爆款推荐”），从而在云店首页（专属版）或选购页中，灵活配置并展示这些带标签的商品，打造个性化的营销专区。

**请注意** ：本功能仅对已开通云店的用户开放。

![云店商品标签功能路径与选购页预览](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/0b951917d5ffb0e742eb50e98ede1a0c.jpg)

## 使用流程

### 创建与管理标签

**新建标签并添加商品**

  * **操作路径** ：【商品】-【云店商品标签】
  * 点击 **【新增商品标签】** 。
  * 输入标签名称，并直接选择需要加入该标签的商品。
  * 点击 **【确定】** 完成创建。



![新增商品标签按钮位置](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/7286149bec9d764384d16b01edd7d8d0.png) ![输入商品标签名称弹窗](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/f65ae86ed5fddf0ab72db2abd4fe1bb3.png) ![选择要加入标签的商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/a20ef066de5f6ab097dd9437dcefd786.png)

**管理已创建的标签**

在标签列表中，可对已有标签进行 **【编辑】** （修改名称）或 **【删除】** 操作。

![编辑与删除标签按钮位置](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/bc1f92eeb1fa1fd1cba8c10e793d859a.png)

### 管理标签与商品的关联

**单个商品设置/修改标签**

  * **操作路径** ：【商品】-【商品】
  * 在新增或修改商品时，于编辑页面直接选择 **云店商品标签** 。



![单个商品编辑页面选择标签](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/d47473823e26f541108e3df79c2136bb.png)

**批量修改商品标签**

（1）在商品列表，勾选目标商品或利用查询条件筛选。

（2）点击 **【批量操作】** -> **【修改云店商品标签】** 。

（3）在弹窗中：

选择 **【批量添加标签】** 或 **【批量删除标签】** 。

可选择已创建的标签，或直接 **【新增商品标签】** 。

（4）点击 **【确认】** 完成。

![批量修改路径](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c014f8ab7edafc9f71862f6e8c60bcac.png) ![批量修改标签操作弹窗](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/885ca18cd42efd943ca4fd78bfe256c8.png)

**按标签查询商品**

在商品列表，支持通过 **云店商品标签** 条件筛选查看商品，商品列表页也会展示商品已关联的标签。

![按商品标签筛选与列表展示](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/9d0eb458863e9e7b915bf076e6555594.png)

### 在店铺中展示标签商品

**在选购页展示**

对指定标签启用 **【选购页展示】** 后，该标签及其商品将展示在云店选购页的顶部。

![选购页展示设置开关与预览效果](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/564c32456e6bf6662bc93a318be9df59.jpg)

**在首页展示（仅限云店专属版）**

在进行 **[首页装修](https://www.zhihuiji.cn/help/doc/3304)** 时，您可以通过以下方式展示标签商品：

  * 在海报或导航组件中，设置跳转到指定的标签页面。
  * 添加 **“商品”** 或 **“商品分组”** 组件，选择按 **“标签”** 展示对应专区的商品。



![首页装修时选择标签与预览效果](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/889ec52dc4c7be19f95218c53dc76fe6.jpg)

### 调整标签商品排序

  * **操作路径** ：【云店】-【云店商品排序】
  * 选择目标标签后，可对其下的商品进行**拖拽排序** ，或使用 **【置顶】** 、**【置底】** 功能快速调整顺序。



![云店商品排序功能路径与操作界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/8ad2bbb1bab82ec5db5e0ec6a6fd62de.png)
