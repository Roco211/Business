# 如何设置员工可查看所有客户

官方页面: https://www.zhihuiji.cn/help/doc/3501

> 适用于已在【系统设置】中勾选“启用关联业务员”功能的商户。

如需设置部分员工可查看所有客户的客户信息，可通过角色权限实现。

**操作路径** ：【设置】→【角色权限】→ 新增或修改员工的角色 → 在「敏感数据」→「客户权限」中，勾选【查看其他业务员/用户关联的客户】→ 保存即可。
