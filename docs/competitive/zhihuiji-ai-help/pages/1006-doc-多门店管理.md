# 多门店管理

官方页面: https://www.zhihuiji.cn/help/doc/1006

多门店管理教学视频

通过启用多门店功能，您可以将不同门店和仓库的库存分开管理，并独立核算各门店的账户与业绩。

## 📌 关于多门店模式

本系统支持的是**连锁模式** ，即：

  * **商品全域互通** ：所有门店共享同一套商品库，无需（也无法）将商品设置为归属于某个特定门店
  * **库存分开管理** ：商品是全域的，但库存可按门店独立管理（各门店有自己的库存数量）
  * **数据集中管控** ：总部可查看所有门店的经营数据，进行统一分析和决策



> 如果您需要的是**独立多店模式** （各门店商品库相互隔离、独立经营），请购买两个单店版来管理。

## 开启多门店功能

**操作路径** ：前往【设置】->【系统设置】->【基础设置】，勾选【启用多门店】。

>   * **适用版本** ：此功能仅限**多店版** 用户使用。
>   * **重要提醒** ：启用后，若您已创建门店并产生业务单据，将无法直接关闭多门店。如需关闭此功能，您需要先删除所有额外创建的门店（包括作废门店关联的全部单据），之后即可取消勾选。
>

## 创建新门店

**操作路径** ：前往【设置】->【门店管理】，点击左上角的【新增门店】按钮，填写门店信息即可完成创建。

![新增门店流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/b79c58ceb4ff1e8b64ff2ed1ab421f43.png)

## 门店的实际应用场景

创建门店后，您可以在以下场景中应用，实现精细化管理：

### **💰 财务对账**

在【资金概况】中为不同门店设置独立账户。开单时选择对应门店账户，系统将自动记录流水，方便您随时查看各门店的账户余额和收支明细。 ![财务对账流程图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/dc4fa8049672a945ff4c37427168135d.png)

### **📦 库存与出入库**

  * 门店即仓库：门店本身会作为库存出入库的一个单位，出现在仓库列表中，可直接用于出入库操作。
  * 关联仓库：若启用了多仓库功能，您可以在创建仓库时设置其关联的门店。开单选择仓库时，列表中会同时显示
    * 门店（作为独立的库存单位）
    * 关联了当前门店的仓库



![门店的应用](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/4ea8d8bc4be124f995c50fe863312eca.png)

### **📊 数据筛选与分析**

在【分析】模块的各项报表中，您可以筛选门店，快速查看特定门店的经营数据，便于横向对比和业绩考核。 ![数据分析筛选截图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/5c4163ed81a2426642e9a57e1a8c9832.png)

### **👥 员工权限管理**

在设置员工权限时，可以指定其所属门店。被授权的员工在开单时，只能选择其所属门店及关联仓库。同时，他们在查看账户概览时，也仅能看到有权限的门店账户信息，保障数据安全。 ![设置员工的门店与仓库权限](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/d5980f18d9840b56e1e4e1e1e3836a36.png)

## 管理与维护门店

您可以在【设置】->【门店管理】的门店列表中，对已有门店进行管理。

  * **✏️ 修改门店信息** ：点击门店右侧的“修改”按钮，可以随时更新门店的名称、地址、电话等信息。
  * **🗑️ 删除门店** ：点击门店右侧的“删除”按钮即可移除门店。
    * **⚠️请注意** ：如果该门店已经产生了销售单据或入库记录，将无法直接删除门店。您需要先处理（如作废）关联的所有单据后，才能执行删除门店操作。 ![管理门店](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/b83d171ae31bdb7a0fd12e25f4a9ecf7.png)
