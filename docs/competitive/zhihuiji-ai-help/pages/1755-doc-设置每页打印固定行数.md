# 设置每页打印固定行数

官方页面: https://www.zhihuiji.cn/help/doc/1755

**用户场景：** 当商品较少时，纸张很空，不美观，想要通过设置行数来控制位置

**操作步骤：**

1、设置-打印设置-选择打印模板进入到打印模板编辑器，然后点击表格，右侧信息设置-勾选固定行数和行高。然后设置每页固定打印的行数和行高。

2、设置好的行数，会直接显示在画布中。

3、设置行高后，超过行高的内容会被系统截断；
