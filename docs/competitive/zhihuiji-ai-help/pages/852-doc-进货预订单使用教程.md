# 进货预订单使用教程

官方页面: https://www.zhihuiji.cn/help/doc/852

视频描述  **新增进货预订单**

**路径** ：【进货】-【进货预订单】

1.先选择供应商，如没有可直接新增

2.选择对应的商品，可直接点击商品名称的空白处来添加，输入对应的数量，自动算出金额

3.点击“保存”即可；点击“保存并新增”可接着开进货订单。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/1fb8658cad0782fd2ce7abf5dd54d463.png)

**进货订单转进货单**

**路径** ：【进货】-【进货预订单】

【查看】：点开可查看详情，点右小角的“转进货”，即可由进货订单专为进货单。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/5fb7615136191502867145a397842088.png)

转成进货单后，若有变动，可直接修改进货单。

注意： 1，若进货预定单已转为进货单，进货预定单列表，此单据会显示已完成， 点击【查看】发现已无法作废该进货预定单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202402/2c89abf40b62113483b7463eebf4c4ea.png)

2，若作废进货单，原先的进货预定单不会因此被一同作废。

**作废进货预订单**

**路径** ：【进货】-【进货预订单】

可以对进货订单进行查看、复制与关闭操作。

【作废】：点击“作废”，会再次提醒是否真的废弃，点击“确认”即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202402/ff467f16377aba56b5883d11890a4f76.png)
