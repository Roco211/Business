# 云店客户访问提示“抱歉,您无法访问该店铺”

官方页面: https://www.zhihuiji.cn/help/doc/3293

云店客户访问提示 **“抱歉,您无法访问该店铺”** ，如下图所示：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/ef810234e1d4ac61f991219a0683748a.png)

**解决方案：** 在云店客户列表里面找到对应的客户，检查是否停用，停用的客户会无法访问云店，重新启用就可以

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/7b713f55791cd939d2c109f61057c9ca.png)
