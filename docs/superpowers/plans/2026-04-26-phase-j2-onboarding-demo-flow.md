# Phase J2：新手引导与一键演示流程

## 背景

Phase I 已完成 AI Command Center、AI Task Flow、AI 员工真实状态、AI 经营日报；Phase J1 已完成审批后的 AI 执行复盘。

当前缺口是：第一次进入系统的老板虽然可以看到很多 AI-native 能力，但还需要自己摸索点击顺序。J2 要把完整闭环包装成一个可理解、可执行的商用试运行引导。

## 目标

- 在首页提供清晰的“老板一分钟体验流程”。
- 用真实现有能力串联：经营查询 → 生成销售草稿 → 去任务中心确认 → 查看执行复盘 → 回到首页刷新经营状态。
- 新手引导按钮可以跳转到该流程位置，而不是装饰性按钮。
- 保持 confirmation-first：一键演示只能生成草稿和引导确认，不能绕过老板确认直接落账。
- 不伪造订单、客户、库存、财务数据。

## 非目标

- 不新增后端表。
- 不新增自动审批接口。
- 不引入假订单/假客户/假经营数据。
- 不做完整产品帮助中心。

## 实施范围

1. H5 首页新增 OnboardingDemoFlow 卡片。
2. TopBar “新手引导”按钮滚动/跳转到演示流程。
3. 演示流程提供 4 个阶段：
   - 查今日营业额
   - 生成销售草稿
   - 去任务中心确认
   - 看执行复盘并刷新首页
4. 演示流程可调用已有 `api.chat` 与 `api.createSalesOrderDraft`。
5. 生成销售草稿后展示 confirmation_id，并提供“去任务中心确认”。
6. 样式保持 dashboard.jpg 浅色、紫色、圆角卡片风格。

## 安全边界

- 演示流程只允许创建 pending confirmation。
- 审批仍必须在任务中心由老板点击“确认并执行”。
- 执行复盘只来自 J1 后端真实 approval 响应。
- 所有数据仍通过现有 auth/context/tenant/shop 隔离 API。
