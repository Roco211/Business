# 删除和停用客户

官方页面: https://www.zhihuiji.cn/help/doc/888

**删除客户**

**业务场景** ：日常业务中，不慎添加了错误的客户，需要对客户进行删除。

**路径** ：【首页】-【客户】-找到客户-【删除】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/b382dcd7d576e3e51494b6cf0dd31485.png)

**功能说明** ：

1、删除客户时，需要先处理完所有关联单据后，包括检查5大模块：销售订单、销售单、收款单、收支单。参考：<https://www.zhihuiji.cn/help/doc/3298>

2、删除客户时，提示“已关联单据，不允许删除”，说明仍未全部删除业务单据。

**停用客户**

**业务场景** ：实际业务上不需要用到的客户，但是不想删除业务单据，仍然保留客户资料。停用客户，能够减少开单时冗余客户选择的干扰。

**路径** ：【首页】-【客户】-找到客户-【停用】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/06e3a615d1cabf5336e8e7c742a0b39c.png)

**功能说明** ：

1、停用客户，不会影响到已保存的单据欠款。

2、停用客户，可以批量停用/启用
