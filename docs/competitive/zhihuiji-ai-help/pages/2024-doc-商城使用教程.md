# 商城使用教程

官方页面: https://www.zhihuiji.cn/help/doc/2024

**路径：** 左侧导航栏 → 【商城】

* * *

## 商城概览

进入商城页面后，可查看：

  * 当前订阅的**版本** 及**有效期**
  * 可订阅的**应用** 和**硬件**



点击 **【立即续费】** 可跳转至购买页面。

![商城页面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/59ebfda6d82b5dba2a9a335ce1c86f0b.png)

* * *

## 我的服务

点击 **【我的服务】** ，可查看已订阅的服务，可按状态筛选：

  * **全部服务**
  * **生效中**
  * **已失效**



**操作说明：**

  * 点击右侧 **【详情】** ，可查看购买的订单单号
  * 点击 **【续费】** ，可跳转至对应服务的购买界面
