# 批量启用保质期管理

官方页面: https://www.zhihuiji.cn/help/doc/3341

**操作路径** ：【商品】-【商品】-【批量操作】-【启用保质期管理】

**操作前确认**

请确保您已在【设置】-【系统设置】-【商品设置】中，勾选了【启用保质期管理】。

**批量设置步骤**

  1. **选择商品范围** ： 在商品列表勾选目标商品，或通过筛选确定范围。
  2. **进入批量设置** ： 点击顶部【批量操作】，选择【启用保质期管理】。



![批量启用入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/6c9bc83240105be95cc6c0e953128d47.png)

  3. **设置统一规则** 在弹窗中依次设置：
     * **生效范围** ：选择“只修改选中商品”或“修改当前查询条件下的所有商品”。
     * **保质期** ：填写正整数并选择单位（天/月/年）。
     * **预警（可选）** ：勾选“启用预警”并设置提前预警天数，了解[如何查看保质期预警](https://www.zhihuiji.cn/help/doc/3345)。



![批量设置弹窗](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/78cbfcca3515ea62f7971e94f334a286.png)

  4. **点击【确定】**



系统将为所选商品统一启用保质期管理并应用设置。

**核心价值**

一次性为多个同类商品（如所有饮料、所有调料）完成保质期设置，极大提升初始化效率。
