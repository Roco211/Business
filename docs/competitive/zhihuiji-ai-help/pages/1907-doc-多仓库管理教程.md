# 多仓库管理教程

官方页面: https://www.zhihuiji.cn/help/doc/1907

视频

先在开启多仓库后才能显示仓库管理界面。

路径：设置-系统设置-勾选启用多仓库。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/7e982afdf4cc106a5632a6c6e942cf03.png)

新增仓库：点击设置-仓库管理-新增仓库，仓库名称和关联门店是必填的。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/de2cab7a673e363725e859b3c2af5b9f.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/7d190eb043feb6854bc1997aa1009ba4.png)

修改仓库:点击仓库名称后面的修改按钮，即可修改仓库信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/0776f3b19965e23d8b85113dac894ea1.png)

删除仓库：点击仓库名称后面的删除按钮，该仓库没有被使用过才支持删除。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/f7a63672f3e21732ab305cd0156e1b29.png)

权限配置：管理员默认拥有全部仓库权限，如需给其他员工添加仓库权限，可通过设置-员工管理，修改员工的仓库权限。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/6620fd7b70325315e59d77f3f71cc6ba.png)
