# 设置用户的默认打印模板

官方页面: https://www.zhihuiji.cn/help/doc/3391

每个用户可独立设置自己的销售单默认打印模板。

**操作路径：** 【设置】→【用户偏好设置】→【销售时，支持设置默认打印模板】→ 启用后选择打印模板

**说明：**

  * 此设置仅对当前登录的账号生效。
  * 若未单独设置，打印时将使用【设置】→【打印设置】中为销售单设置的全局默认模板。
