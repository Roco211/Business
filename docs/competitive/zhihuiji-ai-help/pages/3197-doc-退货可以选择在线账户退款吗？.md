# 退货可以选择在线账户退款吗？

官方页面: https://www.zhihuiji.cn/help/doc/3197

退款单可以选择在线账户退款吗？ 答：扫码收银的销售单，不支持作废；退货也无法选择在线账户原返，只能线下给客户，比如微信转账。
