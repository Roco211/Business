# 进货退货：新增与作废

官方页面: https://www.zhihuiji.cn/help/doc/854

视频描述

**进货退货**

**路径** ：【进货】-【进货退货】

1.选择供应商名称，点击“+”可直接新增供应商

2.选择退货的商品，可以扫码添加，也可以鼠标点击商品名称的空白处添加

3.添加商品的退货数量，将显示负数；对应的付款金额为负数，即对方要退钱到我方账户

4.点击“保存”即可保存单据；点击“保存并新增”可接着继续开进货退货单。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/e98a5f37209f543b087cb89f2fa1ff29.png)

**进货退货单的作废**

**路径** ：【进货】-【进货退货】-【查看历史单据】

找到对应的单据，可对单据进行相关操作。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/07aebb952d564b30ae231a729b9acab6.png)

【作废】：点击作废，可作废该进货退货；

需要注意的是，废弃单据需要和关联付款单一起作废。
