# 复制进货单

官方页面: https://www.zhihuiji.cn/help/doc/3386

通过此方法可快速创建一张与历史单据内容相似的进货单，适合本次进货商品与上次类似时使用。

**操作路径：** 【进货】→【进货】→ 在目标单据右侧点击【查看】→ 在单据详情页点击【复制】→ 确认或调整信息 →【保存】

**操作图示：**

  1. 点击【查看】进入进货单详情页
![点击查看按钮](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/c27e5655fd7389853fd60e38446c73d4.png)

  2. 点击【复制】按钮 ![点击复制按钮](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/de35cf433fd2822b1a7d21f1a6de5690.png)

  3. 调整信息后保存单据
![点击保存](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/025b6baab859dc2d67d6aca677e0f38f.png)
