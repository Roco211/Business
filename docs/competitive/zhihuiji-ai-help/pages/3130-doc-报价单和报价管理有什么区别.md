# 报价单和报价管理有什么区别

官方页面: https://www.zhihuiji.cn/help/doc/3130

**报价单场景：** 由卖方向买方提供的一份正式文件，用于详细列出产品的名称、规格、价格等信息，作为交易前的价格参考和协商依据。协商一致再转销售订单或者销售单，进入正式的交易流程。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/b29d4e578a67f68186ef38a097f0c039.png)

**报价管理场景：** 提前设定好不同客户对应的不同商品价格，做销售单时会自动带出提前设定好的价格，类似于大客户报价。
