# 主体信息为空或校验不通过

官方页面: https://www.zhihuiji.cn/help/doc/3325

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/1b082ff2186c1c25e062671161bd4dc6.png)

**解决方案：** 请核对下以下信息后重新提交申请。

**1\. 请检查营业执照图片** ：已完成上传；如果已上传，通常是图片自动识别有误；

**2\. 需仔细检查统一社会信用代码/主体名称：** 正确填写且无字符错误（如0与O/Q、1与I等）或多余空格，包括括号内的补充信息（如“xxxx(个体工商户)”）；

**3\. 工商信息完全一致：** 法定代表人信息与工商登记完全一致、营业执照信息与注册信息完全匹配。

**4\. 更换浏览器或隔天再试。**
