# 「手机端」开销售单

官方页面: https://www.zhihuiji.cn/help/doc/1260

视频教程

**操作路径：** 首页【销售开单】→ 选择客户 → 添加商品 → 【收款】或【保存】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/03344116b7e97667c80fc3f54edee03c.png)

**保存后支持操作：**

  * **再来一单** ：继续开销售单
  * **立即发货** ：将当前销售单标记为已发货
  * **打印** ：打印当前销售单
  * **分享** ：分享当前销售单给客户
  * **查看详情** ：进入详情页进行修改、作废、标记开票、复制等操作



![销售单详情](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/dd44d10b953e48b8da5af546b35736a9.png)
