把 `project_docs` 压成一张可审产品壳层、AI 控制平面、业务真相层和交付路径的总控台。

一句判词 前台像微信群，后台像受控操作系统。

要审的不是“会不会聊天”，而是它能不能把语音、多模态、确认、库存和审计稳稳串起来。

React Native + Expo + FastAPI + MySQL + Celery + WebSocket

从上帝视角审视这个原型，而不是只看几张漂亮页面

这个 showcase 不再是“项目介绍站”，而是把产品定位、页面壳层、AI 员工体系、接口合同、 数据真相、交付节奏和真实实现现状压到一张总控图里，让你能同时看见它已经成型的部分和仍停留在蓝图里的部分。
