# 调拨单

官方页面: https://www.zhihuiji.cn/help/doc/2704

## 新增调拨单

路径：点击右下角的【更多】-【调拨】-右下角【调拨】-选择调出和调入的仓库或者门店，然后选择调拨商品，输入调拨数量后点击完成即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/c024b30e30a14a2ee371ef6b2886da17.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/c34ffef729868370f6a8913551fd8013.png)

## 修改调拨单

路径：点击进入到调拨单详情界面，然后点击底部的【修改】按钮，即可修改调拨单的商品信息。

注意：调出和调入仓库不支持修改。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/93f969ac24d1642ffe6222daac1c6034.png)

## 作废和复制调拨单

路径：点击进入到调拨单详情界面，然后点击右上角的【...】，然后点击底部的【复制本单】和【作废】按钮，即可复制调拨单和作废单据。
