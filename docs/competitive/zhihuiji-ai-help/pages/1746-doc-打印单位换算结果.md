# 打印单位换算结果

官方页面: https://www.zhihuiji.cn/help/doc/1746

**用户场景：** 销售单增加换算结果，方便打印单据用来出货点货的。

**操作步骤：**

1.设置-打印设置-选择要设置的销售单模板。点击表格，出现蓝色的虚线边框就说明选中了，然后右侧勾选单位换算结果。点击“？”可以看到字段说明。

2、勾选后，打印若有辅单位的商品，会显示主辅单位之间的换算结果，仅支持显示辅单位。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/42eb87243c2cfb7e2286cf67632aea82.jpg)

例如：卫龙 亲嘴软豆皮(豆品) 60g的辅单位是件，1件=12包。开销售单数量是30包，换算成辅单位就是2件6包。
