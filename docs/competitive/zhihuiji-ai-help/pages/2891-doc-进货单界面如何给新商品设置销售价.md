# 进货单界面如何给新商品设置销售价

官方页面: https://www.zhihuiji.cn/help/doc/2891

当进货单有录入新商品时，可以在进货界面快速输入新商品的销售价格。

1.操作路径：左侧栏进货-再点击进货旁的+号-输入新商品名称-右上角新品定价

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/71e26f7d35c27fe7dce30eeb685fbe08.png)

2.新品定价界面可以输入新商品的各个等级价格。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/e0be0ddd798cddbb80354c269da60a46.png)
