# 调拨单教程

官方页面: https://www.zhihuiji.cn/help/doc/1983

视频描述

## 1.新增调拨单

路径：点击左侧导航库存-调拨右侧的+号，或者点击库存-调拨-新增调拨单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/b8c290d95b77f4865f154d718db5ac7b.png)

## 2.调拨单详情

新增调拨单保存成功后会显示调拨单详情界面，可以点击修改，作废，复制，查看历史单据。还可以导出到PDF和打印。也可以点击修改备注和上传单据图片，最多能上传5张图片。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/2ce5038ece2e8d935c5d186c8243a22d.png)

## 3.调拨单列表

点击库存-调拨可以进入到调拨单列表界面。可以按照单据日期，单据编号，调出或者调入仓库/门店，调拨人，商品名称和备注查询，也可以点击导出调拨单明细。右侧可以查看，修改和作废调拨单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/f30083b0aa323e9c2b2a78c179a6f3ce.png)
