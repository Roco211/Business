# 作废进货单

官方页面: https://www.zhihuiji.cn/help/doc/3387

当您制作了错误的进货单时，可通过此功能作废单据。

**操作路径：** 【进货】→【进货】→ 列表右侧操作栏点击【作废】→ 确认作废

**注意事项：**

  * 作废后单据将无法恢复，请谨慎操作。
  * 若进货单已关联付款单，系统会提示您选择处理方式。



**操作图示：**

  1. 点击【作废】按钮
![点击作废按钮](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/cee72a9ceea4400429e4cc3cbb4cf841.png)

  2. 确认作废操作
![确认作废](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/833ce3a34b866150746a8a9fc891f0b0.png)

  3. 已关联付款单的处理选择（如出现）
![弹窗选择](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/1a8dcc68dc2a5593679529dd5b1584b9.png)




**关联付款单处理说明：**

  * **转为预付款** ：仅作废进货单，付款单保留为预付款，后续可重新关联其他单据。
  * **一起作废** ：同时作废进货单及关联的付款单（仅当两者金额完全一致时可操作）。
  * **取消** ：放弃本次作废操作。
