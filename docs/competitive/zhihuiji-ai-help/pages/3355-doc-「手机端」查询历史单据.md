# 「手机端」查询历史单据

官方页面: https://www.zhihuiji.cn/help/doc/3355

**操作路径：** 【销售】- 使用筛选与搜索

开单后，所有销售、预订、退货单据均统一在【销售】模块中管理。您可以通过以下方式快速查找：

  1. **切换单据类型** ：在【销售】列表页顶部，通过点击或左右滑动，在**销售单、预订单、退货单** 之间切换。
  2. **搜索单据** ：在顶部搜索框中，可直接输入**单号、客户名称、商品名称或备注** 进行查找。也支持**扫描商品条形码** 来查找单据。
  3. **筛选单据** ：点击搜索框右侧的筛选图标，可按**日期、客户、门店、业务员、单据状态（如待发货、已结清）** 等多种条件组合筛选，精准定位目标。
**请注意** ：系统默认隐藏“已作废”单据，如需查看，请在筛选条件中将“隐藏作废单据”改为“不隐藏”。



![查询单据流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/f70a0d57a2f5949c3ad348d87e5288cf.png)

找到目标单据后，直接点击即可进入详情页，进行查看、分享、打印、修改、复制、作废等操作。
