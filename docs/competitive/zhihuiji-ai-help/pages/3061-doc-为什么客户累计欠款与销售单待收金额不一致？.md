# 为什么客户累计欠款与销售单待收金额不一致？

官方页面: https://www.zhihuiji.cn/help/doc/3061

客户累计欠款与销售单待收金额不一致： ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/0150ac150db4789538bf7f09779d30b9.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/f0d1e13b6b4359615b3b42d77fbc0fd6.png)

原因是：**客户列表的客户欠款=客户对账单累计欠款=客户初始欠款+销售单待收金额-未按单收款的金额+调整单调整的金额** （注：未启用「客户/供应商双身份」）

客户累计欠款与销售单待收金额不一致可检查以下页面：

1、客户详情检查是否有初始欠款 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/d056b9d33639697a9d4e9bb158e1ca81.png)

2、收款单未按单收款的金额，有两种情况：

①单据是直接收款，未关联单据，那么收款的金额需从欠款金额减去； ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/d4ce2eeddac94840b20dbf7b9bd60b7f.png)

②单据是按单收款，已关联单据，但是收的金额大于单据合计金额，那么多出来的钱也需从欠款中减去 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/df5c03c611c66b9390949cbd3f5302ae.png)

3、调整单：通过客户详情可以直接调整欠款金额，会生成调整单 可以在客户对账单明细中，查找“调整单”类型的记录，欠款金额为正数就是增加欠款，负数就是减少欠款
