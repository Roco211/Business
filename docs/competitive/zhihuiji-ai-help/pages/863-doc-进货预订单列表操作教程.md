# 进货预订单列表操作教程

官方页面: https://www.zhihuiji.cn/help/doc/863

视频描述

**进货预定列表**

**路径** ：【进货】-【进货预订】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/6d236e8c4b4479e710e7066384d8b530.png)

**查看/复制/关闭进货订单**

**路径** ：【进货】-【进货预订】

1.可通过筛选单据的日期、供应商名称、单据编号、商品名称，来查询具体某一个单据。

2.在对应的单据右侧有”查看““复制””关闭“操作

（1）查看：点开可查看具体信息

（2）复制：可以复制一张相同的进货订单。如果本次进货订单和之前类似，就可以直接复制或简单修改，快速完成进货订单

（3）关闭：关闭进货订单后，就无法转进货单。相当于作废该单据。

3.可勾选是否”隐藏作废单据“。
