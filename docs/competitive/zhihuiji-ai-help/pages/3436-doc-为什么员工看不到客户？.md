# 为什么员工看不到客户？

官方页面: https://www.zhihuiji.cn/help/doc/3436

员工账号有查看客户权限，但登录后看不到全部客户，通常是因为启用了 **“关联业务员”** 规则。

* * *

## 检查与说明

**检查路径：** 【设置】→【系统设置】

若勾选了「启用关联业务员」，员工默认只能查看**已关联给自己的客户** 。

![系统设置](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/399268ac3406c1608a59df8459407ffc.png)

> 📖 如何关联客户？请参考：[客户关联业务员教程](https://www.zhihuiji.cn/help/doc/889)

* * *

## 解决方案

如需让员工查看全部客户，管理员可选择以下任一方式：

**方式一：** 取消勾选「启用关联业务员」，则所有员工可查看全部客户。

**方式二：** 通过【设置】→【角色权限】→ 修改对应角色 → 勾选「查看其他业务员/用户关联的客户」，则该角色的员工可查看全部客户。

![角色权限设置](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/f3de746741488be4531288e230b9f1ab.png)
