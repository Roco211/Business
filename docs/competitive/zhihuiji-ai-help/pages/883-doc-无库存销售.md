# 无库存销售

官方页面: https://www.zhihuiji.cn/help/doc/883

**无库存销售**

**路径** ：【设置】-【系统设置】-【允许负库存销售】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/e55e6dc480628dd6f8e3436192c22680.png)

**业务场景** ：遇到当前库存是负库存，常见原因是采购的进货单日期晚于出库的销售单日期，通过查询库存统计报告进行分析。

**功能说明** ：

1、未勾选“允许无库存销售”时，系统会强制不允许销售开单后，使仓库出现负库存。

2、未勾选“允许无库存销售”时，销售时将无法选择无库存货品。
