# 如何添加和修改商品的单位？

官方页面: https://www.zhihuiji.cn/help/doc/913

**添加辅单位及换算率**

**路径：** 【商品】-商品基础资料，勾选“支持多单位”后可添加辅单位

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202302/c54760a9b5f81aab3a3050a03b88f11d.jpg)

**业务场景：** 双计量单位使用，除了单个销售，还需要整件销售。以便开单销售或者进货时，比如按箱或按个，用来自动计算价格。

**功能说明：**

1、支持不添加辅单位。

2、添加辅单位时，需同时添加对应的换算率。当开单销售或进货时，单据将自动变成换算后的价格。

3、第一次添加换算率时，请务必谨慎操作，换算率一旦发生业务则无法随意修改。

4、支持1件商品最多2个辅单位

**修改辅单位**

**路径：** 【商品】-商品基础资料，勾选“支持多单位”后可修改辅单位

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/b0a958d88fb1c7ecba9b368629928d03.png)

**业务场景：** 货品的辅单位修改是日常业务中不可或缺的功能。

**功能说明：** 支持随意修改辅单位。

**修改换算率**

**路径：** 【商品】-商品基础资料，勾选“支持多单位”后可修改换算率

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/a9d3813e34c85ec35d5eacb9f101f952.png)

注意，点击右侧蓝色符号，可以切换换算的大小单位，比如1打=10盒，切换后可以变成1盒=10打

**业务场景：** 换算率修改是日常业务中不可或缺的功能。

**功能说明：** 不支持修改已发生业务的换算率。
