# 商品批量导入

官方页面: https://www.zhihuiji.cn/help/doc/904

## 批量导入新增商品

视频描述

### 业务场景

软件初始用建立货品基础资料，需要新增大量的货品资料，可以利用Excel表格快速导入新货品。

### 功能说明

1、快速导入时，请先下载商品资料导入模板。

2、不支持批量导入商品图片。

3、EXCEL表格文件需要关闭后再上传，才能导入成功。

### 操作路径

【商品】-【商品】-【导入新增】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/75046d2f14314d40c9197531e3eea71d.png)

### 下载商品资料导入模板

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/6077cfb2bc995fdf3c78624a0f6bcb7e.png)

选择商品类型

  * 简单商品：适用于没有规格或单规格的商品信息录入

  * 多规格商品：适用于有多规格(如颜色，尺码)的商品




![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/78d1ffec0cbc12349032616a49424292.png)

设置需要哪些商品信息 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/6967517a54c80bd135c0b504bd472dd2.png)

点击下载模板，在模板文件中填写要导入的商品信息，保存

**注意：请勿修改表头和文件格式**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e2d1fb21a35fa9fa12c73408607e8194.png)

### 上传表格

点击上传文件，选择填写好的模板文件，进行导入 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/939306039d07df20ccf7c390becf80ce.png)

### 查看导入结果

#### 导入失败

若导入失败，可下载失败数据，根据“错误原因”提示，调整导入模板中填写的内容后重新上传

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/f8cbfeab960e7267bbb8ac5dcc194649.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/8e845e2e5f55bb699f249b173f980c0e.png)

#### 导入成功

若全部导入成功，则商品导入已完成。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/32b8d452f8a8a4e94b3e5cb959dfe537.png)
