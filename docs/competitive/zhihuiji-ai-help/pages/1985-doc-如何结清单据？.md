# 如何结清单据？

官方页面: https://www.zhihuiji.cn/help/doc/1985

视频描述

收尾款有三种办法，只要选择其中一种操作即可，不可重复操作，否则会导致欠款为负数。**建议使用方法2和方法3来收尾款。**

**方法1：修改销售单本次实收金额**

到销售单列表找到对应的销售单，点击修改，然后填写本次实收金额保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/2920703dc3ebd3c78961e2449c7d4edc.png)

**方法2：查看销售单点击收尾款**

视频描述

点击销售单列表的查看按钮，进入到查看销售单界面，点击右下角的收尾款，或者点击右下角查看收款记录，本单待收金额右侧的收尾款。收尾款成功后会自动生成一个收款单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/e220fb1286f308655cd0c482b07ae8b1.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/5ddec927f124154c9f0a21ad0521dc0e.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/c41387919aa3450dbf0f39b05c3ffff3.png)

**方法3：开收款单进行收尾款**

**路径：** 【资金】-【收支】-【收款】右侧的“+”。或者点击客户列表-客户名称后面的收款按钮进入到新增收款单界面。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/315fccbcaacd7d2c9c1134c392e13f43.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/c158a53c353082a42c42a5692ff9602e.png)

（1）选择选择门店

（2）选择收款的客户

（3）选择欠款单据，勾选要收款的单据关联

（4）输入本次的收款金额，点击保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/9e355fa8a918051fa894f8d4bfca2bd5.png)

**注意：**

1.输入的收款金额要大于或者等于本次结算金额，否则会提示“本单收款不能小于本次结算”。

2.如果需要抹零可以点击本次结算的优惠按钮。

3.如果只是收一部分的款，需要填写欠款单据后面的本次收款金额。
