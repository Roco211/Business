# 付款单操作教程

官方页面: https://www.zhihuiji.cn/help/doc/869

视频描述  **新增付款单**

**应用场景：** 开进货单的时候，本次付款只填写了部分金额，或者没有本次实付金额是0，那么剩下的尾款，可使用付款单功能来操作。

**路径1：** 【资金】-【付款】旁边的【+】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/121a95e761d3f24579a977341ef5f09f.png)

**路径2：** 【资金】-【付款】-【新增付款单】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/f6f5791bbf67b2916726229dc820bca1.png)

**1.直接付款**

供应商有初始欠款，但没有欠款单据，可以直接付款。

（1）选择付款的供应商

（2）选择付款的账户，输入付款金额

（3）点击保存

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/f7c1e62123037b16d8ce9ceae6b14303.png)

**2.按单付款**

供应商有欠款，并且有对应的欠款单据，需要按单付款，这样付款单列表才会显示已付金额。

（1）选择供应商名称

（2）选择欠款单据，可以根据单据编号，业务员，单据日期查询进货单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/ac6cafa50c674f32a0e931b3aac09f32.png)

（3）输入付款金额，结算账户，保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/f09193d00b429dad168f4f20603d3f3d.png)

**注意：填写的付款金额要大于或者等于勾选的单据总金额，否则会提示“付款金额不能小于本次付款金额”。**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/99bd13e785df0e25dfe9cd9a6c63758e.png)

**付款单列表**

**路径：** 【资金】-【收支】-【付款】

（1）可通过筛选单据的日期、供应商名称、单据编号，业务员，备注，单据类型来查询单据。

（2）在对应的单据右侧有【查看】【修改】【作废】操作.

（3）可勾选是否”隐藏作废单据“。

（4）可以点击导出，导出付款单列表的内容。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/65097995ea07f484d701a1bf7fab384e.png)

**付款单详情**

路径：付款单列表点击【查看】可以进入到付款单详情界面。

付款单详情界面的左上角可以点击【修改】【作废】【单据列表】，右上角可以【导出PDF】【打印】操作。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/ec9c3f1725934229a517cd261f92b732.png)
