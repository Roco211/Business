# APP端组装单教程

官方页面: https://www.zhihuiji.cn/help/doc/2199

## 组装单

### 新增组装单

路径：右下角【更多】-【库存】-【组装拆分】-顶部【组装】-右下角【组装】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/1a0dfbbe05eaa22a91f97e423fd1124d.png)

（1）选择组合件商品，只能选择一件。

（2）选择子件商品，可以选择多件。

（3）输入组装费用。

（4）保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/a3cdfc5ac8482248cd752a7cebf7627a.png)

保存成功界面可与点击再来一单，或者查看单据详情。点击完成即可关闭该页面。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/32c937c32a524f6b0e371b232157430c.png)

**注意：开单完成后，子件商品库存数量减少（成本以进货成本价计算），组合件商品库存数量增加（成本总额=子件成本之和+组装费）**

### 组装单详情

（1）点击右上角的三点，可以作废组装单。

（2）点击底部的修改按钮可以修改单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/7ad019d4a69c62f6f842bb6a5c983e4d.png)

### 组装单列表

（1）可以输入单号/组合件名称/备注查询。

（2）点击筛选，可以选择日期，组装员，是否显示作废单据查询。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/7b169304fca69b88c22b16749795de4a.png)

## 配方

### 新增配方

路径：点击左侧导航【库存】-右下角【组装拆分】-右上角【配方】-右上角【+】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/d5b48357cd72bb8755e76566ad6864ab.png)

（1）选择组合件商品

（2）选择子件商品

（3）保存

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/547fa114ff0f69c57ddad7adbbf90344.png)

或者在新增组装单和拆分单时候底部可以勾选成配方。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/1ed0f5fc99409a85b0f5de84fa4c75a2.png)

### 配方列表

（1）可以输入组合件名称/货号/条形码查询配方。

（2）点击配方后面的三点，就可以选择编辑或者删除配方。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/5aa38d3b314a0324b0194b9583877be9.png)

### 使用配方

（1）新增组装单，右上角选择配方。

（2）更改组合件商品数量，子件数量等比例变化。

（3）修改/删除子件商品数量，配方关联关系会消失，再去改组合件商品数量，子件商品数量不会等比例变化。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/d6a7db5edc74d407cd6c47125364bc40.png)
