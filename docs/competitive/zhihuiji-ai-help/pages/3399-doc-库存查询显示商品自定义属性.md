# 库存查询显示商品自定义属性

官方页面: https://www.zhihuiji.cn/help/doc/3399

在库存查询页面的商品明细中，如需展示已设置的自定义属性（如“产地”、“材质”等），可通过表头设置添加相应字段。

**操作路径：** 库存查询页面 → 点击商品明细表头左上角齿轮图标【设置】→ 添加所需自定义属性字段 →【确定】
