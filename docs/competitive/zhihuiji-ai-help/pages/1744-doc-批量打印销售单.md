# 批量打印销售单

官方页面: https://www.zhihuiji.cn/help/doc/1744

**业务场景** ：

场景1：客户前一天在家或用手机开单，第二天到店统一打印多张单据，方便快速配货。

场景2：客户为按月结算时，统一打印当月单据，快速找到欠款单据并给客户核对。

操作步骤：销售单列表，勾选单据后，点击【批量打印】，即可在打印弹窗可选择打印模板、打印机、设置打印份数。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/a264639fe7e81f11cc1c2f38dd49d319.jpg)

点击预览可以预览每一份销售单的内容。
