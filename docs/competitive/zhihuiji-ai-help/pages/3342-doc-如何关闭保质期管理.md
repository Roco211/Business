# 如何关闭保质期管理

官方页面: https://www.zhihuiji.cn/help/doc/3342

**⚠️操作前提醒**

取消保质期管理后，商品库存将相同批次合并，再次开启后，可通过批次盘点进行调整

* * *

## 关闭单个商品的保质期

**操作路径** ：【商品】-【商品】- 找到商品 -【修改】

（1）进入商品编辑页面。

（2）在【商品库存】部分，**取消勾选【启用保质期管理】** 。

（3）系统会弹出确认提示，请仔细阅读关于库存合并的说明。

（4）确认无误后，点击弹窗中的【确定】，并**保存** 商品。

![关闭单个商品保质期提示](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/d781c57b12ebab756aa685710b6b1bdd.png)

* * *

## 批量关闭全店保质期

此操作将一次性关闭**所有** 已启用该功能的商品。

**操作路径** ：【设置】-【系统设置】-【商品设置】

（1）在设置页面，**取消勾选【启用保质期管理】** 。

（2）系统会弹出一个详细列表，展示**所有即将被关闭保质期功能的商品** （包含商品名称、规格、保质期、提前预警天数）。

![全店关闭确认列表](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/85c41444858f423e96283a743cc222ef.png)

（3）仔细核对列表，确认后点击列表下方的【确定关闭】。

（4）系统会进行**二次确认** 。再次点击【确定关闭】，即可完成全局关闭。

![二次确认弹窗](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/858331c76555ce6f492493ff5adc5c70.png)
