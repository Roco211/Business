# 销售单抹零

官方页面: https://www.zhihuiji.cn/help/doc/2190

1.操作路径：设置-系统设置-单据设置-勾选销售单抹零，然后选择要抹零的位置。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/1e3c1f88d2fa30e6ba8d82e48ba47a55.png)

2.比如选择抹分，开销售单点击抹零，会自动把分抹去。**注意，设置抹零不会自动四舍五入的，后面的数字不管多少直接抹去。**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/ec15bbb0f1ad83b7df351704f72d0cff.png)
