# 快递服务

官方页面: https://www.zhihuiji.cn/help/doc/1451

**第一步、开通快递服务**

操作路径：销售-其他-快递服务

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202411/f79d941244ca0410fe4fbdca6e7c6c33.png)

若您没有快递100企业账号，需先开通账号，提交账号资料之后即可注册成功

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/193999cb0d2a98a1985b2f535a32e659.jpg)

若您已有快递100账号，点击授权登录，输入登录账号密码之后进行授权登录，即可绑定快递100账号

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/a323bf848101d1551f16fc56d2ccb417.jpg)

**第二步，给寄件账号充值** （暂不支持货到付款）

操作路径：快递服务-我的账户-立即充值，选择充值金额和充值方式之后确认，完成对账号的充值

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/9b6d20470fee46fa26bb1c735ce71bc9.jpg)

**第三步，在线发快递**

第一种方式，在销售单列表选择一张单据，点击“…”选择发快递

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/245dab92c9276f5ea63f04aeaa99a90e.jpg)

第二种方式，选择销售单，进入到销售单详情页，点击“发快递”

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/f26789b16c96fd3ecf125ff76bf30619.jpg)

填写完收件人、寄件人、物品和快递信息后，点击提交

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/58d3d8c69c8dc144b85d57a24c8b15eb.jpg)

下单时会先在账户中扣除预估费用，待快递员线下取件称重后，根据实际产生的快递费用进行扣除或退还。

**相关问题** ：

**1、发快递之后是否能取消？怎么取消** ？

**方法一：** 进入销售单详情，选择要取消的快递订单点击“取消快递”

(注：1.在线取消快递的前提是物流状态为“已下单”或“待揽件”2.揽件后若需取消快递，需要线下联系快递门店进行取消)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/b085ad698ee3b719eff2c9adae415473.jpg)

**方法二：** 进入<快递服务-寄件订单>，选择要取消的快递订单点击“取消快递”(取消的前提是物流状态为“已下单”或“待揽件”)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/991dbe51badf98e375a06c88b19792c2.jpg)

**2、如何查看已寄件的订单** ？

**方法一：** 进入销售单详情，选择要查看的寄件订单，点击后可查看此快递订单信息详情以及物流详情

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/d4787745a6b1d63d93a790a41e66e367.jpg)**方法二：** 进入<快递服务-寄件订单>界面，选择要查看的寄件订单，点击后可查看此快递订单信息详情以及物流详情

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/cea3ef20bc12323315f1db8a8a805c8c.jpg)

**3、如何查看账户余额交易明细** ？

进入到【快递服务-我的账户】界面，点击<余额明细>，可查看账户余额交易明细

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/cdc0f2bd9150c22d9fffa39d3b317882.jpg)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202206/eb7cb1627aae767fcb56938c351f8632.jpg)

**4、如何申请开票** ？

登录 https://api.kuaidi100.com/login 在管理后台—消费中心—支付记录中申请开票

**5、快递服务是支持哪些快递公司的呢？**

快递服务是目前是支持圆通，申通，德邦这三个
