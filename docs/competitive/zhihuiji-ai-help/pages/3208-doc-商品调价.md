# 商品调价

官方页面: https://www.zhihuiji.cn/help/doc/3208

商品调价，需更新以下两处价格：

## 调整基础价格

**路径：** 进入 “**商品列表** ” ，修改商品的【零售价】、【批发价】等价格资料，用于维护未创建专属报价的新客户；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202509/61a6d7aa64d89545dc3704876a0af968.png)

**批量修改商品信息：** 【商品-批量操作-修改商品信息】下载导入模板表格，修改商品价格资料保存，然后再导入到软件里。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/82cdfa49c9f406ec47afb3f3290dae16.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c68fab0353085b68af3ac48b17824b50.png)

## 调整专属价格

**路径：** 进入“**客户-报价管理** ”调整最新报价，用于维护已购买过的老客户。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202509/189dd04a3a57d95c7751ea4815dc46de.png)

**批量导入改价：** 【报价管理-导入改价】下载导入模板表格，修改最新报价保存，然后再导入到软件里。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/81b0e69299270b595ee37ba9333fd7bb.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e09b2e8208b5bd1ac8b9be22258c649b.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/6a1a4fbdfb395aedfa81669111983672.png)

**注意：** 仅支持修改导出的报价再导入回去，不能新增报价。
