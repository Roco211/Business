# 销售单配送信息使用教程

官方页面: https://www.zhihuiji.cn/help/doc/2196

使用场景：顾客有多个店铺地址，商户希望在开单时可以直接记录对应的地址，后续配送的时候可以直接根据地址进行配送，方便快捷。

视频描述

## 新增配送地址

操作路径：【客户】-【客户】，找到对应的客户信息-点击【更多】-【修改】-【+配送信息】

1.在编辑客户的时候，可以增加多个联系人/联系电话/地址，最多支持5个。

2.可以设置为默认地址，在开销售单勾选配送地址时，自动带出默认地址。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/0657bf4ebe7e46e9819cf2ddf3b5ea10.png)

## 使用配送地址

操作路径：销售-销售-新增销售单-勾选配送信息，选择司机配送或快递物流。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/6eaf6dfdc437c7d2c323c1087a94e6cc.png)

1.自动带出默认地址，点击选择客户其他地址，若该客户有多个地址，可在弹窗里选择客户的其他地址。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/f17a35d32e62440e8a236d6ffec436e2.png)

2.开销售单勾选配送信息后，在单据详情页可以查看配送方式/客户联系人/联系电话/送货地址

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/be5b87323aeda86fba826791fd15fde6.png)
