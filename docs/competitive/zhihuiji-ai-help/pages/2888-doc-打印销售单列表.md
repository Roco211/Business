# 打印销售单列表

官方页面: https://www.zhihuiji.cn/help/doc/2888

## 设置销售单列表打印样式

点击设置-打印设置-选择销售单列表模板

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/530342fca50f1d54b6f7b754cabaceed.png)

点击表格，右侧信息设置-列设置，可以勾选要打印的信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/9da77f7bb65162d5ba7ffa7e7455d7b0.png)

## 打印销售单列表

点击左侧栏销售-销售-打印列表。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/2febadebb164baa932cee77202b9cead.png)

可以预览效果，然后点击打印即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/639dcf5fb8d5aba15ab0ce639946cd0c.png)
