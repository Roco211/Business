# 无法蓝牙打印，或提示“请确定设备已开启，并在通信范围内”

官方页面: https://www.zhihuiji.cn/help/doc/3326

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/2ed6f3296b5392a032aca40c3eef8cf6.png)

**解决方案：** 无法蓝牙打印，或者提示“请确定（目标打印机）设备已开启，并在通信范围内”，需前往打印设置移除设备，重新连接打印机。

**1、蓝牙打印机设置：** 在【打印预览-打印设置】页面，点击【打印机管理-蓝牙打印机】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/b082d1ee317870319af25e32f452f1cb.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/212c8ce6772bf686e1fef7abe680be74.png)

**2、移除目标打印机：** 【蓝牙打印机】-【已配对设备】点击目标打印机-【移除该设备】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/dfc1245e8d76ad838584752dce6042ae.png)

**3、重新蓝牙配对：** 【蓝牙打印机】-【发现新设备】点击目标打印机，系统自动配对

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/3413e77ba10524200f323214f765742f.png)

**4、重新选择打印机：** 在打印预览页，点开【目标打印机】重新选择，通常会听到长“滴”一声配对成功，即可正常打印

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/6e8ea3449b7df92f166b705996d27b27.png)
