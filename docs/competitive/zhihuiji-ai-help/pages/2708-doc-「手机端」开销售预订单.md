# 「手机端」开销售预订单

官方页面: https://www.zhihuiji.cn/help/doc/2708

**操作路径：** 【销售开单】→ 顶部切换至【销售预订单】→ 选择客户与商品 →【保存】

![开销售预订单流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/74430328807d7b6533aaf2e09f59b8aa.png)

**支持操作：**

  * **收订金** ：开单时可收取订金
  * **转销售** ：预订单可转为正式销售单
  * **打印** ：打印当前预订单
  * **分享** ：可分享预订单给客户
  * **查看详情** ：进入详情页进行打印、修改、分享、复制、关闭、作废等操作



![销售预订单详情](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/172a224a0a2d31b6a3d3d3461dce3804.png)

**💡 温馨提示：**

创建销售预订单不影响商品库存，仅在转为正式销售单后才会扣减库存。

关闭预订单：关闭预订单后，本单将无法继续转销售

作废预订单：未转销售的预订单可随时作废，已转销售的需先作废对应销售单。
