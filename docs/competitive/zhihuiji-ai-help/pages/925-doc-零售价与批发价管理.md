# 零售价与批发价管理

官方页面: https://www.zhihuiji.cn/help/doc/925

## **添加/修改零售价和批发价**

**路径：** 【商品】-【商品】-新增/修改商品-【商品价格】-【零售价】/【批发价】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/9e2c55ed2b6d2ef913cacfbe542c79fd.png)

**业务场景** ：日常业务销售时，需要用到货品的统一零售价或者统一批发价，属于基础的销售价格资料。

**功能说明：**

1、添加/修改销售价格时，不会影响到已发生业务的单据价格。

2、另外支持新增商品的好友价与会员价等（可自定义名称），点此查看[价格等级](https://www.zhihuiji.cn/help/doc/891)。

## **统一零售价 • 使用示例**

**业务场景** ：日常业务销售时，开单销售时需要能自动带出货品的统一零售价。

**功能说明：**

1、使用前，必须先设置客户价格等级：【首页】-【客户】- 找到客户 -【修改】-【价格等级】-【零售价】-【保存】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/7280af52f256d44cb2e32fd7be2cc3e6.png)

2、开单销售时，先选择「零售客户」或「价格等级为零售价的客户」，再选择货品，则会自动带出货品的统一零售价。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/bf8225427082ec2efbd588f215dc8f98.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/efe9d36d2296e88545bec316972abe69.png)

## **统一批发价 • 使用示例**

**业务场景** ：日常业务销售时，开单销售时需要能自动带出货品的统一批发价。

**功能说明：**

1、使用前，必须先设置好客户价格等级：【首页】-【客户】- 找到客户 -【修改】-【价格等级】-【批发价】-【保存】 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/0eab6ed8f5406b080f5237724ff9d4aa.png)

2、开单销售时，先选择「批发客户」或「价格等级为批发价的客户」，再选择货品，则会自动带出货品的统一批发价。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/b0a27187672ae1f120b8a08b1ee7723b.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c0fa819e0335b251255f4a09d352f843.png)
