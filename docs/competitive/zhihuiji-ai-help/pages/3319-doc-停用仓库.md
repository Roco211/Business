# 停用仓库

官方页面: https://www.zhihuiji.cn/help/doc/3319

**场景：** 中止仓库的【对外业务职能】，包括进货和销售，但保留其【内部物流属性】调出功能。

  * 公司有两个小仓库A和B，为了降低管理成本，决定关闭仓库A，将其功能合并到仓库B；
  * 一个为促销活动设立的“临时爆款仓库”，活动结束后需要关闭。



**路径：** 左侧【设置】-【仓库设置】-【仓库管理-停用】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/de9b0cbc525108bd032701e8edfe583c.png)

**注意：** 仓库停用仍可调出，不支持调入和销售进货。
