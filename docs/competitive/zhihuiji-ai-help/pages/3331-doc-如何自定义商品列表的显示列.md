# 如何自定义商品列表的显示列

官方页面: https://www.zhihuiji.cn/help/doc/3331

**操作路径：** 【商品】-【商品】- 点击列表左上角【设置】按钮

  1. 在商品列表页面，点击左上角的【设置】按钮（齿轮图标）。
  2. 在弹窗中，勾选您希望在列表中直接看到的信息列。
  3. 点击【确定】，列表将立即按您的设置显示。



![列表设置入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/be5ef67352ba1132da29ff7d1f15bf5f.png)

**适用场景**

  * 在列表里直接查看库存、价格等关键信息，无需点进详情
  * 隐藏不关心的列，让列表更简洁
