# 普通账户操作教程

官方页面: https://www.zhihuiji.cn/help/doc/876

**新增普通账户**

**路径：** 【资金】-【账户概览】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202204/2d9982a1a26cba9da45da20d2e09e297.jpg)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/baf356ab46f3dc00fec32f2afc381e7b.png)

分为普通账户和在线账户两种类型。

点击“新增普通账户”，完善账户信息，“保存”即可。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202204/1310b5d031f030b4a634af2cb9c4b3ce.jpg)

**业务场景：** 修改结算账户，是日常业务中不可或缺的功能。

**功能说明：**

1、修改账户的当前余额，会影响到初始余额和资金流水。

2、不支持修改系统预置的结算账户。

**删除账户**

**路径：** 【资金】-【账户概览】

进入列表后，在账户右侧点击“删除”即可。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202204/8b3d6a5101f4860f58b12b4650680e8b.jpg)

**业务场景：** 日常业务中，不慎添加了错误的结算账户，需要对账户进行删除。

**功能说明：**

1、删除结算账户时，要先删除所有已发生业务的相关单据，包括检查6大模块：销售订单、销售单、收款单、进货单、付款单和收支单。

2、删除结算账户时，提示“已经发生业务，不允许删除”，说明仍未全部删除业务单据。

3、不支持删除系统预置数据。
