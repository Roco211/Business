# 云店“店长推荐”类目中的商品如何添加？

官方页面: https://www.zhihuiji.cn/help/doc/3045

操作路径：【商品】--【商品】
新建/修改商品时，在「云店信息」-「云店商品标签」中选择「店长推荐」，保存并上架商品后，客户可在“店长推荐”类目中看到此商品。

![选择店长推荐](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/954e98d790a213705dcf51979b27babe.png)

  * 可以在【云店】--【云店商品排序】--「店长推荐」中查看已上架、已推荐的商品
  * 排序方式：点击排序按钮拖拽排序，或点击操作栏的“置顶”“置底”



![查看与排序](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/8a7b9fe791e2a7c030eae5688663e691.png)
