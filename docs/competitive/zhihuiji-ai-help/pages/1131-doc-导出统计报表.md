# 导出统计报表

官方页面: https://www.zhihuiji.cn/help/doc/1131

**一、功能介绍**

为充分满足客户灵活查看和处理数据、进行数据分析，财务对账等场景下需求，增加报表导出功能。

目前支持①销售统计报告导出（按单据/商品/客户统计）、②进货统计报告导出（按商品/供应商统计）、③员工业绩统计导出、④库存统计导出、⑤经营利润导出 这五类报表的数据导出。

二、**操作路径**

下面以销售统计报告导出为例，若您需要导出一份按照单据统计的销售统计报告，则点击：

【分析】-【销售统计】-【按单据统计】-【导出】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202111/f9af2fde5f82b4a1dde707d232518181.png)

待弹出的【导出记录】显示“导出成功”后

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202111/f9af2fde5f82b4a1dde707d232518181.png)

点击下载即可导出您所选择的按单据统计的销售统计报告。
