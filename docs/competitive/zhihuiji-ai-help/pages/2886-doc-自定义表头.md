# 自定义表头

官方页面: https://www.zhihuiji.cn/help/doc/2886

可调整自定义表头的位置，并用于开单，开单的信息将同步影响打印、导出、对账等功能。

自定义的表头信息，销售单、预订单、报价单、销售退货单可共用  视频描述

## 创建表头：

操作路径：新增销售单界面，点击表头左侧的设置按钮，然后点自定义表格底部的创建表头。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/586abf2b374bb67b370a9012286f79dc.png)

创建的表头可以点击右上角的+号，显示到开单界面里，也可以点击修改和删除表头。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/d54ed8568ed7a8b66090e4a910bef59e.png)

显示的表头里点击右上角的——号可以设置不显示表格，鼠标拖拽移动可以调整表头的显示顺序。设置好点击右下角的确定按钮保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/249dd99a8ff5e8b28b36698861f5b518.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/1faf05d574ba139f0cd7a838b4591232.png)

## 打印表头

点击设置-打印设置-选择对应的销售单模板修改，再点击表格，右侧可以勾选打印创建的表头信息，然后保存模板。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/245972cf21cdaf4b799994283696a7d1.png)

查看销售单界面，点击打印，然后再点击预览，就会显示有创建的表头信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/1f3b5018b8766bb6059a69684b045cc4.png)

## 导出表头

导出单据明细，会显示有创建的表头信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/c54c3ffdbe7885d3c09547c9343ae5fa.png)

## 对账单显示表头

点击分析-客户对账，对账单明细，可以设置显示创建的表头信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/11b640170abf237712766014b614318a.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/4435082538fb7af5c2d6911f9a75a3ec.png)

点击设置-打印设置，选择对账单模板，可以设置打印创建的表头。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/4957680c9176c3ce16ccd9a6dac523d8.png)
