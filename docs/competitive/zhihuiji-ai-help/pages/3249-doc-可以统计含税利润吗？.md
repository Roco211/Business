# 可以统计含税利润吗？

官方页面: https://www.zhihuiji.cn/help/doc/3249

智慧记AI进销存默认按税前金额（未含税）统计利润，如需按税后（已含税）口径统计，请注意以下几点：

**1、进货成本：** 进货单只有一个进货价，无法设置两个成本，即填写“税前净价”就是不含税成本，**填写“税后价”就是含税成本** ；

**2、销售价：** 销售单虽可分别显示税前净价（未含税）与税后价（已含税），但系统仅支持前者统计利润，暂不支持后者。如需按已含税的销售额呈现利润，则**开单时不要设置税额相关列，“单价”直接填写已含税的税后价；** ——税率税额默认0或手动改0，查看税额可填写到备注

**3、销售利润统计：** 系统将根据以上税后数据【商品销售额（默认已含税）】，扣除税额和成本后自动完成利润统计。——由于税率税额0，填写含税价相当于直接计算含税利润
