# 「手机端」新增门店

官方页面: https://www.zhihuiji.cn/help/doc/1276

智慧记AI进销存多店版[启用多门店](https://www.zhihuiji.cn/help/doc/1285)后，可新增门店。

**操作路径：** 【我的】→【店铺管理】→【门店管理】-右上角【+】-填入门店信息后，点击右上角【保存】即可。
