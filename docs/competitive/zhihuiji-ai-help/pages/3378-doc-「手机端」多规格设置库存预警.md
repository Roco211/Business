# 「手机端」多规格设置库存预警

官方页面: https://www.zhihuiji.cn/help/doc/3378

**操作路径：** 【商品】→【新增/编辑商品】→【规格管理】→【下一步】→【编辑规格】→【库存预警】

![进入库存预警设置](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/dd88d287314140df84b8d1848894bf4b.png)

**在此页面，您可以：**

  1. **填写预警值** ：分别为每个规格设置「最低库存」、「安全库存」与「最高库存」。
  2. **使用批量设置（可选）** ：若所有规格预警值相同，可点击【批量】一键统一设置。



![批量设置库存预警](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/2ef25478215b68a376a3148e70bb7363.png)

  3. **管理多仓库（若启用）** ：可为不同仓库分别设置预警值，或开启「所有仓库预警值相同」统一设置。



* * *

**💡 温馨提示：**

  * 设置完成后，所有触发预警的商品规格将统一在【库存预警】页面中展示。
  * 您也可以在【商品】→【查看商品】→【规格】→【库存预警】中，随时查看已设置的预警值。 ![查看库存预警值](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/3d211caa4a964016ac778685ac451b4b.png)
