# 如何删除规格

官方页面: https://www.zhihuiji.cn/help/doc/920

**操作路径：** 【商品】-【规格管理】

在规格列表中找到目标规格，点击右侧的【删除】按钮即可

**请注意** ：若规格已被任何商品使用，则无法删除。
