# Excel盘点

官方页面: https://www.zhihuiji.cn/help/doc/2887

视频描述

1.操作路径：点击左侧栏库存-盘点-Excel盘点

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/309aae51c2c15780ecde3abbfe17691c.png)

2.然后点击导出

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/8fca2650e8809a2fabc7a6c46fb0a698.png)

3.选择要盘点的门店或者仓库，和盘点的商品

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/52a437745db7d3b186687e546d6eb153.png)

4.下载的表格录输入要盘的商品的实际库存数量，然后点击导入。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/2b1d7f263df6a3c70662ea13ae6a3167.png)

5.导入成功后会显示导入成功和导入失败的商品。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/70f4fde8068c17ed8094965ca4708cce.png)

6.点击查看盘点单，可以看到导入成功的商品。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/e42ce7c276c2b60cb0aa69222fcdf71e.png)

7.可以点击下载导入失败的商品查看原因，没有填写实际数量的商品不能导入。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/97b58ca0ddbadfdd99f252930ab7815d.png)

8.确定没有问题点击完成即可自动生成盘点单

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/5764c1e303d866e0c6c853c8eb59045b.png)
