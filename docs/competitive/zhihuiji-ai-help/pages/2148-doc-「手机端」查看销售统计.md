# 「手机端」查看销售统计

官方页面: https://www.zhihuiji.cn/help/doc/2148

查看路径：底部点击【分析】→【销售统计】卡片→【销售统计】 ![查看销售统计](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/87f563103103bb83bb9937b1fd4fc6e4.png)

  * 支持两种统计维度：【按商品】和【按客户】查询。
  * 在查询框中输入名称、条形码、编码货号或简拼，可筛选对应商品或客户，并更新下方的销售额、销售成本、毛利率、销量/销售笔数、毛利及税额等统计结果。
  * 若存在多个门店，可在查询前选择具体门店。
  * 点击【筛选】，可按商品分类、客户分类、客户名称、业务员等条件进一步筛选。
  * 点击【日期】，可自定义查询时间范围。
  * 点击【排序】，支持按商品销售额、销售量、销售毛利进行升序或降序排列。
