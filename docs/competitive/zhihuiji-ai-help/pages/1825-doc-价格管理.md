# 价格管理

官方页面: https://www.zhihuiji.cn/help/doc/1825

视频描述

**业务场景：** 价格查询是可以方便老板快速查询和修改到每个规格的货品的价格

**操作路径：** 左侧导航商品-价格查询。

**隐藏停用商品：** 勾选隐藏停用商品后不会显示停用商品的信息；

**查询：** 支持品牌，重量，供应商，和商品名称/条形码/货号同时查询；

**批量改价：** 点击批量改价可以快速修改每个商品的进货价，零售价和批发价。
