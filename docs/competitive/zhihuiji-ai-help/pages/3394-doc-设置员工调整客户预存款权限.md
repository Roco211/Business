# 设置员工调整客户预存款权限

官方页面: https://www.zhihuiji.cn/help/doc/3394

如需限制员工调整客户预存款的权限，可通过角色权限设置进行管理。

**操作路径：** 【设置】→【角色权限】→ 修改对应角色 → 取消勾选「客户」中的「调整预存款」→【保存】
