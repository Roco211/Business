# 新增、修改、停用、删除供应商

官方页面: https://www.zhihuiji.cn/help/doc/855

视频描述

## 新增供应商

**路径** ：【进货】-【供应商】-【新增供应商】

依次填写对应的基础信息和辅助信息，点击保存即可。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/712dff895827c234e3dd2cde2fbaf07c.png)

## 修改/停用供应商信息

**路径** ：【进货】-【供应商】

可输入供应商名称、联系人、手机号、备注，来查找相应的供应商

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/1223de183743cedabbdccdcefcfe9220.jpg)

**修改：** 如需要修改，在供应商列表中选择“修改”操作，就可以重新编辑供应商的信息了。

**停用：** 如需要停用，在供应商列表中选择“停用”操作；停用后可重新点击“启用”。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/a4066fb97dc1d9fc2715bb1cd206b48d.png)

##查找供应商

**路径** ：【进货】-【供应商】

进入该页面，可看到所有的供应商名录；

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/345d34706f04afe6382d009e7d89fc9b.png)

右上角有个”查询“按钮，可以输入供应商名称，联系人，手机号以及备注信息来查找；

如输入联系人姓名”黄“，可出现对应的供应商。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/fdb71231ce7db8da3a48dcc02bd042bd.png)

## 隐藏停用供应商

**路径** ：【进货】-【供应商】

如有近期不再从那里进货的供应商，可以先做停用处理。

然后勾选左上角的”隐藏停用供应商“，那么在供应商列表中就不会再出现

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/ab87b62dd0b94153a0a6b5dc3adc3475.png)
