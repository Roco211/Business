# 销售报价单教程

官方页面: https://www.zhihuiji.cn/help/doc/1947

业务场景：报价单是销售最先给客户提供的价格信息，暂未涉及资金往来。

常用报价场景：适用于家居建材。报价单类似口头协议，流程上先有报价单；接下来需进一步协商达成一致，报价单才进入正式销售环节，产生销售意向后，生成销售订单；成交，生成销售单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/ec72310780c7dd54720fb54ca65ebe35.png)

视频描述  操作路径：

方式1：菜单栏【销售】-【报价单】列表-【新增报价单】；

方式2：菜单栏【销售】-【报价】-【+】新增报价单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/82fb37d12e0b9ad6289f4cfd6a79a4e9.png)

1.新增报价单和新增销售单类似，选择门店，输入客户名称，选择商品，保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/b32d51a3d4ebdea34ad043f204a5812f.png) 2.报价单列表：可搜索或查询不同维度下的报价单信息。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/6fbe4f37d5877d32e3bca583dd3e298e.png) 3.查看报价单：支持修改，复制，作废，转销售，导出PDF,分享和打印。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/73e3165c8965b1426a430e3968948fd6.png)
