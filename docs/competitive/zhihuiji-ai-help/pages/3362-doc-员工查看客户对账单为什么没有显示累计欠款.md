# 员工查看客户对账单为什么没有显示累计欠款

官方页面: https://www.zhihuiji.cn/help/doc/3362

**员工查看客户对账单没有显示累计欠款一般是以下两个原因导致的：**

**原因一：** 查询的时候选择了某一个门店了，没有选择全部门店，把选择全部门店即可全部看到

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/1bc58be677659e5d94785d6dab43be90.png)

**原因二：** 该员工的权限只有部分门店可查看，如果需要累计欠款的话，需要让老板把全部的门店都归属给该员工。
