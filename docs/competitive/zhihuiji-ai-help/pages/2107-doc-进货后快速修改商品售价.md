# 进货后快速修改商品售价

官方页面: https://www.zhihuiji.cn/help/doc/2107

场景：进货价波动时，快速调整售价，避免亏本销售。

（1）操作路径：点击库存-进货-新增进货单-保存，当进货价格有发生改变，保存成功的界面会显示多少个商品的进货价发生变化，点击调整售价按钮可以进入到调整售价界面。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/5a9e2dabb6f0502ecddd6044b575876b.png)

（2）进入到调整售价界面，会显示每个商品的进货价比上次的进货价增加或者降低了多少，点击改售价按钮可以进入到改售价界面。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/411930792ea2c1b74f525a9c7303bc39.png)

（3）进入到改售价界面，可以修改每个价格等级的售价，会显示原来每个价格等级的售价供参考。修改好价格点击确定，然后再点击保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/e14d907ab9160da28cc95eb64e321f1c.png)
