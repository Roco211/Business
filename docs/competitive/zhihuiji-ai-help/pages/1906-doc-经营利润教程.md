# 经营利润教程

官方页面: https://www.zhihuiji.cn/help/doc/1906

业务场景：如果想要查看净利润，就可以到经营利润查看。

视频描述

路径：分析-经营利润

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/6ceef0567fe5374095e295776dd97fe6.png)

1.可以选择日期和门店查询。

2.经营利润=收入-支出。

3.点击【导出】按钮，可以导出经营利润报表的内容。

4.点击项目名称后面的【明细】，可以查询到该项目对应的单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/62997ec48c7cb51a5084d5b33ffea30c.png)

注意：

1.销售收入主要是销售单据的总应收金额，包括运费和抹零。

2.销售成本是指已售出的商品成本（减去已退货的货品成本）。
