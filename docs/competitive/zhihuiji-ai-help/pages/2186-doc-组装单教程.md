# 组装单教程

视频描述

## 组装单

**使用场景：** 商家外购商品后并不是直接卖给其他客户，而是先进行“加工”，变成可销售的组装件后再出售。

比如：门窗生产企业将铰链、窗框、玻璃等加工成窗出售；还有灯具生产厂家将灯源、面板、支架等加工成灯具出售等。

**功能介绍：** 支持开组装单，将多个商品转化为一个新的商品。

### 新增组装单

操作路径：【库存】-【组装】-【+】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/16883543201b536b81638731db258339.png)

1.选择组装员，选择日期；

2.输入组合件商品信息，只能选择单个商品；

3.选择子件商品信息，可以选择多个商品；

4.输入组装费用，选择结算账户；

5.可选择保存此方为配方，下次快捷应用配方，再点击保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/c492fca4bd03e2d1c1bb71855e08cf37.png)

**注意：开单完成后，子件商品库存数量减少（成本以进货成本价计算），组合件商品库存数量增加（成本总额=子件成本之和+组装费）**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/2a2572b6b84ea365e06077db05e3f4f0.png)

### 组装单列表

1.支持选择日期、单据编号、组合件商品名称、备注、组装员查询。

2.可以勾选隐藏作废单据。

3.可以查看，修改和作废组装单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/08434c01f3008348e9b7345a18cdc641.png)

## 配方

**使用场景：** 一个成品的零件用量是固定的。每次加工都是消耗等比例的零件数量。其他叫法包括：BOM表、物料清单。

**功能介绍：** 支持提前创建配方，开单快速应用。

### 新增配方

操作路径：组装单列表-新增组装单旁的【配方】-新增配方

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/ca17b1a7d49bac27f695d3b0bbffd816.png)

1.选择组合件商品信息；

2.选择子件商品信息；

3.点击保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/99cf03f26964ee457c20ec6dee558dd2.png)

或者在新增组装单时也可以勾选存为配方。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/4c0e8097d00b47a714ba119f595083d8.png)

### 配方列表

1.可以新增配方；

2.可以输入组合件名称/货号/条码查询配方；

3.点击配方下的修改可以修改配方的信息；

4.点击配方下的删除可以删除该配方。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/9efbfac5e87863f4e3ba816115883451.png)

### 选用配方

1.新增组装单界面，右上角选择配方。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/0537f083617de61a23e4d3d094edfd1b.png)

2.更改组合件商品数量，子件数量等比例变化；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/682819938dd18b0865236b508ec28c65.png)

3.修改/删除子件商品数量，配方关联关系会消失，再去改组合件商品数量，子件商品数量不会等比例变化。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/22481a2a71405e18a3107786ceba6526.png)
