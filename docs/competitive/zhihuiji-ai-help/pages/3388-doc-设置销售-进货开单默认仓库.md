# 设置销售/进货开单默认仓库

官方页面: https://www.zhihuiji.cn/help/doc/3388

在销售或进货开单时，可为当前登录账号设置默认选择的仓库，以提升开单效率。

**操作路径：** 【设置】→【用户偏好设置】→【销售/进货开单，支持设置默认仓库】→ 启用后选择默认仓库

**说明：**

  * 此设置仅对当前登录的账号生效。
  * 设置后，开单时将自动选中此处设置的仓库作为默认值，开单时可手动修改为其他仓库。
