# 员工业绩统计

官方页面: https://www.zhihuiji.cn/help/doc/1903

业务场景：当有多个业务员开单需要分别统计每个营业员的业绩，就可以查看员工业绩统计报表。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/ebd583d85bfd7f8636a78ae16c74486f.png)

路径：分析-员工业绩统计。可以查询到每个业务员总的销售金额和总的销售利润。

1.可以根据单据日期和门店查询。

2.点击【导出】按钮可以导出该报表。
