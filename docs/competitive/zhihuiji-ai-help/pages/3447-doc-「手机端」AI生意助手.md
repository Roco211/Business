# 「手机端」AI生意助手

官方页面: https://www.zhihuiji.cn/help/doc/3447

AI生意助手是您掌上的智能助理，能够解答问题、分析经营、辅助营销与开单，全方位助力生意增长。

**📱 如何找到它？**

在App底部点击【分析】→ 点击右上角【AI】按钮，即可开始对话。 ![操作路径示意图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/dda036ff804087b291ce6c26af665b0f.png)

**🌟 它能为您做什么？**

  1. **📈 AI经营分析**

     * **功能** ：智能诊断店铺经营数据，自动发现问题并提供优化建议。
     * **场景** ：想了解店铺上周为何销售额下滑，或想知道哪些商品最赚钱。 ![经营分析界面示意图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/a4bbe63a4d552f87cd361273b0f9adeb.png)
  2. **🎯 AI营销**

     * **功能** ：
       * **优化商品标题** ，提升搜索与点击率。
       * **生成商品种草文案** ，用于宣传推广。
       * **制定店铺营销方案** ，助力活动策划。
     * **场景** ：新品上架需要写推广文案，或策划节假日促销活动。 ![营销策划界面示意图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/e59690beb6468f60c494164bb708092d.png)
  3. **🚀 AI开单**

     * **功能** ：通过**语音、拍照或粘贴文字** ，快速识别并添加商品，极大简化开单流程。
     * **详细教程** ：详情请参考 **[「手机端」AI开单](https://www.zhihuiji.cn/help/doc/3446)** 。 ![智能开单界面示意图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/c79bfb2a16aaf54f5e8abb930679851e.png)
  4. **❓ 解答软件问题**

     * **功能** ：遇到任何软件操作疑问，直接向助手提问，它将为您提供即时解答与指引。
     * **场景** ：不知道某个功能在哪里，或对操作步骤有疑惑。 ![解答问题界面示意图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/52c15d8df399a05a5e70d7cd0d820341.png)
