# 如何设置开销售单时默认发货/不发货

官方页面: https://www.zhihuiji.cn/help/doc/2566

只要在某次开单时勾选了【保存后发货】选项，下次开单时系统默认勾选状态，一开单即发货。不勾选则下次开单系统默认一开单都不发货。
