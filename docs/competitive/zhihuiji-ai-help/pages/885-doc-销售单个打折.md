# 销售单个打折

官方页面: https://www.zhihuiji.cn/help/doc/885

视频描述

**业务场景：** 满足老板日常经营中，需要给客户单个商品优惠折扣时使用。

1.操作路径：设置-系统设置-单据设置-勾选启用单行折扣。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/c64a49e60a2c45b3ce8dde1b5dcfc9fd.png)

2.开销售单可以输入单个商品的折扣率，从而对单个商品进行打折。
