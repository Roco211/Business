# 云店订单备注自动带入销售单

官方页面: https://www.zhihuiji.cn/help/doc/3404

客户在云店下单时填写的备注信息，在后台将订单转为销售单时，可自动填入销售单的备注栏。

**操作路径：** 【销售】→【云店订单】→ 接单后操作【发货】

**规则说明：**

  1. **云店订单备注为空时** ：转为销售单，系统自动填入**客户下单时填写的原备注** 。

  2. **云店订单备注有内容时** ：转为销售单，系统自动填入**订单备注内容** ，不填入客户原备注。
