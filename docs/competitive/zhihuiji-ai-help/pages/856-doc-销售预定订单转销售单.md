# 销售预定订单转销售单

官方页面: https://www.zhihuiji.cn/help/doc/856

**【销售预定订单】转【销售单】**

**销售预定订单转销售单路径** ：【销售】-【销售订单】-【查看历史单据】-【查看】需要处理的销售预定订单-【转销售】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/2e5399dffe35e9877a633fbf7857aa0d.png)

**业务场景** ：方便老板查看销售预定订单后，一键转成销售单。无需按照销售订单，再次开销售单。大大提高店铺开单效率。
