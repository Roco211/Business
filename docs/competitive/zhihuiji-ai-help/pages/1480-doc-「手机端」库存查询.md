# 「手机端」库存查询

官方页面: https://www.zhihuiji.cn/help/doc/1480

**库存查询操作路径** ：首页【库存查询】→ 可以选择【库存查询】和【保质期查询】。

在【库存查询】页面点商品名称，可以查询商品的【库存分布】和【库存流水】
