# 供应商账单使用教程

官方页面: https://www.zhihuiji.cn/help/doc/961

**供应商对账**

**路径** ：【分析】-【供应商对账】

可以筛选单据日期、门店、供应商进行查询。

该功能主要针对的是进货已开单、但未付款的业务场景，可以得知还有多少款项未支付。

点击“明细”，可以看到当前的欠款是如何产生的。
