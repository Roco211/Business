# 商品智能录入

官方页面: https://www.zhihuiji.cn/help/doc/2795

视频描述

## 功能简介

商品录入智能匹配，是智慧记AI进销存全新推出的一款轻量级数据服务，基于智慧记1.4亿云标准商品库，在新增商品的过程中智能推荐相关商品，帮助快速录入商品，减轻时间成本。

## 功能设置

### 选择适用行业

**操作路径** ：设置 → 店铺信息

选择您的行业类型，当前支持以下行业：

  * 食品酒饮
  * 商超便利
  * 数码电器
  * 美妆个护
  * 文体图书
  * 母婴玩具



> **提示** ：更多行业支持正在陆续开放中

![选择行业界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/44b361d42144071640ff04e6ae88f2a0.png)

## 操作指南

### 使用智能匹配录入商品

**操作路径** ：【商品】-【商品】-【新增商品】

![新增商品入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/f5492caec48970cabf5ad12525760cb5.png)

**操作步骤** ：

  1. **输入商品关键词**

     * 在【商品名称】栏输入商品关键字
     * 系统将自动显示最多10个相关商品推荐

![智能匹配界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202406/e9c0b3cc26e38052bc0da69423f99776.png)

  2. **选择推荐商品**

     * 在推荐列表中双击目标商品
     * 系统自动填充以下信息：
       * 商品名称
       * 商品条形码
       * 商品图片
       * 零售价格

![商品信息自动填充](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202406/42de71886eb284b31581a5e065496ec3.png)

  3. **保存商品信息**

     * 确认信息无误后，点击保存按钮
     * 商品录入完成

![保存商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202406/7a2f857c55cdec51fcd6902e47952095.png)
