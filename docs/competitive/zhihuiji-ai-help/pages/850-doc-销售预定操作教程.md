# 销售预定操作教程

官方页面: https://www.zhihuiji.cn/help/doc/850

视频描述  新增销售预定订单 **————————————————————**

**新增销售预定订单路径** ：【销售】-【销售预定】-【新增销售预定】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202402/21f84f8ea6cc988e38b1c8548623b79f.png)

**业务场景** ：销售预订货品，以便仓库备货出库，一般用于与客户达成协议的合同记录，货品并不实际出库。

**功能说明** ：

1、新增销售预定订单时，客户和货品是必须填入的。

2、支持预付定金。

查看销售预定订单 **————————————————————**

**查看销售预定订单路径** ：【销售】-【销售订单-列表】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/e0a1bce2de93ea7267ed6a2d4366867f.png)

**业务场景** ：满足老板查找已开出【销售订单】的需求，方便业务处理。
