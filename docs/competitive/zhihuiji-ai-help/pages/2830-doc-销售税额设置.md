# 销售税额设置

官方页面: https://www.zhihuiji.cn/help/doc/2830

视频描述

## 税额模式设置

**场景：** 在商业运营中，准确计算税额对于评估利润和经营状况至关重要。系统提供了两种销售税额计算方式：单价不含税和含税，前者适用于国外商户或跨境业务，后者适用于国内商户。

**路径：** 电脑端，左侧导航栏【设置】-【基础设置-系统设置】-【单据设置】，根据业务需求设置税额规则

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/96eca4b2329f9d92feca3bb7ed782f75.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202502/b0224be52a14f3544dea803d252cb6f3.png)

**注意：开单前，一定要留意设置税额模式（勾选含税或取消勾选不含税）；系统默认按开单时的模式计税，不支持修改价税规则，除非作废后重做（可直接复制单据快速重做）。**

## 销售单添加字段【税率】【税额】【含税金额】

系统设置税额模式后，还需在销售单界面手动添加相关字段；开单时会自动根据税额规则计算税额。

**路径：** 开单界面【销售单】-自定义表头【已显示字段】-添加【税率】/【税额】/【含税金额】-【确定】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/7f61444661bb1ebb471f87b165c696e3.png)

## 模式一：国外价税分离计算，单价不含税

单价不含税就是商品售价和税额分开计算，需清晰展示净价与税额，如国际贸易或国外标价100元+10元税。

**关键设置：** 取消勾选【商品价格包含税额】，则销售开单时保存为不含税单价。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/1d707dbcb224cc97fcce55c941caa538.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/f8c9a9881a69a23bffc9b53cbac8075e.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/91e7241a02acbed072649b4ce87ab457.png)

  * **商品税额** = 不含税单价 × 税率
  * **商品含税价** = 不含税单价 × （1 + 税率）
  * **示例：** 商品不含税单价100元，税率10% → 商品税额10元，总价110元



## 模式二：国内价税不分离计算，单价含税

单价含税就是商品售价已包含税额，如国内零售标价100元含税，由系统反推商品原净价90.9元和税额9.09元。注意：价税不分离时，系统隐藏税前净价90.9元（不含税），需自行代入公式计算。

**关键设置：** 勾选【商品价格包含税额】，则销售开单时保存为含税单价。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/9905c703c6f3eb32ff6477cb31880b7a.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/23b0eb5868bc161200d279f8fc053ac5.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/f79257953f4e0447da17f52c7c283670.png)

  * **商品原净价** = 含税单价 ÷ （1+税率）——注意：系统反推隐藏，仅供计算税额参考
  * **商品税额** = 原净价 × 税率
  * **示例：** 商品含税单价100元，税率10% → 商品原净价≈90.9元，税额≈9.09元



## 销售毛利统计

在销售统计报告中，商品销售额全部默认为**税后金额** ，毛利计算需扣除税额。注意：统计报告暂不支持显示税前净价。

  * 销售单商品金额，为税前（净价）时，系统自动相加税前和税额；销售统计显示税后金额；
  * 销售单商品金额，为税后（含税）时，商品金额本身为税后金额。
  * **销售毛利 = 商品销售额（已含税） - 销售商品成本 - 销售税额**

## 打印税率和税额

**路径：** 电脑端，左侧导航栏【设置】-【打印设置】-【打印模版-销售单】，点击进入打印模板编辑界面，可以设置打印税率和税额
