# 批量打印销售退货单

官方页面: https://www.zhihuiji.cn/help/doc/3392

批量打印销售退货单，适用于需要集中处理多张退货单据的场景。

**操作路径：** 【销售】→【销售退货】→ 勾选要打印的单据 →【批量打印】→ 确认模板与打印机、打印份数→ 点击打印

![批量打印销售退货单](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/8b647c76346d230d02275dbb5ae65362.png) ![确认打印模板后点击打印](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/fae00b044b2b4bfbbbf26c5aab4dd0ca.png)

**💡 注意事项：** 销售退货单与销售单默认共用同一打印模板，请确认已选择正确的“退货单”模板。如需单独设置，请查看 [如何设置退货单打印模板](https://www.zhihuiji.cn/help/doc/2102)。
