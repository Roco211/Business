# 批次保质期＆业绩提成如何与智慧记AI进销存组合使用？

官方页面: https://www.zhihuiji.cn/help/doc/1719

**批次保质期、业绩提成是智慧记AI进销存的增值服务，可在智慧记AI进销存内订购使用。**

**批次保质期**

批次保质期是非常重要的商品标记，对小微个体户的老板们来说它不仅能够保证产品质量和安全，还能保证产品库存健康，对产品溯源有着极大的帮助。

**业绩提成**

业绩提成是一种激励员工提高业绩的方式，从而直接推动公司收入的增长。而对于员工而言，业绩提成则可以带来更高的经济回报，同时也能够增强其对工作的投入感和责任心。用智慧记AI进销存的业绩提成服务，可以让老板们自由设置多种提成规则。
