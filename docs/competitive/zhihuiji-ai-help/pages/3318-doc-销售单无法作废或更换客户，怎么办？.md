# 销售单无法作废或更换客户，怎么办？

官方页面: https://www.zhihuiji.cn/help/doc/3318

销售单无法更换客户或作废，通常是由于该单据已与其他业务关联被锁定。请优先检查以下两种情况：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/4adbccf3df29c5f8aba7113562bdea37.png)

## 已发生【收款】

**路径：** 销售单列表，点击【查看】销售单-【查看收款记录】，查看关联的收款单

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/21d0dabe9a7683c086fd4a3f95045ada.png)

**解除关联：** 【资金】-【收款】单据列表-【修改】收款单-【选择欠款单据】-取消勾选销售单，确认后保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/a4b44d256344e33f822bc4daf49bfe87.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/25bf6bf9b878502195516d9af50701b5.png)

## 已关联【销售订单】

**路径：** 销售单列表，点击【查看】销售单-【关联订单号】，查看关联的销售订单

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/b205bc91592e43f6c68142a0ad5e12b5.png)

**解除关联：** 作废当前销售单，再打开原始【销售订单】更换为正确客户，最后重新生成新销售单。
