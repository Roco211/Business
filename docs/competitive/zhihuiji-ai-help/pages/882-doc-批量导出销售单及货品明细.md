# 批量导出销售单及货品明细

官方页面: https://www.zhihuiji.cn/help/doc/882

**批量导出销售单明细**

**路径** ：【首页】-【销售】-【查看历史单据】-筛选销售单-【导出】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/dccd1a5ecd381f433f865830a156686a.png)

**业务场景** ：将销售单及货品明细导出到Excel表格文件中。

**功能说明** ：

1、支持导出单据说明。

2、支持导出销售单列表中的已收金额。

3、不支持导出关联的销售订单编号。
