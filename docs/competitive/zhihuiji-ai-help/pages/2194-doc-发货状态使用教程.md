# 发货状态使用教程

官方页面: https://www.zhihuiji.cn/help/doc/2194

视频描述

**使用场景：** 商户的交易过程，顾客先交定金，商户去备货发货，最后再收尾款的分步的流程，所以根据单据信息去提前备货和定期发货，是商户工作过程中必不可少的工作流程之一；

1.**操作路径：** 设置-系统设置-勾选销售单显示发货状态，默认是不勾选的。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/99662d6fd02725c6abbe3f384624ef5c.png)

2.查询发货信息：系统设置勾选后，销售单列表会显示发货状态；顶部支持高级搜索筛选发货状态（开启后历史单据默认已发货）

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/36a6ff1d869cc76a532e1bccc7c48182.png)

3.批量发货：勾选单据，点击批量发货，提示发货成功，状态从“未发货” 改为“已发货”

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/ec4ea612d354f7c0b9e62d58c32ea76e.png)

4.单个发货：查看某销售单详情，点击底部的发布按钮即可对该单进行发货，点击取消发货即可变成未发货状态。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/8905ad81f1bbbdb71253cfb72c22931f.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/894a390001dd0e16a864b51b6a1b2db7.png)
