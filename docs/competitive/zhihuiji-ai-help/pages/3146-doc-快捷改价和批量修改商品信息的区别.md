# 快捷改价和批量修改商品信息的区别

官方页面: https://www.zhihuiji.cn/help/doc/3146

**快捷改价** 里面**批量改价** 使用场景：所选商品价格都是按相同的**固定比例** 上调或者下调价格，无法按固定金额上调或者下调价格，主要用来调整**零售价和批发价**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202508/d78fd7452be5fef1908f11a1d5ca747b.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202508/0b383277b49f7fd8e0b435b7ef78d723.png)

**批量操作** 里**修改商品信息** 批量改价使用场景：所选商品价格可以按**固定金额或者固定比例** 调整，不同的商品调整价格可以不一样，主要用来调整**零售价、批发价、进货价和自定义的价格等级**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202508/8466259bbe2b5d2b8ee20ae6a7071893.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202508/9dab67829c3984b6b9ce19a1669253ef.png)

**二者主要区别：** 1、调整方式不一样


                   2、可以调整的价格不一样
