# 智慧记AI进销存远程打印单据

官方页面: https://www.zhihuiji.cn/help/doc/1237

云打印机能让你不在店内、异地多仓库，也可以远程打印各类单据！方便快捷！

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202201/af29ffd4fa926b58994c6a5f0a23fc8d.jpg)

**【云打印机联网】**

**第一步：使用前，云打印机一定要先开机。在云打印机侧面（背面）找到小程序二维码，用微信扫一扫进入打印机设备设置页面：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202312/368ad4c3ba50e4b2004497a0fe16589f.png)

【网络配置-WIFI配置】

1、点击【网络配置】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202312/9e87567756708efe6415b94c29f161d0.png)

2、点击【网络模式】的右侧下拉按钮选择【WIFI模式】（网口模式：网口模式无需设置WIFI）。

3、点击【WIFI名称】、【WIFI密码】，手动输入或【选择】一个能正常使用的2.4GWIFI网络，输入正确的WIFI密码，点击【确定】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202312/e23a42b2b3ceac34d3d016ae50923de0.png)

【网络配置-打印服务配置】

1、【打印服务】的右侧下拉按钮选择【自定义服务】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202312/304afaee416f00ce4aa087e080e19a4f.png)


    服务器域名：dasyun.zhihuiji.cn
    首选DNS地址：114.114.114.114
    备选DNS地址：114.114.114.115
    服务器IP：140.143.116.213
    控制端口：20171
    数据端口：20172


3、点击【保存】，提示“配置成功，重启即可生效，是否立即重启？”无需继续修改，点击【立即重启】，重启成功。

小技巧：云打印机也可以通过网线接入网络！若WIFI网络不稳定，推荐有线网口连网。云打印机配置如下：网络配置--网络模式--选择【网口模式】-保存。

**第二步：打开智慧记AI进销存，在当前的智慧记AI进销存店铺绑定云打印机** 。

操作路径：设置-打印设置-打印机设置-打印机管理-绑定云打印机

注意：智慧记及智慧记AI进销存只适配与官方出售的云打印机，请到商场进行购买

输入云序列号和设置打印机名称后，即可绑定成功

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202201/dc8bdf260a519487fcf928f4f2fee0b3.jpg)

启用路径：设置--打印设置--印机设置--根据打印印模板的【纸张类型 】，选择云打印机即可。
