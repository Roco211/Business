# 「手机端」收尾款销账

官方页面: https://www.zhihuiji.cn/help/doc/3346

对于尚未结清的销售单，您可通过以下任一方式完成收款：

  1. **在销售单详情页收款**
在销售列表中找到目标单据，点击进入详情页，点击底部的【收尾款】按钮。

     * 输入本次收款金额及优惠（如抹零）。
     * 系统会自动计算并显示剩余待收金额。**当剩余待收变为0时，该单据状态将自动更新为「已结清」** 。
     * 若仍有待收，后续可继续操作。

![收尾款](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/5e522ee7eaeefa3d948c371b4d43634f.png)

  2. **通过收款单批量/账期收款**
此方式适用于同时收取多笔单据的款项。

     * 进入【收付款】-【新增收款单】。
     * 选择客户后，**必须在下方的“关联单据”列表中勾选本次要结清的具体销售单** 。
     * 完成收款后，被勾选的销售单状态将自动变为「已结清」。

![收款单流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/6af69a64d6f4bcdaed8485a04860dae3.png)




**💡 提示** ：
两种方式创建的记录均可在【收付款】列表的“收款单”中统一查询。在销售单详情页点击「本单实收」也可查看该单的所有收款记录。
