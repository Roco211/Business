# 初始库存与初始成本设置

官方页面: https://www.zhihuiji.cn/help/doc/922

## 功能简介

（1）初始库存：指使用软件前商品的数量，在新增货品时可填入，后续不支持再修改。如库存有变化，可通过盘点单修改当前实际库存。

（2）初始成本：有盘点单、期初库存或负库存销售的情况，需填写初始成本，若未填写则会导致利润计算错误，点此查看[智慧记AI进销存商品成本问题](https://www.zhihuiji.cn/help/doc/2088)。
