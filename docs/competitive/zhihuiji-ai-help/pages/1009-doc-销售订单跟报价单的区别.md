# 销售订单跟报价单的区别

官方页面: https://www.zhihuiji.cn/help/doc/1009

**Q：** 销售订单跟报价单的区别？

答：报价单是销售最先给客户提供的价格信息，类似口头协议，流程上先有报价单；

接下来需进一步协商达成一致，报价单才进入正式销售环节，产生销售意向后，生成销售订单；

成交，生成销售单。
