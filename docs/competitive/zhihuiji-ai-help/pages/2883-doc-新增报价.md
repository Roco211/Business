# 新增报价

官方页面: https://www.zhihuiji.cn/help/doc/2883

当需要给客户提前设置好价格，开单时能直接带出正确的价格时，可以在报价管理提前设置好报价。

操作路径：：左侧栏设置-系统设置-客户/供应商设置，勾选管理客户报价，并在销售时带出客户最新报价和折扣。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/5312ccadea0550bcc701a77952d982ea.png)

然后点击左侧栏【客户】-【报价管理】-【新增报价】，可以根据客户或者根据商品报价。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/0cc0f02ea7606fc5af28a3a8d9f8d6ae.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/98178376a1381197cb40c845ba13573d.png)

## 根据客户报价

（1）输入要报价的客户名称

（2）选择要报价的商品

（3）输入最新报价

（4）点击保存

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/1e80744afc9c33a2529fe0e0fab05dac.png)

## 根据商品报价

（1）输入要报价的商品

（2）选择要报价的客户

（3）输入最新报价

（4）点击保存

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202501/aeb0039295c4d02338ec8107cf3bee27.png)
