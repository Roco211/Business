# 客户对账单的期初欠款没有显示出来是为什么？

官方页面: https://www.zhihuiji.cn/help/doc/3364

**客户对账单的期初欠款没有显示出来一般是以下两个原因导致的：**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/07c66c126fd4685960a9a9f9a0c5e9bd.png)

**原因一：** 自定义表头把 “累计欠款” 隐藏了，到自定义表头把 ”累计欠款“ 加上即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/9bda5529cf1063d6ac4d29a0db95ed2c.png)

**原因二：** 查询的时候选择了某一个门店了，没有选择全部门店

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/16dd61f0bafd2b893beeac9fa340f407.png)
