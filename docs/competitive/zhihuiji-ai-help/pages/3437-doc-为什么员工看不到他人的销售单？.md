# 为什么员工看不到他人的销售单？

官方页面: https://www.zhihuiji.cn/help/doc/3437

员工账号登录后看不到其他人的销售单，通常是权限未开启

**路径：** 【设置】→【角色权限】→【修改】→【敏感数据】→【单据权限】

勾选 **【查看其他用户的销售单】** ，保存即可。
