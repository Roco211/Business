# 积分设置教程

官方页面: https://www.zhihuiji.cn/help/doc/2099

操作路径：设置-积分设置。勾选消费送积分，然后设置积分规则保存。

1.开销售单收款后会自动对客户进行积分，如果没有收款的销售单是不会积分的。

2.只能对整单的实付金额积分，不能对某个商品单独设置积分。
