# 「手机端」设置销售单默认全收款

官方页面: https://www.zhihuiji.cn/help/doc/3359

**操作路径：** 【我的】-【设置】-【开单设置】

开销售单时，若希望系统自动计算并填充收款金额，简化收款步骤，可开启设置：【销售时，默认全部收款】

![设置路径](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/52f6cdd1a60e544a06cd3b7044e2c208.png)

**启用后效果** ：

  * 当您为**具体客户** （非零售客户/批发客户）开销售单时，系统将自动在收款金额栏填入该单的**应收总额** ，无需手动计算输入。
  * 您仍可根据实际需要，手动修改收款金额进行部分收款。



**请注意** ：

  * 此设置主要对允许欠款的**具体客户** 生效。
  * 系统预设的 **「零售客户」** 与 **「批发客户」** 本身**不支持欠款** ，因此无论此开关是否开启，为其开单时都会默认要求全额收款。
