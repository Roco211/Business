# 「手机端」如何隐藏首页数据

官方页面: https://www.zhihuiji.cn/help/doc/3504

在手机端首页，点击眼睛图标即可切换隐藏或显示数据。
系统会自动记住您的设置，下次访问时保持上次的显示状态。
