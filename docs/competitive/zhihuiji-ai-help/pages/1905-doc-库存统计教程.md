# 库存统计教程

官方页面: https://www.zhihuiji.cn/help/doc/1905

业务场景：当要查看商品的进出货明细以及成本的明细就可以查看库存统计。

视频描述

路径：分析-库存统计

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/ac00b9e56d6a6e3e1975f0d912692bb2.png)

1.客户输入日期，仓库，商品名称/货号查询。

2.点击导出可以导出库存统计报表。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/01f2830563de98f798ca3e9ea51c4933.png)

3.点击商品名称后面的【库存流水】，可以查看到该商品的进出货明细。如果觉得库存查询的数量不对，查询这里的库存流水就知道库存数量怎么来的。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/0dab6c41f4f5c3ed3fe67db3e08d4d2f.png)

4.点击商品名称后面的【成本明细】，可以查看到该商品的成本价。如果销售统计的利润不对，查看这里的成本明细就知道成本价怎么来的。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/20026d72fa1a73f70ea70708e7c19a10.png)
