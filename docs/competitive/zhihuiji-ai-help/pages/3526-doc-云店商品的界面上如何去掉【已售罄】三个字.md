# 云店商品的界面上如何去掉【已售罄】三个字

官方页面: https://www.zhihuiji.cn/help/doc/3526

**问题：** 云店商品的界面上如何去掉【已售罄】三个字，如下图所示：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/ee8fd6deabe53fa4c49d2da0b7daeedd.png)

**解决方案：** 点开设置--系统设置--选择勾选销售/调拨/组装/拆分时允许负库存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/27d0a8ae47d3b2c2bc0bf4f7d6aa1f1f.png)

注：允许负库存销售意味着商品即便显示售罄仍可正常售卖，因此无需设置售罄标识。
