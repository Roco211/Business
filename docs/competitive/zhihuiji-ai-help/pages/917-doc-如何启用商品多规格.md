# 如何启用商品多规格

官方页面: https://www.zhihuiji.cn/help/doc/917

为商品设置多规格

**操作路径** ：【商品】-【新增商品/修改商品】-【基础信息】- 勾选【启用多规格】

![启用多规格](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/2d4b4bf9997982718d94da7d69acf939.png)

**操作步骤** ：

  1. 勾选【启用多规格】
  2. 选择规格名称（如“颜色”）
  3. 选择具体规格内容（如“白色”、“黑色”）



![选择规格](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/9bcf0144202e9f41c30f03424e473ed5.png)

**适用场景** ：管理同一商品的多个属性，如衣服的尺码、颜色等。
