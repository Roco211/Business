# 如何修改商品初始成本价？

官方页面: https://www.zhihuiji.cn/help/doc/3536

**业务场景：** 以下场景需要填写正确的初始成本，以确保毛利计算准确：

  * 商品存在初始库存（使用软件之前已有的库存）
  * 商品入库时不使用进货单（正常建议先做进货单，如跳过此步骤，需填写初始成本）



> ⚠️ 商品资料中的「进货价」不参与成本计算，一定要正确输入「初始成本」。

**操作路径：**

【商品】→【商品】→ 搜索目标商品 → 点击【修改】→ 在「初始成本」中填写正确成本价 → 点击【保存】
