# 其他支出教程

官方页面: https://www.zhihuiji.cn/help/doc/1900

视频描述  **1.新增其他支出**

路径1：点击【资金】-【其他支出】旁的【+】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/7d9b92204cc416d37cd5d605d7712728.png)

路径2：点击【资金】-【其他支出】-【新增其他支出】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/970de7b4f85f9e5c6840282842da6b04.png)

（1）选择支出类型

（2）选择付款账户

（3）输入付款金额

（4）点击保存

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/d0231fa83abb8828f290197051f1bb01.png)

**2.其他支出列表**

路径：【资金】-【其他支出】

（1）可以根据单据日期，门店，支出类型，单据编号，业务员，备注查询其他支出单据。

（2）点击【导出】，可以导出到Excel表格。

（3）点击对应单据右侧可以【查看】【修改】【作废】单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/179729f7f9047addd76880a236059bf5.png)
