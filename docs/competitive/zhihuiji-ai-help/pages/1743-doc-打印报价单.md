# 打印报价单

官方页面: https://www.zhihuiji.cn/help/doc/1743

**操作步骤：**

1.设置-打印设置-设置报价单的打印模板。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/0a486ddd8e53c59d5c79c3380f979ca6.jpg)

2.开报价单界面底部有保存后打印的按钮，勾选后保存单据后会自动打印，默认是不勾选的。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/ef911915c17b9421fc76968dd30f7738.jpg)

3.查看报价单，右上角点击打印，然后选择打印模板，可以点击预览或者点打印。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/a8be16d690e9f2bfdcbb42713dd2d8c5.jpg)
