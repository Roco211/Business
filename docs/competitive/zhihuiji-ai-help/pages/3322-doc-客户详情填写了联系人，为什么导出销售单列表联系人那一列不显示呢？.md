# 客户详情填写了联系人，为什么导出销售单列表联系人那一列不显示呢？

官方页面: https://www.zhihuiji.cn/help/doc/3322

**问题：** 客户详情填写了联系人，导出该客户的销售单表格里面不显示联系人

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e9e2688ac5404b6f0035588ef7139919.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e0f2ef8fa6b88f14cbe67038e1a243be.png)

**解决方案：** 导出的销售单列表里面联系人对应的是客户收货信息里面的收货人，填写上即可

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/3ff0e2a9cff19ea17a8a3c7cb9626312.png)
