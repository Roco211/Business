# 小程序开通——小程序授权云店

官方页面: https://www.zhihuiji.cn/help/doc/3034

注册认证完小程序后，小程序需要一键**授权** 给智慧记AI进销存代生成云店，具体步骤如下：

1、首先在智慧记AI进销存电脑端的首页导航栏里，点击“云店”→左下角的“微信小程序”后会出现以下界面，用管理员的微信扫描右边的二维码进行授权

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/386b5794cf7bce385af0802853ba2579.png)

2、在手机端点击想要绑定的小程序，一定要选择底下小程序那一栏哦。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/65f1c3dd287a2e2b798345082423d373.png)

选中之后会出现下面这两个页面，也就表示你已经授权成功了。一般需要耐心等候1-3个工作日，就可以用小程序云店了。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/b54e26aad4b1640d999eecffcd5055a7.png)
