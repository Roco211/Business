# 复制、作废和分享销售单

官方页面: https://www.zhihuiji.cn/help/doc/879

## 复制销售单

**复制销售单路径** ：【首页】-【销售】-【查看单据】- 找到单据【复制】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202411/30ce39fa2fd89c5bf83c6ecbda4ac931.png)

**业务场景** ：客户在店里开的销售单，若想再次下单，老板们可直接点击【复制】，无需再次录入商品。提高店铺开单效率。

## 作废销售单

**作废销售单****路径** ：【首页】-【销售单】-【查看历史单据】- 找到单据【作废】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202411/90737a0b746810af8036d28ea05a33dc.png)

**业务场景** ：基于实际业务需求，有时候客户买的货不要了，需要删除/作废掉销售单

## 分享销售单

**业务场景：** 分享单据到客户微信用于对账

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202411/347b99d63c95ad55daaa0ec7c4c71873.png)

分享后客户扫码即可分享到客户微信 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202411/e823b00c5eb75a8d0b17f921107b9059.png)
