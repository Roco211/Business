# 模板商城

官方页面: https://www.zhihuiji.cn/help/doc/1822

**1.打开路径** ：

路径1：设置-打印设置-模板商城。

路径2：设置-打印设置-编辑模板。

(1)右侧增加10个模板，支持滚动；

(2)点击右上角【查看更多】进入模板商城；

(3)模板显示小图样式，名称和价格。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/fb2e1106462df6da08f4386d91d21cad.jpg)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/2acd5b28fabf01eaf5a3209a6d579846.jpg)

**2.单击模板会显示模板详情** ：

(1)详情有模板纸张、优势、说明、价格等信息；

(2)点击预览可以弹出预览效果，预览界面会显示商户的真实信息，支持打印；

(3)点击购买模板，跳转到官网进入购买流程。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/4708b944b1ff5a02cc4bd6d10864bfa2.jpg)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/7cc5a7863729e04f97f2066f5ab4acab.jpg)

**3.模板商城**

（1）顶部显示筛选，默认按最新发布时间排序。

（2）单据特点目前有显示logo、支持多联、收款码、有条款4个，默认全部勾选，勾选则显示。

（3）纸张类型默认显示全部纸张，默认全部勾选。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/08a730ab44b0fe914353274fdde7104f.jpg)

**4.购买流程**

1.在智慧记AI进销存里点击购买模板，直接进入官网提交订单

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/c8600f90401176a7d90fc4abd59d30b1.jpg)

2.提交订单-支付-支付完成

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/e478a3a03b9d89d4fd29f6ef370c1840.jpg)

3.返回智慧记AI进销存后，显示购买成功提示弹窗点击【使用模板】可进入编辑模板

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/5584b48ba19fa992ad9e359b6e854516.jpg)

  4. 在打印设置中，会自动创建已购买模板，在对应的单据分类下，购买的模板显示红色的【新购】标签。



![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/6372b53a55b33d723d8de78753183fa0.jpg)

5.原模板会显示【已购买】标签，点击使用模板可进入编辑页面
