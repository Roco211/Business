# 新增和修改客户

官方页面: https://www.zhihuiji.cn/help/doc/886

**新增客户**

**路径** ：【首页】-【客户】-【新增客户】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/8a83fdf3a7cc0f25f6393cb28ad55095.png)

**业务场景** ：通过客户资料及时了解客户信息，并利用客户信息开着相关业务工作，更好地满足客户需求。

**功能说明** ：

1、新增客户时，“客户名称”是必须填入的。

2、新增客户时，智慧记提供了以下3种新增方式：

**• 从客户-【新增客户】**

**• 从客户-批量导入新客户**

**• 销售开单时点击 “+” ：新增客户**

**修改客户资料**

**路径** ：【首页】-【客户】-找到客户-【修改】

**操作视频** ：https://v.qq.com/x/page/t0778d2nigc.html

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/1860fdd32a24e7868e6d8ace71b3d5e4.png)

**业务场景** ：客户资料可以设置对应客户分类和默认的价格等级、折扣等关联使用信息。修改客户资料，是日常业务中不可或缺的功能。

**功能说明** ：

1、修改客户资料的折扣时，不会影响到已保存的单据货品价格。

2、修改客户资料时，智慧记提供了以下2种修改方式：

**• 从客户-找到客户【修改】**

**• 从客户-批量修改导入客户资料**
