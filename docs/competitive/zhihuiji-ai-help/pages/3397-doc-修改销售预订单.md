# 修改销售预订单

官方页面: https://www.zhihuiji.cn/help/doc/3397

未完成的销售预订单支持修改，但已发货的商品不可编辑。

**操作路径：** 【销售】→【销售预订】→ 选择目标预订单 → 点击【修改】

**修改说明：**

  * **已发货商品** ：不可修改
  * **未发货商品** ：可修改数量、价格等信息，也可移除本商品
  * **新增商品** ：可继续添加新的商品



完成修改后，点击【保存】即可更新单据。
