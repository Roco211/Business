# 客户对账及分享账单

官方页面: https://www.zhihuiji.cn/help/doc/960

**客户对账**

视频描述

**路径** ：1.【资金】-【客户对账】-【对账】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/2b52a18ec423b95e58b11be849a7e3fb.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/b67085c5ae4c62de67b7c5a94717e971.png)


          2.【客户】-【对账】


![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/7a8c9202b94fa29bcf9ca798468c98cd.png)

可以筛选单据日期、门店、客户进行查询。

该功能主要针对的是销售已开单、但未收款的业务场景，可以得知还有多少款项未收到。

点击“明细”，可以看到当前的欠款是如何产生的，以及查看应收对账单详情。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/5484a177fa48a305937584952ed9c8e4.png)

点击【微信对账】，然后用手机微信扫码后可以把该对账单分享给客户。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202312/cc4ef25873b42955e7f96e797e2ffd6f.png)
