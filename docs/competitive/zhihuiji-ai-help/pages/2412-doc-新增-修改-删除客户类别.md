# 新增/修改/删除客户类别

官方页面: https://www.zhihuiji.cn/help/doc/2412

## 新增客户类别

视频描述

1.操作路径：【客户】-【客户】-点击左侧客户分类【编辑】-右侧【+】。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/698f558769ad6a7be2fa6cd6f33cd883.png)

2.如果要设置一级类别就点击全部后面的加号新增类别,上级类别选择无，然后保存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/5121e23d5c50add88d89a2d6d7d9a5b8.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/9a1be5a880a48f1b8047714d3cde5b4e.png)

3.如果要新增二级类别，就点击对应类别后面的加号新增类别。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/6b883d3faff3711a025b55277392534a.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/7c028eda77b406cf3e574b60e1a36b35.png)

## 修改客户类别

1.操作路径：【客户】-【客户】-点击左侧客户分类【编辑】-选中要修改类别然后点击中间的编辑按钮修改即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/a85b5699d2f9609e9ee92be335884d7a.png)

2.可以修改类别的名称和上级类别

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/3bf84bdf5b9c84492ac4d519a194b986.png)

## 删除客户类别

1.操作路径：【客户】-【客户】-点击左侧客户分类【编辑】-选中要修改类别然后点击最后面的删除按钮。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202401/05ba6a25baeee7efdf0d11791e5ef6c8.png)

2.注意：类别名称下面没有子类别和商品信息的类别才支持删除。
