# 如何设置云店主题风格

官方页面: https://www.zhihuiji.cn/help/doc/3305

**操作路径** ：左侧栏点击 **【云店】** \- **【云店装修】** \- 顶部 **【主题风格】**

在此页面，您可以：

  1. 选择您喜欢的主题颜色。
  2. 在预览区域实时查看效果。
  3. 确认效果后，点击底部 **【保存】** 按钮。
