# 库存预警教程

官方页面: https://www.zhihuiji.cn/help/doc/923

**业务场景：** 对货品库存进行监控，方便按业务要求提前获悉不足库存，不用相关人员实时查看，可通过查询库存预警报告。

  * **安全库存：** 为了应对不确定性，如需求突然增加、供应商延迟交货，防止缺货，保证服务水平；
  * **最低库存：** 当库存降到这一“补货点”，就必须立即下单采购，确保在补货提前期内，库存不会耗尽；
  * **最高库存：** 库存量的上限。用于控制库存成本，防止过度采购和资金积压，优化资金占用和仓储空间。



视频描述

**路径：** 【商品】-【修改商品】-【库存管理】，勾选启用，然后输入最低库存数量，安全库存数量，最高库存数量。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/0cbb9e3b76d8fc5d7f1d0d8c8a6ed49e.png)

当库存超出预期时，首页会显示库存预警数量，点击数量会跳转到库存预警界面、

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/25c1e5c9e385f8151016195b9509af43.png)

或者点击左侧库存-库存预警可以进入库存预警界面。库存预警界面可以根据仓库，商品类别，库存状态，补货基数，供应商查询。输入补货数量可以点击生成进货预定单，或者生成进货单。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/19b0561f0ba1bcd6fa92e4b92b0246fc.png)
