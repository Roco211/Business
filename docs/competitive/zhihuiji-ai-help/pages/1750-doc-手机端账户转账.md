# 手机端账户转账

官方页面: https://www.zhihuiji.cn/help/doc/1750

**用户场景：** 常见于销售账户和统计账户分开，账户录入错误，财务对账，财务管理等场景。

**功能介绍：** 商户可以将一个账户中的金额转入到另一个账户中。

**操作步骤：**

资金-选择账户-点击要转出的账号后面的三点水，然后点击转账。
