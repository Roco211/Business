# 如何新增收支类型？

官方页面: https://www.zhihuiji.cn/help/doc/948

视频描述  **收支类型**

**路径** ：【资金】-【其他收入】/【其他支出】旁的【+】-【收入类型】旁的【+】，进入到收支类型。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/3c4aae2b9b34f128493c7444b7c201e8.png)

除了业务往来，营业过程中还会产生诸如房租、水电、分红等其他开支。

在这里可以新增收支类型，也可以对已有的账户修改或删除。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/f2e99bb8d9d5ca8ea95c2aa879d26b78.png)

新增账户类型：点击左上角的“新增账户类型”，在弹出的小窗输入账户名称，选择记收入还是记支出。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/b4f0699af8212a4e9b034e9934fcd06c.png)

修改/删除账户：点击每个账户右侧的“修改”“删除”按钮。

如果删除该账户，相关联的业务单据将一起删除。
