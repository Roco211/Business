# 收款单操作教程

官方页面: https://www.zhihuiji.cn/help/doc/860

视频描述

**路径：** 【资金】-【收支】-【收款】右侧的“+”。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202310/5e6c6f0bc29565f809cb49a6ea0fbb60.png)

**1.直接收款**

输入客户名称和金额保存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/07eb5cefe4698eae2f1c43d3e5279fc1.png)

**2.按单收款和按单优惠**

（1）选择选择门店

（2）选择收款的客户

（3）选择欠款单据，勾选要收款的单据关联

（4）输入本次的收款金额，点击保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/9e355fa8a918051fa894f8d4bfca2bd5.png)

**注意：**

1.输入的收款金额要大于或者等于本次结算金额，否则会提示“本单收款不能小于本次结算”。

2.如果需要抹零可以点击本次结算的优惠按钮。

3.如果只是收一部分的款，需要填写欠款单据后面的本次收款金额。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/9cb6ce50c916d89e8c9f46a8a625ca3c.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/70b290752a6c93df4aa308a5790d264d.png)

**3.收款单详情**

点击收款单列表的查看按钮，或者在保存收款单后会显示收款单的详情，左上角可以点击修改，作废，查看单据列表，右上角点击导出PDF，分享，打印。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/d20f36b76c52e0047c7994f19a8ec8f2.png)

**4.收款单列表**

**路径：** 【资金】-【收支】-【收款】

（1）在收款单列表，可通过筛选单据的日期、客户名称、单据编号，业务员名称，收款类型，备注来查询具体某一个单据。**收款类型有直接收款和按单收款两种，直接收款是指没有关联销售单的收款单，按单收款是指关联了销售单的收款单。**

（2）点击导出可以导出收款单列表

（3）在对应的单据右侧有查看，修改，分享，作废的操作

（4）可勾选是否”隐藏作废单据“。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/1ac2c58a77df397905593c36b866024e.png)
