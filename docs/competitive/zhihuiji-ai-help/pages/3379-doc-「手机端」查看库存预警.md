# 「手机端」查看库存预警

官方页面: https://www.zhihuiji.cn/help/doc/3379

**操作路径：** 【更多】→【库存】→【库存预警】

![进入库存预警列表](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/95c2afd6a68be265d120901a6703a4aa.png)

**在【库存预警】页面，您可以：**

  1. **按状态筛选**


  * **全部** ：查看所有触发预警的商品。
  * **库存不足** ：仅查看当前库存量 **< 最低库存** 的商品。
  * **库存较低** ：查看当前库存量 **< 安全库存** 的商品（此结果包含“库存不足”的商品）。
  * **库存过多** ：查看当前库存量 **> 最高库存** 的商品。


  2. **按其他条件筛选** 您还可以结合**商品类别** 、**仓库** （若已启用多仓库）和**供应商** 进行筛选。



![库存预警筛选功能](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/c31d4c69a483470beda234ba1a6a5bc8.png)

  3. **快速补货** 点击右上角「**去进货** 」，可快速发起补货操作：


  * **选择补货方式** ：切换为「补货至安全库存」或「补货至最高库存」（默认为“补货至安全库存”）。
  * **勾选商品与调整数量** ：系统默认带入已筛选的预警商品（若未筛选，则带入“库存不足”和“库存较低”的商品），并自动计算建议补货量，您也可手动调整。
  * **完成补货** ：确认后，点击「生成进货预订」或「生成进货单」并保存单据即可。



![去进货功能入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/56e2d4cf66dc2e773ecdbff7516e39f8.png)

* * *

**💡 温馨提示：**

只有已设置库存预警并且当前库存达到预警条件的商品，才会显示在此页面中。
