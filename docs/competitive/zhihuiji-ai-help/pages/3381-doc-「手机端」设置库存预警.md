# 「手机端」设置库存预警

官方页面: https://www.zhihuiji.cn/help/doc/3381

手机端支持设置库存预警功能，帮助您精准掌握库存状态，及时补货，避免缺货或积压。

**操作路径：** 【商品】 → 【新增/编辑商品】 → 【库存预警】

![单规格设置库存预警](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/1cef83695c041265f77ae1b8f7e6c5c8.png)

**设置库存预警值：** 您可以为商品设置三个关键的库存阈值，并保存生效：

  * **最低库存** ：当**库存量 < 设置值**时触发“**低于最低库存** ”预警，提示需紧急补货。
  * **安全库存** ：当**库存量 < 设置值**时触发“**低于安全库存** ”预警，提示库存已低于建议水平。
  * **最高库存** ：当**库存量 > 设置值**时触发“**高于最高库存** ”预警，提示库存可能存在积压。



**多仓库设置（如已启用）：** 若您的店铺已启用多仓库功能：

  * 您可以为不同的仓库分别设置不同的预警值。
  * 或勾选「**所有仓库预警值相同** 」进行统一设置。



![单仓库与多仓库设置对比](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/d8e2dd688f64f9778459202c1cc72dfe.png)

* * *

**💡 温馨提示：**

  * 所有设置过预警并达到条件的商品，均可在【库存预警】页面统一查看与管理（路径：【更多】→【库存】→【库存预警】）。
  * 建议根据商品的销售与补货情况，定期回顾并调整预警值，以保持最优库存水平。
