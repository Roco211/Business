# 商品条码批量生成

官方页面: https://www.zhihuiji.cn/help/doc/909

**批量生成条码**

**路径：** 【商品】-【商品】-【批量操作】，勾选或筛选商品后，点击【生成条形码】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/f65a987a98d1a4f38b2291641c889122.png)

选择只修改选中的商品，或修改当前查询条件下的所有商品，点击确认 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/003177ecc1fcdc60e3e3864bb808679b.png)

**业务场景：** 商品无条码，可以通过此方式快速生成条码，方便出入库管理。
