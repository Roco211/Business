# 开单收银台操作教程

官方页面: https://www.zhihuiji.cn/help/doc/1525

**一、什么是开单收银台** ？

针对老板们在门店开单和收银的需求，智慧记AI进销存，秉持简单好用的原则，打造专门的开单界面，突出产品“极致开单”的特性，为老板们推出了开单收银台，**与智慧记AI进销存数据互通** ，能更好满足零售、餐饮、服装、母婴、生活服务等多个行业的门店管理需求。

**二、开单收银台有哪些功能和亮点** ？

1、扫码收银，收款语音播报，

2、门店取单/挂单，告别排队困扰

3、超大图标全屏显示，简单易用好用

4、打印小票，简单方便

5、数据和智慧记AI进销存打通，方便查询

**三、开单收银台操作指引**

**1、进入开单收银台**

操作路径：【首页】-【收银】-【开单收银台】-【立即使用】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/5f40051cb462f28c12722be8eb219b4a.jpg)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/7fa13c1173e9dc504721bca43dafb4b6.jpg)

**2、选择商品开单收银**

操作路径：【扫码/点击右侧选择商品】-加入购物车-【收款】，可以选择【现金收款】、【扫码收款】或者【记账收银】。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/0ba256351ad13c887743365f15025015.jpg)如果您是选择商品，支持在右侧查看热销商品、常购商品，以及查看商品分类或者输入商品名称搜索商品，更加方便的找到指定的商品进行开单

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/c5896963b60c3d23c2d784941b01280c.jpg)

**3、修改商品**

操作路径：【购物车】-点击【指定商品】-可修改价格、数量、规格、单品备注

![修改页面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/6814c75496c2e6674cd4ff0dee3de406.png)

**4、给客户优惠**

操作路径：【优惠】-【整单折扣】/【整单立减】，支持自定义折扣力度和自定义立减金额

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/c6c43ba01a1264c02846dcacd42215f5.jpg)

**5、给单据抹零**

在收银设置开启抹零后，点击【抹零】则根据设置的规则给客户的单据抹零

操作路径：右上角【设置】-【抹零设置】，选择抹零规则

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/bee4a537fa43fd188fd5136aaca1a3c8.jpg)选择好抹零规则后，点击【抹零】即可

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/a94ba8a4f2dbcc1aa8c1e8f925e79dfa.jpg)

**6\. 整单备注**

操作路径：【整单备注】-【输入备注信息】-【确定】。会记录最近三条的备注供选择

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/d297f3739965ff471b4e8319f468771e.jpg)

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/2abf1dda157fb5b0033a288b6887b6de.jpg)

**7、取/挂单**

当在店铺经营繁忙时，可以使用取/挂单功能

操作路径：【挂单】/【取单】，在购物车有商品是，点击为挂单（挂单数量目前限制50）；购物车没有商品时，点击为取单。

挂单，会记录客户、商品（主要是价格）、挂单时间

取单，如果商品、客户被删除/停用，取单会移除商品或客户；其他信息有变更，则会更新。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202208/17ebe26494f41b93fa1ab6ca71d76179.jpg)
