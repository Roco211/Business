# 如何查看毛利异常的商品？

官方页面: https://www.zhihuiji.cn/help/doc/3535

**查看路径：** 【分析】-【销售统计】-【按商品统计】

可点击「销售毛利」或「毛利率」排序，快速定位到毛利异常的商品。
