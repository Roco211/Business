# 多单位商品输入主单位价格会自动换算辅单位的价格吗？

官方页面: https://www.zhihuiji.cn/help/doc/3043

新建/修改商品时，启用多单位，输入主辅单位和换算率之后，填写主单位的价格，若辅单位没有价格，则会自动计算辅单位的价格，但是写入辅单位的价格不会反写主单位的价格。

举例：设置商品主单位为瓶，辅单位为箱，1箱=10瓶

当输入「瓶」的进货价为10元，会自动计算「箱」的进货价为10*10=100元

但输入「箱」的进货价为100元，不会自动计算「瓶」的进货价，需手动输入主单位的价格。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202506/c736ad7675245658d53b7a1612fff9b0.png)

产生单据后反填价格逻辑：

①产生进货单会反填/更新对应单位的进货价，但不会根据该单位价格自动反填其他单位价格

举例：保存商品时，主单位「瓶」的进货价为10元，「箱」的进货价为100元

创建进货单，单位选择「瓶」，进货价输入20元，保存后，查看商品详情，「瓶」的进货价为20元，「箱」的进货价依然为100元。

②产生销售单，若对应单位原本没有零售价/批发价，则会反填对应单位价格，同样也不会根据该单位价格自动反填其他单位价格，若对应单位已有价格则不会反填。

举例：保存商品时，主单位「瓶」的零售价为20元，「箱」的零售价为200元

创建销售单，选择零售客户，单位选择「瓶」，零售价输入30元，保存后，查看商品详情，商品的零售价没有变化。

保存商品时，主单位「瓶」的零售价为0元，「箱」的零售价为0元

创建销售单，选择零售客户，单位选择「瓶」，零售价输入30元，保存后，查看商品详情，「瓶」的零售价为30元，「箱」的零售价依然为0元
