# 云店商品分享

官方页面: https://www.zhihuiji.cn/help/doc/2815

方式一：点击要分享的商品详情--右上角小箭头--分享当前图片到 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/74a1563164afe7acb49da7d410f20326.png)

方式二：点击商品中间的小箭头，如下图所示： ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/506bb3556d0dcf6b24ac8e68b05f01cb.png)

**使用场景：** 1.客户不知道订什么货，为客户定向推荐商品； 2.新品上市/促销商品，分享到朋友圈进行推广，吸引客户下单； 3.想推荐商品给同行/朋友，带来业绩增长。
