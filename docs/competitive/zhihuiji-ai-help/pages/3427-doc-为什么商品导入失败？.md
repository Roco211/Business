# 为什么商品导入失败？

官方页面: https://www.zhihuiji.cn/help/doc/3427

商品导入失败通常与模板使用不当或数据格式错误有关。请按以下步骤排查：

**1\. 确保使用正确的模板**

  * **请务必下载系统提供的专用导入模板** ，并严格按照模板格式填写。
  * **切勿直接使用“商品导出”功能生成的表格进行导入** ，两者格式不兼容，会导致失败。



![下载导入模板](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/dad40ad2c4cd4f8b5cefe9b565ced58e.png)

**2\. 检查并遵守模板规范**

  * **请勿修改、删除或移动模板中的表头（列标题）** 。
  * **请勿调整模板的列顺序、单元格格式或增加系统未定义的列** 。



![提示模版错误](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/dcd995ff6ecc19467ce28c17b8cffcfa.png)

**3\. 下载并查看失败报表**

如果确认模板无误但导入仍失败，系统会提供详细的失败报表。

  * 在失败提示界面，点击“下载失败报表”。



![下载失败报表](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/af5a14fceb55bc43009c926134708944.png)

  * 打开报表，查看“失败原因”列，系统会明确指明每一行数据的具体错误。根据报表提示修改对应数据后，重新上传文件即可。



![查看失败报表](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/f270101dbf6985ac4a7d1eaff262af43.png)

**注意事项**

“导入新增”功能专用于**批量创建新商品** 。如果您需要**批量修改** 现有商品的信息（如价格、分类），请使用独立的“批量修改”功能。

> 详细操作指南：[商品信息批量修改](https://www.zhihuiji.cn/help/doc/2829)
