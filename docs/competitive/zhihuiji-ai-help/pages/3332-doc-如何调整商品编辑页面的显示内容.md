# 如何调整商品编辑页面的显示内容

官方页面: https://www.zhihuiji.cn/help/doc/3332

**操作路径：** 【商品】-【商品】-【新增商品】/【修改商品】- 点击右上角【点击设置】

  1. 在新增或修改商品的页面，找到并点击右上角的【点击设置】按钮。
  2. 在弹窗中，勾选您需要显示的信息字段，取消勾选希望隐藏的字段。
  3. 点击【确定】，页面将立即刷新，只显示您勾选的字段。



![字段设置入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/6c03938e5ab11f5affaa9388149eb3d7.png)

**适用场景**

  * 简化编辑界面，只保留常用字段，或调出被隐藏的字段
  * 字段包括：条形码、编号/货号、商品类别、供应商、品牌、重量、备注、图片、规格、自定义属性
