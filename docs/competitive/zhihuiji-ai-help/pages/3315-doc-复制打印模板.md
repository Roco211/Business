# 复制打印模板

官方页面: https://www.zhihuiji.cn/help/doc/3315

**适用场景：**

  * 退货单：将表头标题“销售单”字样修改为“退货单”，并可调整其他内容；
  * 【二等分】模板适配为【三等分】样式：现有的打印模板是为二等分纸设计的，但需要使用三等分纸打印，并可调整页面布局。



**1、打印模板设置：** 左侧【设置-基础设置】-【打印设置】，点击目标模板；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/2bd126762d752e560d642e7b263fdfc4.png)

**2、复制出新模板：** 在打印模板编辑界面，点击右上角【复制】，填写新模板名称；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/7d1443fc0b876f852774f4b4f2e46dff.png)

**3、保存新模板：** 重新调整打印内容（比如将标题“销售单”改成“退货单”），选择纸张大小，如有需要可勾选默认模板，保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/dbb437269c2f17596a37ae0ac7939795.png)

**4、预览打印** ：销售单打印时，选择复制出的新模板

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/b6d38ba04f618d8c61618992a5be88e7.png)
