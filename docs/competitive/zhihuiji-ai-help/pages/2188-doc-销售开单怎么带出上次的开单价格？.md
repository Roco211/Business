# 销售开单怎么带出上次的开单价格？

官方页面: https://www.zhihuiji.cn/help/doc/2188

**路径：** 设置-系统设置-单据设置-勾选销售时自动带出客户上次结算价格和折扣，自动获取商品的上次结算价和上次折后价。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202411/483a6f082863045e6b98a870aeb6f764.png)

有开过销售单的客户，下次开单会自动带出上次的结算价格。**注意：之前保存过的销售单有修改过开单价格的，会自动记录修改后的价格。**
