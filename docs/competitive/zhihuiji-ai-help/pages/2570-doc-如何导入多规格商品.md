# 如何导入多规格商品

官方页面: https://www.zhihuiji.cn/help/doc/2570

视频描述

**操作路径：** 【商品】-【商品】-【导入新增】 ![导入新增入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/75046d2f14314d40c9197531e3eea71d.png)

**(1) 下载模板**

选择下载 **“多规格商品导入模板”** 。 ![下载多规格模板](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/f8fc6987041ec56c39f515f6a59b9a31.png)

**(2) 填写规格（关键步骤）**

  * **规格名称** ：在“多规格”列填写，如 `颜色/尺码`（用英文“/”分隔）。
  * **规格内容** ：根据名称顺序，在对应列填写具体值，如 `红色`、`S`。
  * **填写示例** ：商品“铁制红箱1#”有2种颜色和2种尺寸，需创建4种组合。 ![填写示例](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202402/64e82710f9fde8afe31df17e99ecfb60.png)



**(3) 上传文件**

保存填好的`.xlsx`文件，回到导入页面点击上传，完成导入。

**常见问题**

**问题一：多规格与规格内容不匹配**

  * **现象** ：系统提示“多规格与规格内容不匹配”。
  * **解决** ：检查并补全每个规格名称对应的所有规格值。 ![错误示例1](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202402/e7996aa63dfdc29be309414a0e735c22.png)



**问题二：规格内容组合重复**

  * **现象** ：系统提示“规格内容组合重复”。
  * **解决** ：在表格中查找并删除完全相同的规格组合行。 ![错误示例2](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202402/b6812d3ddc31f9de33f04dea18bdbe04.png)
