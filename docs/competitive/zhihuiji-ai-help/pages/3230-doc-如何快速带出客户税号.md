# 如何快速带出客户税号

官方页面: https://www.zhihuiji.cn/help/doc/3230

新增客户时，下拉页面至底部，在 “客户税号” 栏填写对应信息保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/1bc43ec8f23e4d3e55973e6b60f345a5.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/595dff8e2ba5ba1c1ec54488d7698ade.png)

设置- - 打印设置 选择要设置的单据模板进入编辑界面 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/7f933009c07064cfc73ba947a458f04f.png)

长按左侧 “客户税号”，将其拖到中间画布的合适位置，最后保存设置。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/402733ee62aeb4c74446cd0512fa0390.png)

点击已有税号的客户，预览销售单以查看效果。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/14a94a20edb24da99017a2c180cf78c7.png)
