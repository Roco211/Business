# 前放纸打印错位

**打印机前进纸打印错位**

解决方案：前放纸打印机设计限制，打印完一页后回退再次打印时，可能导致在第一页上重叠打印第二页内容。为避免错位，通常需手动取出第一页后再打印第二页。建议改成后进纸打印。
