# 设置销售/收款默认收款账户

官方页面: https://www.zhihuiji.cn/help/doc/3390

在销售或收款时，可为当前登录账号设置默认收款账户，以提升开单与收款的效率。

**操作路径：** 【设置】→【用户偏好设置】→【销售/收款时，支持设置默认收款账户】→ 启用后选择默认账户

**说明：**

  * 此设置仅对当前登录的账号生效。
  * 设置后，开单或收款时将自动选中此处设置的账户作为默认收款账户。
