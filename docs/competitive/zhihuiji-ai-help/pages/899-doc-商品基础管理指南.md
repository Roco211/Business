# 商品基础管理指南

官方页面: https://www.zhihuiji.cn/help/doc/899

商品基础操作视频

## 功能简介

商品是智慧记AI进销存中最核心的业务资料，进货、销售、库存管理等所有业务都围绕商品展开。本指南将带您快速掌握商品的**新增、修改、查询、停用与删除** 五大基础操作。

## 新增商品

您可以通过多种方式将商品录入系统。

**(1) 操作路径**

【商品】-【商品】-【新增商品】

![新增商品与批量新增入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/5ecce39b7d8c72f1063838b239ee579e.png)

**(2) 三种录入方式，任您选择**

  * **扫码识别（最快）** ：使用扫码枪扫描商品条形码，**自动识别并填充** 商品名称、图片等信息，高效准确。
  * **智能推荐（便捷）** ：在商品名称中输入关键词，系统将**智能推荐相关商品** ，双击即可完成录入，带出标准名称、条码和图片。
  * **手动填写（灵活）** ：根据需要，自由填写各项商品信息。



![智能录入](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202406/e9c0b3cc26e38052bc0da69423f99776.png)

![填写商品基础信息](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/532cffeb9fef43969972d0c99855bfa3.png)

**(3) 完善其他信息**

  * **商品价格** ：设置零售价、批发价、进货价等。
  * **商品库存** ：设置初始库存与成本。



**注意：初始库存指第一次录入货品信息时已有的库存，保存商品之后无法修改初始库存，后续库存变化可[修改当前库存](https://www.zhihuiji.cn/help/doc/858)。**

![填写商品价格](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/0a239b509a54bb39b63fb9e29b3cc2e1.png)

![填写商品库存](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/520b7377f03a89d9159b4eb5cf2022c7.png)

## 修改商品

当商品信息发生变化时，您需要及时更新。

**操作路径**

【商品】-【商品】- 找到目标商品 - 点击【修改】

![修改商品入口](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/83f7e8edd9dd7457a1990f07f3ebc76d.png)

**请注意** ：修改商品资料的价格时，**不会影响** 已保存单据的实际价格。

## 查询商品

快速找到您需要的商品。

**(1) 快速搜索**

在商品列表顶部的搜索框，输入商品名称、简拼、条形码等即可查询。

![快速搜索](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/9309b5080e5245378891ef23076673a7.png)

**(2) 高级查询**

展开“高级查询”，可根据品牌、供应商、重量等更多条件精准筛选。

![高级查询](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e0c83e5ae9707c1741e9bc7a2e39814e.png)

## 停用与删除商品

### 停用商品（推荐）

对于**暂时不销售但有历史记录** 的商品，建议使用停用功能。

**效果** ：停用后商品不会在开单时显示，避免干扰，同时**完整保留所有历史数据** 。

**(1) 单个停用**

在商品右侧点击【更多】→ 选择【停用】。

![停用商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/dc0c7fc0c9397dd73266200056552043.png)

**(2) 批量停用**

勾选多个商品后，点击顶部【批量操作】-【启用/停用】，在弹窗中选择停用。

![批量停用路径](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c5c794542ff99b688259a4b27dd7529e.png)

![选择停用](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/62262b740b6f64d90b8d57883154c8d6.png)

### 删除商品

仅适用于**彻底清理误添加且无任何业务记录** 的商品。

**(1) 单个删除**

在目标商品右侧点击【更多】→ 选择【删除】。

![单个删除](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c7f5818f7d7fa1b08fc8107076f89eb2.png)

**(2) 批量删除**

勾选多个商品后，点击顶部【批量操作】-【删除】。

![批量删除](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e04ef195f93c1428d4946ef75da2488b.png)

**(3) 删除限制**

**若商品已产生业务数据，系统将禁止删除**

  * 商品关联历史单据时无法直接删除
  * 需要先[处理完所有关联单据](https://www.zhihuiji.cn/help/doc/3298#%E5%8A%9F%E8%83%BD%E7%AE%80%E4%BB%8B)后才能删除商品



![删除失败提示](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/d9ad233196cbe3160ee333cc8bc4a479.png)
