# 进货价管理指南

官方页面: https://www.zhihuiji.cn/help/doc/926

## 业务场景

日常业务采购时，需要用到货品的进货价，属于采购的基础价格资料。

## 功能简介

填写商品进货价后，日常开单采购时，会自动带出货品的进货价。

添加/修改进货价时，智慧记AI进销存提供了以下5种方式，根据实际需求选择一种方式即可：

• 新增/修改单个商品时填写进货价

• 导入新增商品时填写进货价

• 批量修改商品进货价

• 快捷改价修改进货价

• 开单进货时快速回填进货价

## 添加/修改进货价

### 新增/修改单个商品时填写

**路径：** 【商品】-【商品】- 新增/修改商品 -【商品价格】-【进货价】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/ddab9517151c8338397741ec5d726412.png)

### 导入新增一批商品时填写

**路径：** 【商品】-【商品】-【导入新增】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/75046d2f14314d40c9197531e3eea71d.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/286904a9f07348308b064cd6558988a9.png)

**路径：** 【商品】-【商品】-【批量曹组】-【修改商品信息】

### 快捷改价

**路径：** 【商品】-【商品】-【快捷改价】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c1b2ac693b7816b2e28ec9a7e111a377.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/333ad404b7f01b9af357db2f463ccf12.png)

### 通过开单进货，回填进货价

**路径：** 【进货】-【进货】-【新增进货单】

填写单价后保存单据，将自动回填更新此单价至商品资料的进货价

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/d892c8d09eeeb4127ff8601c89915a31.png)

### 注意事项

添加/修改商品进货价，不会影响到货品成本和已发生业务的进货单价格。
