# 农药商品扫码出入库

官方页面: https://www.zhihuiji.cn/help/doc/2966

## 功能简介

本功能专为农药商家设计，支持通过扫描农药商品二维码快速完成商品信息录入和出入库操作，提升工作效率。

## 重要注意事项

  * **仅支持32位农资农药类商品** 二维码
  * **大部分农药商品** ：扫码后可自动带出商品名称和信息
  * **少量特殊情况** ：因登记证号问题可能无法自动识别，需要手动录入补充



![支持的二维码示意图](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202503/a440480b8f566f5d0acef7e399a976ed.jpg)

## 操作步骤

### 行业设置

**操作路径** ：【设置】-【店铺信息】

  * 在行业类型中选择【农资农药】，并保存



![行业设置界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/83f95b6e80a7ffd5a3ae5913b7754ae8.png)

### 扫码录入商品

**操作路径** ：【商品】-【新增商品】

  1. 确保已切换至**英文输入法**
  2. 使用扫码设备扫描农药商品二维码
  3. 系统自动带出对应的商品信息
  4. 补充其他必要信息后保存



![扫码录入界面](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202503/05f6fe5d70d0dd4665e658a39ed0936c.png)

### 扫码出入库

  * 完成商品录入后，在开单出入库时可直接扫描同一二维码
  * 扫码出入库时，需确保已切换至**英文输入法**
