# 云店商品展示划线价

官方页面: https://www.zhihuiji.cn/help/doc/3528

**路径：** 云店 → 云店设置 → 商品设置 → 勾选「划线价」

开启后，当商品对客户的展示价格**低于零售价** 时，零售价将自动显示为划线价。
