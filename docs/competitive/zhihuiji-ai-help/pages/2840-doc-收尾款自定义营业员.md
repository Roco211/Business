# 收尾款自定义营业员

官方页面: https://www.zhihuiji.cn/help/doc/2840

**背景：** 以前的版本收尾款时默认业务员为开单的业务员，商家无法自己修改，会有商家期望尾款能划给实际的收款人，方便自己在用资金流水查看各人员收款金额时，快速判断每个人收了多少款，然后再去找相关人员核对。
