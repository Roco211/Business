# 「手机端」新增员工

官方页面: https://www.zhihuiji.cn/help/doc/3421

**手机端新增员工操作路径** ：【我的】→【店铺管理】→【员工管理】-右上角【+】-填入员工信息后，点击右上角【保存】，邀请员工扫码加入店铺即可。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/9812316dabe21545dde9c9e617bff7b7.png)

**注意事项：** 员工的权限取决于所属角色，点此查看[如何设置角色权限](https://www.zhihuiji.cn/help/doc/3506)
