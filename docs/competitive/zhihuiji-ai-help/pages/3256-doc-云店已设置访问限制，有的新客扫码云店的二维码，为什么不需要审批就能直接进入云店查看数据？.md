# 云店已设置访问限制，有的新客扫码云店的二维码，为什么不需要审批就能直接进入云店查看数据？

官方页面: https://www.zhihuiji.cn/help/doc/3256

**原因：客户给顾客提供的二维码有误导致的**

如果客户是点开“客户--查看--尚未成为云店客户”这里的二维码，这里是直接邀请客户注册成为云店客户，所以不需要审批。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/828996b9eebfa0ffb1b3f69c5b3ee7c4.png)

如果是需要审批的客户，需要发送“云店--我的云店--右下角二维码”这里的二维码给客户

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202510/5703507ef1479347b1eed73f6d25001f.png)
