# 打印单据教程

官方页面: https://www.zhihuiji.cn/help/doc/1410

**一、功能介绍**

为充分满足客户在销售、收款、进货、付款等场景的下业务流程的流转，增加单据打印功能。

视频描述

**二、操作路径**

1\. 首先设置打印模板

操作路径：【设置】-【打印模板】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202110/37b50fd9add4ef2c072be58f3c2edbb9.png)

目前支持销售单和销售订单、进货单和进货订单、以及收款单和付款单的打印

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202110/a3092e68c9670df1d470d0bba6a1fbc9.png)

默认模板为二等分，可以选择A4或者三等分模板打印

点击模板，可以进入详细设置，已销售订单为例：

操作路径【设置】-【打印模板】-【销售订单】-【A4】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202110/f8237a91c066a7c412651e1f0987cb0d.png)

可自由选择在打印单据顶部出现的信息

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202110/d6713cd463401fe8a6772b3890bca2d5.png)

双击左侧打印单上信息，可以自主修改编辑该字段名称

不需要打印的信息，不点击勾选即可。

**2\. 启动打印**

开单后，点击进入对应单据，点击右上角【打印】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202110/3b158ea224530960c655b177ff3f6656.png)

可自主选择需要打印的模板类型，进行预览和打印

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202110/ef4267402dc05f8df1b44da82638640a.png)

至此，就完成了一次单据打印。
