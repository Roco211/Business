# 快捷改价操作

官方页面: https://www.zhihuiji.cn/help/doc/906

**快捷改价**

视频描述

## 业务场景

当商品因进货价变化、市场价格变化、经营策略等原因需要**批量调整售价** 时，可使用“快捷改价”功能，快速完成价格更新，大幅提升效率。

## 操作路径

**路径1：** 【商品】-【商品】-【快捷改价】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/cae9a1fa1a75961eb7aeb43286aebad6.png)

**路径2：** 【商品】-【价格管理】-【快捷改价】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/13f0b85afc2d0b670b5de286823be7e1.png)

## 操作方法

**方式一：直接改价（适用于精确调价）**

（1）进入【快捷改价】界面。

（2）在商品对应的价格输入框中，直接输入**新的价格** 。

（3）全部修改完成后，点击 **【改价完成】** 。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/195a7d24d0a2e7d59640e7abf8eacf53.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/da720ca377033797b8db976ff412989f.png)

**方式二：批量按比例调价（适用于统一折扣或涨价）**

（1）进入【快捷改价】界面，**勾选** 需要调价的商品。

（2）点击 **【批量改价】** 按钮。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/a3f028984e70a97c7521c7fa7dd39906.png)

（3）在弹窗中设置调价规则：

**调价范围：** 选择对「选中的商品」或「当前查询条件下的所有商品」生效。

**价格类型：** 选择需要调整的价格，如零售价、批发价等。

**计算基准：** 以商品的「进货价」、「原零售价」、「原批发价」等作为基准。

**调整方式：** 上调或下调指定的**百分比** 。
