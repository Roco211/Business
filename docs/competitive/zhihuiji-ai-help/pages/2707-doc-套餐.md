# 套餐

官方页面: https://www.zhihuiji.cn/help/doc/2707

## 新增套餐

当您有需要将商品组合销售时，如新品和畅销品组合、临期商品组合、节日活动套餐等；

这时候可以使用智慧记AI进销存的商品套餐功能，在开单时能够快速选择，提高开单效率。

（1）路径：点击底部【商品】-顶部【套餐】-右上角【+】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/f701e75a3f40c41891f3b21d71180b07.png)

（2）输入套餐名称，选择组成套餐商品信息，填写好套餐的零售和批发价格保存即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/b22dd2c28a9376104a9d09365b59a86f.png)

## 修改套餐

（1）点击套餐名称后面的【...】，可以打印标签，编辑套餐，停用套餐，和删除套餐等；

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/13c45eed9d2c6f1ef2697f5a9bd413fc.png)

（2）点击套餐名称可以进入到套餐详情界面，点击右上角的编辑按钮可以修改套餐信息，点击底部的开单可以进入到开销售单界面。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/8236cb637cd282d78126ee2e2ea0567a.png)
