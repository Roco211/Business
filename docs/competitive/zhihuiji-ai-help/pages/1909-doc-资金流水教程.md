# 资金流水教程

官方页面: https://www.zhihuiji.cn/help/doc/1909

1.路径：点击左侧资金-资金流水。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/f0e95ca0d734da44f94b17f3b88cd2ab.png)

2.可以选择单据日期，门店，账户和业务员查询，同时也可以输入单据编号，关联单据编号和备注查询。点击导出按钮可以导出到Excel表格。

单据编号是指有填写金额交易的单据编号，关联单据编号是指有关联收款/付款单的销售/进货单的单据编号。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/6b8ae36de1ac1ea8179619f53e825a2e.png)

3.资金流水底部可以翻页查看，也可以选择每页显示的条数。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202307/4d5a9791cd4aab239a5b7543fd390594.png)
