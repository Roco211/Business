# 【开单】快速新增和查看销售单

官方页面: https://www.zhihuiji.cn/help/doc/878

## 新增和查看销售单

视频描述

**新增销售单路径** ：【首页】-【销售】-【+】

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202105/628bec9247293b62869daef2fa7c024e.png)

**业务场景** ：确认货品出库的证明，通过销售单来体现货品转移，是货品实际出库的重要标志和原始凭证。

**功能说明** ：

1、新增销售单时，必须填写客户名称，才能记录到该客户产生欠款。支持0收款。

2、新增销售单时，支持销售出货和销售退货两种开单模式：销售出货填正数，库存自动减少；退货填负数，库存自动增加。

3、支持销售折扣，包括整单折扣和客户专属折扣，并且支持折上折的打折方式。

**查看销售单路径** ：【销售】-【销售】-【查看】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/e62c351e932f637672be1d6af1038d37.png)

**业务场景** ：满足老板查找已开出【销售单】的需求，方便业务处理。
