# 开票状态使用教程

官方页面: https://www.zhihuiji.cn/help/doc/2221

**用户场景：** 系统无开票记录，商户无法判断该客户的单据是否已开票，若多次开票则多次计税，会给商户造成直接经济损失

视频描述

（1）操作路径：销售-销售，找到对应的销售单查看，点击顶部的标注已开票，开票状态就变成已开票，如果点击错已开票，也可以改成未发票状态。默认新增的销售单是显示未开票的。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/a1cb5b92ba5b4e54ab791f2cd23fedc6.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/f7dc87029fc0c950ce85e7b4e7d9cbec.png)

（2）销售单列表点击左侧的设置按钮，把开票状态添加到已显示字段，就可以直接在销售单列表显示开票状态，并且可以选择发票状态查看单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/61f677adeb750673e9548f279413aa54.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/53a102c5f5341dd164851e7abd0d05be.png)

（3）销售单列表勾选对应的销售单，然后点击批量操作，改为已开票，就可以批量更改发票状态。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/82116362fd3e62cdac18ccc44f0f2959.png)
