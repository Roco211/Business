# 「手机端」分享单据

官方页面: https://www.zhihuiji.cn/help/doc/3358

**操作路径：** 【销售】- 进入单据详情页 - 点击【分享】

您可以将销售单、预订单或退货单快速分享给客户或同事，支持多种格式。

  1. **找到并点击【分享】按钮**
在目标单据的详情页右上角，找到并点击【分享】按钮。

  2. **选择分享格式**
系统将弹出分享选项，您可以选择：

     * **单据卡片** ：简洁的信息摘要，适合在即时通讯软件内发送，客户可点开查看详情和单据单据凭证。
     * **单据图片** ：生成直观的单据截图。
     * **PDF文件** ：生成标准的PDF格式文件，便于打印或存档。
  3. **选择分享渠道**
选择格式后，点击底部【分享至微信好友】，您可以选择相应联系人完成发送。




![分享单据流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/bdfa950e8decbb763c9d3cf44e47c3a9.png)

**💡 提示** ：
分享内容会包含单据的核心信息（单号、商品、金额、客户等），方便对方快速确认。
