# 小程序开通——小程序微信认证

官方页面: https://www.zhihuiji.cn/help/doc/3031

**注：请自行根据自身所属行业确认认证所需要的证照文件！** 视频版教程请点击[链接](https://www.zhihuiji.cn/help/video/1818)查看

微信认证需要在**微信公众平台** 进行，入口是https://mp.weixin.qq.com/点击“前往小程序”，可以看到以下这个界面，点击“认证”：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/cbb322295a6c3b56b0118d328f51c6b0.png)

  1. 同意协议：商户会看到一份微信公众平台认证服务协议，直接最底下勾选，然后点击下一步。



![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/ed3094fa51e6df0e79d8b8f9c80a826c.png)

  2. 填写资料：选择机构类型——**企业法人/个体工商户** ；然后需要上传一份申请公函。请注意，申请公函需要点击“下载公函模板”进行下载打印，在跳转的窗口最底下点击“打印本页”，连接打印机进行打印，打印之后，需要手写将红线地方填写完成，然后加盖公章/法人签名，加账号联系人签名。填写完成后，再将公函扫描或者拍照上传即可。请注意，请认真核对公函，打印、签字、加盖公章后上传。若信息有误，请返回注册或认证流程修改资料。如果无法使用打印本页按钮，请使用Ctrl+P快捷键或者在空白处点击右键打印。



![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/efd9fcf4ce6ff249c9f6e82ea8dfc7d7.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/dd0b12ba4ef1b79bdae13e3b4bca555b.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/8238aa2dc1df76d0e7523616a4233f43.png)

填写企业资质信息。注意小程序申请是一定**需要营业执照** 的。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/8238aa2dc1df76d0e7523616a4233f43.png)

填写对公账户，如果个体工商户没有对公账户的话，个体工商户无对公账户，可填写与营业执照上法人一致的个人银行卡号：

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/0b660093b0e521776add6a5c088d1ddc.png)

最后补充认证联系人信息，扫码后点击下一步即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/d8bc768e0d6f1ed3b859a69ef444f2e0.png)

点击下一步，补充发票信息后，需要交纳300元认证审核费用，**该费用由微信平台方收取，非智慧记实际收取** 。请注意，如果审核失败的话，300元是不予退还的，因此请确认信息无误后再提交。（审核费用一年一交。）

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/a9ddc76426132a75ff63dab1b3af7e18.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/948a1ca62fb6bfca8b26ef35b2dfb84c.png)

其他进入微信认证的路径：设置-基本设置-微信认证，在微信认证一栏点击详情，即可申请小程序的认证。 申请完成后，在认证审核过程中会有第三方审核机构联系你，与您核对认证主体信息，以及会往您留的账户汇小额打款，后续审核人员都会致电您确认。 接下去就是补充小程序基本信息了
