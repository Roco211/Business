# 如何设置不同营业员开单默认仓库和门店？

官方页面: https://www.zhihuiji.cn/help/doc/2825

**场景：** 一个门店一个仓库，两个营业员，需要营业员1开单选择商品默认门店库存、营业员2开单选择商品默认仓库库存。

**操作方法：** ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/9ed3b3ca5039ed2be4beaa7f927f36ab.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/f0f329bc495ac22ba236ab32a763d5cb.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/39df419bfd2c3f68f34e9776183c0753.png)

这样设置好之后营业员1开单商品就是默认门店库存，营业员2开单商品就是默认仓库库存 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/c35fe62abcb1c3eb45a4bf65685b4887.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/3ee76d220a1bcd9b34992bf0f13cd1cd.png)
