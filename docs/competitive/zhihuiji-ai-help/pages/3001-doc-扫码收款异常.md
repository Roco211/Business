# 扫码收款异常

官方页面: https://www.zhihuiji.cn/help/doc/3001

扫码收款异常，多为客户支付时网络波动导致异步支付延迟：

1、扫码收款后，**请务必让客户展示支付成功页面** 进行人工核验；若支付失败，需重新发起支付，或线下收款再自行补录系统；

2、登录乐刷商户平台查询交易流水，若存在记录但系统未同步，资金将按风控规则于T+1个工作日17:00前自动更新支付结果，到时如未到账请联系客服处理。
