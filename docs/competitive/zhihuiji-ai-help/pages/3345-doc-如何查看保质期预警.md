# 如何查看保质期预警

官方页面: https://www.zhihuiji.cn/help/doc/3345

为商品启用保质期管理并设置提前预警天数后，您可以：

  1. **查看预警数量**

登录后，在【首页】底部的【重要提醒】模块中，查看“保质期预警”的数字，表示即将到期的商品数量。

  2. **查看预警详情**

点击“保质期预警”的数字，页面将自动跳转至【库存】-【保质期查询】页面，并自动筛选出【保质期状态】为“即将过期”的商品列表。
