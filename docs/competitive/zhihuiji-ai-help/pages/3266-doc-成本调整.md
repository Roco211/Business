# 成本调整

官方页面: https://www.zhihuiji.cn/help/doc/3266

**使用场景：** 当库存商品的账面成本与实际成本发生重大差异，并且无法通过调整历史单据来修改

1.盘点盈亏（库存残次/变质/过期）

2.商品调价，对于时尚品、电子产品、生鲜等，市场价或公允价值持续下跌，且预计难以恢复

**操作步骤：** 分析--库存统计--成本明细--成本调整

**注意：**

1.成本调整需要一段时间才能生效，调整后请稍后查看

2.成本调整操作后不可撤回，请谨慎操作

3.成本调整是调整当时的成本，不会影响商品以前的成本
