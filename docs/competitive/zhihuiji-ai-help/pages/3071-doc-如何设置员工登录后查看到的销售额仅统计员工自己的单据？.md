# 如何设置员工登录后查看到的销售额仅统计员工自己的单据？

官方页面: https://www.zhihuiji.cn/help/doc/3071

设置员工登录后查看到的销售额仅统计员工自己的单据，且不希望员工能查看到其他员工单据的统计数据，可以在设置-角色权限，编辑员工的角色权限时：

1、敏感数据中，不勾选「查看其他用户的销售单」，勾选「查看首页关键数据」 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/8b3c2c82b1ee510277297d079e9bb9d8.png)

2、分析模块不勾选权限 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/2bcda0c8848f8ca554718666a734e120.png)

按以上设置后，员工登录智慧记AI进销存APP，可以通过更多-经营概况，查看到根据员工自己作为业务员的单据统计到的销售额、笔数、毛利数据，且不能看到其他员工单据的统计数据 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/a1d1d9de54c21c62bad34b723c3cb7e3.png)
