# 「手机端」商品查价

官方页面: https://www.zhihuiji.cn/help/doc/2108

**操作路径：** 【商品查价】→ 选择客户 → 输入商品名称

![商品查价路径](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/7df03c214209f004181e33ae00b7b068.png)

**查询结果展示：**

  * **建议售价** ：系统推荐价格
  * **等级售价** ：该商品各价格等级对应价格
  * **历史记录** ：该商品近期的销售和进货记录



**💡 适用场景：**

客户现场询价时，快速查询商品价格并报给客户。
