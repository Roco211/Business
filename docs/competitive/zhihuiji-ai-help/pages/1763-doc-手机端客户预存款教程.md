# 手机端客户预存款教程

官方页面: https://www.zhihuiji.cn/help/doc/1763

**1.预存款录入：** 点击左侧销售-底部选择客户-客户详情点击当前预存款-存款。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/054c11c25caafb49a4bdea2e59719299.jpg)![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/1b074ff17a1ad670c4d8acf690c5b34e.jpg)

**2.销售单抵扣余额：** 开单界面点击底部的明细-勾选抵扣，然后再点保存即可。默认是自动抵扣的，如果需要不抵扣把勾去掉，然后点击结算账户保存即可。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/fa05dea18c4729d2f1685518f6f5d728.jpg)![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/6e06c85f91f1928c2e20c5eb7451b537.jpg)

**3.收款单抵扣余额：** 左侧资金-收款-新增收款单选择客户名称，勾选客户预存款抵扣，然后点击保存即可。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202306/10366d95f304608c481f4242eebe2a52.jpg)
