# 进货统计教程

官方页面: https://www.zhihuiji.cn/help/doc/1904

操作路径：分析-进货统计。

1.可以选择按商品统计和按供应商统计。

2.可以选择单据日期，门店，商品名称/货号，商品分类，业务员查询。

3.进货总金额不包含运费。

4.点击【导出】可以导出进货统计报表。

5.点击表头的进货金额和进货数量可以重新排序。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/ba366feddbbb87a365aa4a5ca1c7bb9b.png)

6.按照商品统计，点击商品名称后面的【查看】按钮，可以查询到该商品在每个供应商的进货金额和数量。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/0d2a5f3431012d4c800f1b7f62a352a5.png)

7.按照供应商查询，点击供应商名称后面的【查看】按钮，可以查询到该供应商进货的每个商品的总数量和总金额。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202308/2ca321ce9ed66af0440e69b5c0e791dc.png)
