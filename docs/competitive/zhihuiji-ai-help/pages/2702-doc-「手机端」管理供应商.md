# 「手机端」管理供应商

官方页面: https://www.zhihuiji.cn/help/doc/2702

## 新增供应商

操作路径：【更多】-【供应商】-右上角【+】，输入供应商的详细信息保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/9338fcf1dd51731b05220c3bc17609f2.png)

## 修改和删除供应商

点击供应商名称后面的【...】，然后点【编辑】和【删除】即可修改供应商和删除供应商信息。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202404/3a2a532506dd4c393a9eb38651f043be.png)

注意：没有发生业务的供应商才可以直接删除，已经开过单据的供应商需要找到对应的单据（如：进货订单，进货单，付款单）作废后才能删除供应商。
