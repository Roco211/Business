# 员工门店/仓库权限设置

官方页面: https://www.zhihuiji.cn/help/doc/2824

**应用场景：** 员工只负责自己所属门店/仓库的管理和开单发货，不能操作其他的门店/仓库。 **操作步骤：** 设置--员工管理--修改--选择所属门店--勾选仓库--确定

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/001a9d1b09b62be53f406211208b4f86.png) ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/bc23f3be18d2a54f3b37e60864a10c49.png)

设置好之后营业员开单就只能选择有权限的门店/仓库

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202408/3a0cdc5b2c1f13cc82bcdf3724eaf2eb.png)

只能看到有权限门店/仓库的库存数量（包括开单、库存统计、库存查询等查询商品数量的地方）
