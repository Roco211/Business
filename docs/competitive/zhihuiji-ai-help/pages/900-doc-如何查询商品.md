# 如何查询商品

官方页面: https://www.zhihuiji.cn/help/doc/900

**操作路径：** 【商品】-【商品】

在顶部搜索框，输入商品名称、简拼、条形码、规格、货号或备注，快速定位商品。 ![快速搜索](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/9309b5080e5245378891ef23076673a7.png)

**1\. 使用高级查询**

如需更精确的查找，可展开**高级查询** ，按商品名称、规格、品牌、重量、供应商，以及其他自定义属性条件筛选。

![高级查询](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/e0c83e5ae9707c1741e9bc7a2e39814e.png)

**2\. 隐藏无库存/停用商品**

  * 查询时，可勾选 **“隐藏无库存商品”** 或 **“隐藏停用商品”** ，让列表更简洁。
  * 默认勾选隐藏停用商品 ![隐藏设置](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/144b8b0f8da943897b8abb3597584070.png)
