# 门店和仓库的区别？

官方页面: https://www.zhihuiji.cn/help/doc/1627

门店是进行销售出库的；
在库存管理上，可以用门店管理库存，也可以门店用关联仓库管理库存；
简单来说，门店管钱，仓库管库存。
