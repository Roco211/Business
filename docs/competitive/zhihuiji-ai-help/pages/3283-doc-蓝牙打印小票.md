# 蓝牙打印小票

官方页面: https://www.zhihuiji.cn/help/doc/3283

**1、添加和配对蓝牙打印机**

**路径：** 手机端，销售单详情页 - 左下角打印-打印预览页，右上角【打印设置】-【打印机管理-蓝牙打印机】添加蓝牙打印机，找到需要配对的蓝牙打印机，点击名称自动配对

![配对流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/888a02aac2f3c41d59fa61c450022d4a.png)

**2、在打印预览页，选择【打印模板】和【目标打印机】进行打印**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/dce527b8d20d31c2dfb65a16cb7012c0.png)
