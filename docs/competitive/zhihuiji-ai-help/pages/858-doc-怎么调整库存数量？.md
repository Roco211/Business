# 怎么调整库存数量？

官方页面: https://www.zhihuiji.cn/help/doc/858

视频描述

场景： 软件里面记录的库存和实际库存不一致需要调整库存

## 方法一：做盘点单修改

做盘点单修改数量可以批量商品同时修改。

**路径** ：【库存】-【盘点】-【新增盘点单】

1.可以选择锁定仓库。锁定之后，盘点这段时间内不允许发生出入库业务操作，除非解锁或者是盘点结束。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202204/6a9795fb986e2dbb503a9270e00c9a56.jpg)

2.在下面的盘点单中选择要盘点的商品，会显示现存量，这时输入实际数量，系统会自动判断当前的盈亏数量。修改好实际数量点击保存即可。

![](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202204/2bb4dd12c5f029c8d4006eed5ab5f979.jpg)

## 方法二：查看商品界面调整当前库存数量

商品查看界面调整数量只能对单个商品进行修改数量。

1.路径：点击左侧导航【商品】-【商品】-找到要修改的商品名称后的【查看】按钮。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202412/0e4cdc1cb83f4dec0aac8200c54afa39.png)

2.进入到查看商品界面，滑动到当前库存数量界面，点击数量旁边的编辑按钮修改。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202412/ca18b87a00121e13988c247720a6ffde.png)

3.输入实际库存数量，然后点击确认即可。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/01c83a2534fc507c613f685da79e5553.png)

**注意：**

（1）在查看商品里修改数量，不会生成盘点单，不产生盈亏，不计入经营利润，操作记录和库存流水可查；

（2）做盘点单修改会产生盈亏金额，是会影响到经营利润。
