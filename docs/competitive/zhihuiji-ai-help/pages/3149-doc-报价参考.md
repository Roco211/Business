# 报价参考

官方页面: https://www.zhihuiji.cn/help/doc/3149

**使用场景：** 开销售单定价需要参考零售价、成本价、历史结算价等等，又不想去查询以前的单据。

**操作步骤：** 设置--系统设置里面勾选需要显示的参考报价，勾选后新增销售单单价下拉框就会显示对应的价格作为参考
