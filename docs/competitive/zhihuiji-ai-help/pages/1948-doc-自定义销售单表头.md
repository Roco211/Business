# 自定义销售单表头

官方页面: https://www.zhihuiji.cn/help/doc/1948

**业务场景：** 根据销售需求增减业务，优化开单流程，自定义开单界面。

点击销售单列表或者新增销售单界面表头左侧的设置按钮。

自定义表头由已显示字段和可选字段两部分合并组成，可点击“+”加入显示字段，或者“x”关闭显示；拖拽可调整字段顺序，简单易用。
