# 【完整指南】智慧记AI进销存·使用指南

官方页面: https://www.zhihuiji.cn/help/doc/3483

## 第一步：基础设置

> 用5分钟把店铺基础信息配置好，后续开单管货更顺畅。

### 店铺信息设置

  * 设置店铺**名称、Logo、联系电话、地址**
  * **操作路径** ：【设置】 → 【商户信息】 ![智慧记商户信息设置页面，可填写店铺名称、地址、电话、上传Logo](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202602/49f4f97f95ccb88045125d60d56d5f94.png)



### 打印模板设置

  * 系统已预置默认打印模板，可根据实际需求修改（如**添加Logo、收款码** ）
  * **操作路径** ：【设置】 → 【打印设置】 → 点击要编辑的模板 ![智慧记打印模板编辑界面，可调整小票样式、添加Logo和收款码](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202602/67dc3877014cd6941450802b24f7732c.png)



### 员工账号与权限（如有多个店员）

  * **设置角色权限** ：如销售只能开单，库管只能管库存
    * **操作路径** ：【设置】 → 【角色权限】 → 【新增角色】
  * **添加员工账号** ，分配角色（销售/库管/财务）
    * **操作路径** ：【设置】 → 【员工管理】 → 【新增用户】 ![智慧记员工管理页面，可新增员工并分配角色权限](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202602/0e3f9c3492f95a7d70665086446f4042.png)

## 第二步：新增商品（把货搬进系统）

> 商品录入系统后，开单时可直接选择，提升开单效率。

### 提前录入商品

您可以根据手头的资料和场景，选择最适合的录入方式：

场景 | 推荐方式 | 操作路径
---|---|---
有Excel商品清单 | **电脑端Excel导入** | 【商品】 → 【商品】 → 【导入新增】（下载模板填写后上传）
有进货单/商品册照片 | **手机端AI拍照识别** | 【商品】 → 点击右上角“+” → 【AI快速录入】 → 【图片识别】
有Excel/PDF文件 | **手机端AI文件识别** | 【商品】 → 点击右上角“+” → 【AI快速录入】 → 【文件识别】
商品有条码 | **手机端/电脑端扫码录入** | 手机端：【商品】 → 点击右上角“+” → 【扫码录入】
电脑端：【商品】 → 【商品】 → 【新增商品】 → 使用扫码枪扫描
新增单个商品，想快速带出信息 | **电脑端智能搜索** | 【商品】 → 【商品】 → 【新增商品】 → 输入关键词搜索
新增单个商品，手动填写 | **电脑/手机通用** | 【商品】 → 【新增商品】/点击“+” → 手动录入

![智慧记电脑端商品列表页，可查看、导入、新增商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/ec5c8d276fcb607940148758aaac3240.png)

![智慧记手机端新增商品页，支持手动录入、扫码、AI识别](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/780907aaa604e7fda87dff4fd0c29b86.jpg)

### 开单时遇到新商品

开单时如果发现商品还没录入，可以直接在开单过程中完成新增，无需中断流程：

  * **手机端** ：在商品选择页面点击右上角“+”，填写信息保存后自动带回开单界面
  * **电脑端** ：在开单页面直接输入新商品名称，系统会标记为“新”，保存单据后自动生成商品档案



⚠️提示: 若商品有**初始库存** ，建议通过商品列表新增；通过电脑端开单直接创建的新商品，初始库存默认为0。 ![智慧记开单页面，直接输入新商品名称系统自动识别](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/9e4f8005154a009358dfe2f921f9b66f.png)

## 第三步：日常开单（进货/销售）

### 进货开单（入库）

  * 录入**供应商、商品、数量、进价**
  * 添加商品方式：搜索、选择、扫码、AI识别清单批量添加、Excel导入
  * 保存后**库存自动增加** ，应付账款同步更新
  * **操作路径** ：【进货】 → 【进货】 → 【新增进货单】



![智慧记电脑端新增进货单页面，可选择供应商和商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/f45c2f0bcb1107feee0151183a7d270f.png)

![智慧记手机端新增进货单页面，支持扫码和AI添加商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/486b242f5438b8d0b9a60eae3ff09f1f.png)

### 销售开单（卖货）

  * **选择客户** ：可直接选老客户，或临时新增
  * **一客一价** ：选择客户后自动带出上次成交价格
  * **选择商品** ：搜索、选择、扫码、AI识别批量添加
  * **确认金额** ：系统自动计算总价、折扣、应收



您可以根据场景选择开单方式：

场景 | 推荐方式 | 操作路径
---|---|---
不想动手打字 | **手机端语音开单** | 【首页】 → 【销售开单】 → 【AI开单】 → 【语音识别】
客户拿着单据来 | **手机端拍照开单** | 【首页】 → 【销售开单】 → 【AI开单】 → 【拍照识别】
微信收到客户订单 | **手机端文本粘贴识别** | 【首页】 → 【销售开单】 → 【AI开单】 → 【文本识别】
商品多/批量加商品 | **电脑端操作更便捷** | 【销售】 → 【销售】 → 【新增销售单】

![智慧记电脑端新增销售单页面，支持一客一价和商品快速选择](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/daea075431b36a2629da783b6912e79a.png)

![智慧记手机端新增销售单页面，支持语音、拍照、文本AI开单](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/e24551349d3c3eddc08a18b3f0eb2c49.png)

### 打印单据

  * 支持**蓝牙/远程/电脑** 打印
  * **操作路径** ：
    * **手机端** ：开单后或查看历史单据时点击「打印」，或设置「单据保存后自动打印」
    * **电脑端** ：开单时选择「保存并打印」或查看历史单据时点击「打印」



![智慧记电脑端打印预览界面，可选择打印机和打印格式](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/31488b4dc15efbd4b52c9d9e8a5bb90a.png)

## 第五步：库存管理

> 货卖了多少？还剩多少？要不要进货？

### 查看库存

  * 实时查看商品**库存数量、成本、库存总金额**
  * **操作路径** ：【库存】 → 【库存查询】 ![智慧记库存查询页面，可查看各商品实时库存和成本](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/e2cc6a50800aa95317c31f3c7ee8870f.png)



### 入库/出库操作

  * **进货入库** ：采购到货后，录入进货单，自动增加库存
  * **销售出库** ：开单后自动扣减库存
  * **盘点调整** ：定期盘点，修正库存差异
    * **操作路径** ：【库存】 → 【盘点】 ![智慧记库存盘点页面，可录入实盘数量系统自动调整差异](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/913697861fcad483faea51bf06a6c090.png)



### 库存预警处理

  * 系统自动计算**库存短缺、超出** 的商品
  * 可根据预警**快速生成进货单**
  * **操作路径** ：【首页】 → 【库存预警】 → 查看详情 ![智慧记库存预警页面，展示短缺和超储商品并可一键进货](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/56fb3f87312e39643fbc344dd16f6f7c.png)

## 第六步：多仓管理

> 多个仓库怎么管？

### 新增仓库

  * 启用「**多仓库** 」并在系统中添加仓库
  * **操作路径** ：【设置】 → 【系统设置】 → 勾选「启用多仓库」；【设置】 → 【仓库管理】 → 【新增仓库】 ![智慧记仓库管理页面，可新增、编辑、启用/停用仓库](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/cd88f1ce12202f9ebda1781731734bc4.png)



### 商品调拨

  * 门店/仓库间调货，手机一点即可完成
  * **操作路径** ：【库存】 → 【调拨】 → 【新增调拨单】 ![智慧记新增调拨单页面，可选择调出仓库、调入仓库和调拨商品](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/537b08989c7cd61cea40aa9bbac724ec.png)



### 仓库应用

  * 开单（销售单/进货单/盘点单等）时可为商品**选择出/入库仓库** ![开单选择仓库](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/59d14078c849417bb96525860107688c.png)\- 查询库存时可**筛选查看指定仓库** 数据，也可看全店汇总
    * **操作路径** ：【库存】 → 【库存查询】 → 选择仓库筛选 ![库存查询筛选仓库](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/a7853495df3a57e7ca83fad20c965c69.png)

## 第七步：进阶功能

> 用熟基础功能后，试试这些能让生意翻倍的‘黑科技’。

### AI生意助手

  * 自动分析**热销商品、库存、利润**
  * 生成**营销文案** （朋友圈、商品描述）
  * **操作路径** ：【首页】 → 【AI生意助手】 ![智慧记AI生意助手页面，提供经营分析和营销文案生成](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/d11dcc0233c4f053c5697e9cc6a432d9.png)



### 微信小程序商城（云店）

  * 开通后客户可在**微信自助下单**
  * 订单**自动同步** 到AI进销存系统
  * **操作路径** ：【云店】 → 立即开通/免费试用 ![智慧记云店小程序商城页面，客户可在微信端自助下单](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/65beb177ee2b612d9af158e33ee10f9f.jpg)



### 员工业绩提成

  * 设置**提成规则** ，系统自动计算
  * **操作路径** ：【销售】 → 【业绩提成】 → 立即订阅/免费试用 ![智慧记业绩提成设置页面，可设置提成规则和查看计算结果](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202603/6aea1db1567ebcc3a85145f16c81d55c.png)

## 📌 新手常见问题

问题 | 解答
---|---
数据会丢吗？ | 云端存储，自动备份，**不会丢**
能几个人一起用吗？ | 支持增购员工名额，多员工同时使用，**按权限管理**
手机和电脑数据通吗？ | **实时同步** ，在哪都能看
不会操作怎么办？ | 右上角“帮助中心”查看文档，或联系客服
