# 条码标签打印

官方页面: https://www.zhihuiji.cn/help/doc/910

## 业务场景

商品本身没有条码，可以通过此方式打印条码，贴上商品，方便扫码管理。

## 操作路径

【商品】-【商品】- 勾选要打印的商品 -【批量操作】-【打印标签】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/167cad5250dbc2d547ec5f9532c1b83a.png)

自动选择默认模板，也可手动切换为其他模板，模板设置可点此查看[商品标签打印模板设置教程](https://www.zhihuiji.cn/help/doc/3269#%E6%89%93%E5%8D%B0%E8%AE%BE%E7%BD%AE)

若未设置打印机可根据提示进行设置

确认打印份数后点击打印 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/58f2d66d715fe04d4514d22601c98a6a.png)

## 注意事项

  * 若商品没有条形码，需要先生成商品条形码，点此查看[批量操作生成商品条码](https://www.zhihuiji.cn/help/doc/909)

  * 需要提前链接好标签打印机。
