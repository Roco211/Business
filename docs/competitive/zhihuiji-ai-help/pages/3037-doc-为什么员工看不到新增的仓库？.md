# 为什么员工看不到新增的仓库？

官方页面: https://www.zhihuiji.cn/help/doc/3037

创建新仓库后，员工开单时无法显示或选择该仓库，通常是因为**未给员工配置仓库权限** 。

**解决方法**

**路径：** 【设置】→【员工管理】→ 找到对应员工 → 修改 → 勾选新增的仓库 → 确定
