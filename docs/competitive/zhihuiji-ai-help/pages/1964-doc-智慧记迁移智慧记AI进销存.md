# 智慧记迁移智慧记AI进销存

官方页面: https://www.zhihuiji.cn/help/doc/1964

操作路径：智慧记点击系统设置-迁移智慧记AI进销存-勾选我已了解数据迁移智慧记AI进销存功能，然后点击数据迁移智慧记AI进销存。

**注意：**

1.仅能迁移货品基础资料、客户资料和供应商资料，单据不支持迁移。

2.需要在智慧记会员有效期内才能迁移数据，开始迁移前，请先执行云同步，保证各端数据统一。

3.迁移后，智慧记没有任何改变还能正常继续使用，但是智慧记和智慧记AI进销存数据不互通的。
