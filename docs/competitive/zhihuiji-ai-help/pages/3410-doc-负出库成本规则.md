# 负出库成本规则

官方页面: https://www.zhihuiji.cn/help/doc/3410

**库存统计报告：期初金额 + 新增金额 - 减少金额 ≠ 期末金额**

**解决方案：** 检查负出库记录，由于负出库成本算法跟正出库不一致，等式无法成立。建议不要负出库，可以把进货单日期调整到前面日期。

**正出库成本规则：** 默认取上次进货后的库存结余成本，无进货则取商品初始成本价；

**负出库成本规则：** 补货不会影响此前成本，仍默认取最新进货的结余成本；补货时库存变0，则默认补货单价为此时结余成本。

**例：新增金额16元，减少金额10元，期末金额8元**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/7a3511c8173ca6be62e0447fb9386d86.png)

**负库存时补货：** 最新进货成本1元 * 结余数量8 = 结余金额8元，此时等式不成立。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/b3a718ad94e20b19b3e6477965346adf.png)

**调整进货单日期，改成非负出库：** 上次进货后的库存结余成本1.231..元 * 结余数量8 = 结余金额约9.846元，此时等式成立。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/e6fe2149236a81fce1dc96a8ac7e0266.png)
