# 销售单列表导出金额合计与软件合计数据不一致是什么情况？

官方页面: https://www.zhihuiji.cn/help/doc/3439

例：销售单列表应收金额合计为767.42 导出数据显示金额合计为834

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/ee5778aa80f703ef4b8ea5723394c167.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/e063e7ee4f068c7c0aafb3b47d784e33.png)

答：导出的金额仅剔除了商品的单行折扣。若单据使用了整单折扣、税额、运费或优惠，直接合计单行金额会不准确，应合计''本单应收''而非单行商品''金额''。因此，''金额''不能直接作为比对项。
