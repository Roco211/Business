# 云店客户如何解绑

官方页面: https://www.zhihuiji.cn/help/doc/3529

**路径：** 客户 → 客户详情 → 【云店客户】→ 解绑

![云店客户解绑](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/d17aad700348b979181aedd7cd0a3a63.png)

**解绑规则：**

  * 解绑成功后，原微信号变为**游客身份** ，不再关联该客户
  * 微信号与现有云店订单的关联关系**保持不变**
  * 客户后续绑定新手机号时，将自动关联新手机号下的云店订单



**限制条件：**

> 若客户存在**待发货、待收货、部分发货** 状态的在途订单时，**不允许解绑** 。

**重新绑定：** 解绑成功后，点击「尚未成为云店客户」，可分享二维码给客户用新微信扫码绑定。

![解绑后重新绑定](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202604/d30b3004ac8ab93a4802cf86ec6ba8fc.png)
