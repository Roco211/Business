# 账号开单默认信息设置：仓库、收款账户与日期如何带出

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/b3b3948fa9b235a125dbca4729c6b725.png)

1、首先登录需要带出默认信息的账号，点击设置- -用户偏好设置

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/e7e6b1f1c76679a9773fa1114a3d42d7.png)

2、勾选支持默认仓库配置，选择带出仓库。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202507/cb8b80ef2e08b6af2e4bd93f8ddbd100.png)

3、默认收款账户、日期同理。
