# 商品成本是怎么核算的？

官方页面: https://www.zhihuiji.cn/help/doc/927

商品成本采用“结余成本加权平均法”进行核算，当前影响成本的有：

（1）**初始成本**

（2）**进货单** 与 **进货退货单**

## **核心计算逻辑：**

系统会根据库存变动，动态计算商品的结余成本总额和平均成本价

**成本计算公式（商品新增）：（上一次成本总额** +**本次成本总额）/结余数量**

**成本计算公式（商品减少）：（上一次成本总额** -**本次成本总额）/结余数量**

## **计算实例说明：**

A货品第一次进货10件，单价10元，金额100元；

A货品第二次进货10件，单价8元，金额80元。

此时， 库存显示如下： A货品数量20件（10+10），金额180元（100+80），

则 **商品成本：9元=（100+80）/（10+10）**
