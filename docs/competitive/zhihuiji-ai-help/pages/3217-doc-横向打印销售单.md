# 横向打印销售单

官方页面: https://www.zhihuiji.cn/help/doc/3217

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202509/1a073a42e3396604957f6cb30a77f629.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202509/3469e41ab7ea8b82c7413a045610f5eb.png)

受打印机进纸限制，横向打印操作步骤如下：

1、进入打印模板编辑界面，先将【纸张类型】选择**A4**

3、旁边的【宽高】栏，手动输入**实际纸张尺寸**

3、在【打印设置-打印方向】中，勾选“**横向** ”
