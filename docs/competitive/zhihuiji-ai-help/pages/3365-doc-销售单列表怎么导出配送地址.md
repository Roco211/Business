# 销售单列表怎么导出配送地址

官方页面: https://www.zhihuiji.cn/help/doc/3365

**使用场景：** 需要导出销售单列表，根据销售单列表里面的配送地址来送货

**操作步骤：**

1、客户详情添加好收货信息

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/6b925114d89e4f868cc1f6ec9a173887.png)

2、新增销售单勾选配送信息，选择司机送货

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/12bd4a30bc5ad21020404a41e32b46c2.png)

3、设置好以上两步（缺一不可）导出销售单列表就会显示配送地址了

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/af33afdedc22cf65011219fd6548f8ce.png)
