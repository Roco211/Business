# 套餐的销售利润不对

官方页面: https://www.zhihuiji.cn/help/doc/3006

智慧记AI进销存套餐的销售利润不对，检查商品销售额和成本。

**1、套餐内，商品销售额计算公式：** 仅跟单据价格和商品零售价有关，无需理会其他价格等级。

  * **套餐商品占比** =（商品零售价×组成数量）÷组成合计
  * **商品销售额** = 单据价格×商品占比×销售数量



![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202505/a6cec7f8baed9712d6c03a2132694cbe.png)

**2、开单后，商品零售价发生调整变化：** 需重新保存单据更新销售额，系统将按商品当前零售价自动重算报表销售额。

  * 步骤1、商品列表，检查零售价和批发价；
  * 步骤2、销售单列表，找到问题单据，点击修改后直接保存即可，无需任何其他操作。



**3、智慧记AI进销存利润成本规则：** 利润是等于销售价减去成本，成本不是“先进先出”，而是按照加权平均计算的。

  * 默认取上次进货的结余成本，无进货则取商品初始成本价；
  * 检查进货单和初始成本价。
