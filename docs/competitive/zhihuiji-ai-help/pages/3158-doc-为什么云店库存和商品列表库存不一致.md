# 为什么云店库存和商品列表库存不一致

官方页面: https://www.zhihuiji.cn/help/doc/3158

**问题：云店库存和商品列表库存不一致是什么原因呢？（如下图所示）**

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202508/d29abcaec79eee28f9dd92b3a2dbb3a7.png)

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202508/551ac3f6dd6394d53051359a94c17038.png)

**解决方案：云店如果有代发货的订单是会占用云店剩余库存的，需要发货生成销售单才会和商品列表库存一致**
