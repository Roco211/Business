# 批次查询

官方页面: https://www.zhihuiji.cn/help/doc/2205

**操作路径：** 【库存】-【批次查询】

选择批次编号，选择对应的商品名称，仓库，供应商，品牌，重量，点击右侧的”查询“按钮即可查询到对应的商品批次。

举例：

相同一包零食，包装升级换代了，但是价格不变；001编号代表的是旧款，002编号代表的是新款；可得知各自的库存。

可用在手机数码、服装等多个行业，不同批次的产品可能某些方面的参数或者质量有不同的地方，有了批次管理可以更加精准管理货品。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/65e732e5a12e686a12895eba063d40bb.png)

**注意：需要在新增商品时候，勾选了启用批次管理，然后在进货时，输入商品的批次，才能在这里查询到信息。**
