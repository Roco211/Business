# 云店下单库存锁定介绍

官方页面: https://www.zhihuiji.cn/help/doc/2839

**更新云店下单库存锁定之前：**

比如货品01库存是10个，如果不发货的话，货品01的下单数量可以下超过10个，这样导致超过10个后的订单无法发货的。只能有一个人盯着后台，来一个订单里面进货接单发货的操作，这样就比较麻烦。

**增加了库存锁定功能之后，为了避免超卖：**

1、小程序的商品库存对应进行扣减（例如系统库存100个，小程序下单40个，则剩余库存显示60个） 2、销售开单，超出可卖库存后进行提示

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202410/7226e08a0173490cdda0fe6c58e455ed.png)

小程序若不想校验库存，关闭系统设置的“允许负库存”即可
