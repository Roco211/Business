# 商品条码添加

官方页面: https://www.zhihuiji.cn/help/doc/902

## 功能简介

添加商品条码时，智慧记AI进销存提供了以下方式：

• 新增/修改单个商品时，扫码填充、手动输入或自动生成商品条码

• 批量导入新增商品时导入商品条码

• 批量生成商品条形码

## 业务场景

扫码入库或者销售时，需要用到商品条码。

## 操作流程

### 添加单个商品条码

**路径：** 【商品】-【商品】- 新增/修改商品，支持：

  * 扫码自动识别条形码

  * 手动输入条形码

  * 点击自动生成条形码




![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/180a0330f3975edd2c7b8cafb2a1a146.png)

### 导入新增商品时导入商品条码

路径：【商品】-【商品】-【导入新增】 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/75046d2f14314d40c9197531e3eea71d.png)

在表格内填写要导入新增的商品信息和条形码 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202511/c1aa6ef92226eb7f4bbc2044358189c9.png)

### 批量生成商品条形码

路径：【商品】-【商品】-【批量操作】，勾选或筛选商品后，点击【生成条形码】

更多详情点此查看[批量操作生成商品条码](https://www.zhihuiji.cn/help/doc/909)
