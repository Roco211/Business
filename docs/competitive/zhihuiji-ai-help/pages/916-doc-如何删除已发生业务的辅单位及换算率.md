# 如何删除已发生业务的辅单位及换算率

官方页面: https://www.zhihuiji.cn/help/doc/916

**Q：** 货品的规格变了，辅助单位不能修改吗？货品换算率（辅/主）设置错了怎么没法改了？为什么字体是灰色，点击没有作用？如何删除辅单位？

答：重点是要解决以前的单据问题，必须全部单据的辅单位都改掉才可以。导出所有单据->>筛选出用辅单位的单据->>全部修改成主单位。

  * （1）对于软件而言，只是一个替换文本的关系。比如1小支油10元，跟1小瓶油10元一样。“整箱”也是同理；

  * （2）但是对您的实际业务需求而言，“1整箱油10元”显然就不对了；

  * （3）修改操作：以前的单据必须手动一张一张修改，先把全部辅单位都改成旧主单位。比如进货单进货1整箱（12小瓶）花生油100元，则要手动把单据里的“箱”改成“小瓶“，数量改成对应的”10“小瓶花生油，但仍保持原单据价格100元；

  * 辅单位没有关联的单据，就可以删除或修改辅单位和换算率了。




**Q：** 修改单据辅单位太麻烦了，如何解决？

答：如果确认以后都用新单位，建议要不重新新增一个货品名称，旧货品的就留着查看不用了。
