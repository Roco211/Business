# 库存查询教程

官方页面: https://www.zhihuiji.cn/help/doc/1898

路径：库存-库存查询

  * 可以隐藏停用商品，隐藏无库存商品。
  * 可以选择仓库，商品类别，供应商，品牌，重量查询，或者输入商品名称/条形码/货号查询。



库存查询可以显示全部商品的总数量和总金额。

![库存查询](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/86c9f704f26975a3e73c4c6d14fc643d.png)

点击库存分布，可以查询到这个商品每个仓库/门店的库存数量。

![库存分布](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/0e7eed2f57f4f1ab9677a06ccba39386.png)

如果需要导出库存数量可以点击导出按钮导出后然后下载即可。

![导出](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/6c5db8d213560ad13612ad6d5cdd1dd2.png)
