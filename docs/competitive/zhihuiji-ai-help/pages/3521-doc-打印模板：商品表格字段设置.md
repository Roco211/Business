# 打印模板：商品表格字段设置

官方页面: https://www.zhihuiji.cn/help/doc/3521

视频描述  **路径：** 【设置】→【打印设置】→ 编辑打印模板

点击表格区域，在右侧**勾选** 需要打印的字段，拖拽可调整排序。
