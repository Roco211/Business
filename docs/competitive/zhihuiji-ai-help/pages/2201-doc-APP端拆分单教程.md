# APP端拆分单教程

官方页面: https://www.zhihuiji.cn/help/doc/2201

## 拆分单

### 新增拆分单

路径：点击右下角【更多】-【库存】-【组装拆分】-顶部【拆】-右下角【拆分】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/958c9090050bfb94fb3592df3498551f.png)

（1）选择拆分件商品，只能选择一件。

（2）选择子件商品，可以选择多件。

（3）输入拆分费用。

（4）保存。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/c97b2a8ff51e94b8845efebf00207b6e.png)

保存成功界面可与点击再来一单，或者查看单据详情。点击完成即可关闭该页面。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/9216c9faa5b295fdad82b57c117ce63d.png)

**注意：**

（1）做完拆分单后，拆分件数量会减少，子件数量会增加。

（2）子件成本金额合计=拆分件金额+拆分费。

（3）子件成本分摊规则：将差额按照子件金额占当前合计金额的比例分摊累加到子件金额中，然后反算子件单位成本。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/2c6b9ab657210cba16d36534f9ff0b38.png)

### 拆分单详情

（1）点击右上角的三点，可以作废组装单。

（2）点击底部的修改按钮可以修改单据。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/0418ebc75c0a272cde117dd3c71573ab.png)

### 拆分单列表

（1）可以输入单号/组合件名称/备注查询

（2）点击筛选，可以选择日期，组装员，是否显示作废单据查询。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/ff292b5ef596e9a2f6f3258032cfb95a.png)

## 配方

### 新增配方

路径：点击左侧导航【库存】-右下角【组装拆分】-右上角【配方】-右上角【+】

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/17467e6773fc510f420242f90636cf74.png)

（1）选择组合件商品

（2）选择子件商品

（3）保存

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/547fa114ff0f69c57ddad7adbbf90344.png)

或者在新增组装单和拆分单时候可以勾选保存成配方

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/813066ea3344a45196fc15b01cfe1b11.png)

### 配方列表

（1）可以输入组合件名称/货号/条形码查询配方。

（2）点击配方后面的三点，就可以选择编辑或者删除配方。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/5aa38d3b314a0324b0194b9583877be9.png)

### 使用配方

（1）新增拆分单，右上角选择配方。

（2）更改组合件商品数量，子件数量等比例变化。

（3）修改/删除子件商品数量，配方关联关系会消失，再去改组合件商品数量，子件商品数量不会等比例变化。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202309/b2a878024bdf0e59fe5b4ee4a342aba6.png)
