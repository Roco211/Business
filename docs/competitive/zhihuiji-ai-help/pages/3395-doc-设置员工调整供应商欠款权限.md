# 设置员工调整供应商欠款权限

官方页面: https://www.zhihuiji.cn/help/doc/3395

如需限制员工调整供应商欠款的权限，可通过角色权限设置进行管理。

**操作路径：** 【设置】→【角色权限】→ 修改对应角色 → 取消勾选「进货」-「供应商」-「调整欠款」→【保存】
