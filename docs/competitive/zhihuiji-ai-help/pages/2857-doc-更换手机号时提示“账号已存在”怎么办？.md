# 更换手机号时提示“账号已存在”怎么办？

官方页面: https://www.zhihuiji.cn/help/doc/2857

**适用场景** ：当老板或营业员更换绑定手机号时，系统提示“该账号已存在”。

**解决步骤** ：请按照以下流程操作：

  1. **下载并登录** ：在手机上打开**智慧记AI进销存** App，使用**需要被绑定的新手机号** 登录。



⚠️**重要提示** ：此步骤是登录**那个提示“已存在”的新号码账号** ，而非您当前正在使用的老账号。

  2. **账号注销** ：【我的】→【个人信息】→【账号注销】，仔细阅读提示后确定注销。



🚨**风险警告** ：账号注销是不可逆的。一旦注销，该账号下的所有数据（包括但不限于单据记录、客户信息等）将**永久清空且无法恢复** ，请务必谨慎操作。 ![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202601/f3c3c7573f5f03bcd52953fd38526cbf.png)

  3. **返回更换** ：成功注销新号码账号后，请返回您最初需要操作的设备（老板或营业员的老账号），重新进行更换手机号的操作即可。



**核心建议**

  * **优先选择未注册号码** ：在更换手机号时，尽量直接使用一个全新的、未在智慧记AI进销存注册过的手机号，可避免此问题。
  * **评估账号价值** ：在注销前，请务必确认该手机号对应的账号内**是否开通了会员** 。**强烈建议不要注销含有会员权益的账号** ，以免造成财产损失。
  * **确认操作对象** ：操作全程请清晰区分**当前老账号** 和**待注销的新号码账号** ，切勿误登录、误注销。
