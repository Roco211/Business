# 开启进货单单行折扣教程

官方页面: https://www.zhihuiji.cn/help/doc/2222

视频描述  **操作路径：**

（1）设置-系统设置-勾选启用单行折扣。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/0866f213d69ca718e78fdb8c27a237ed.png)

（2）进货-新增进货单-点击左侧设置按钮，把折扣，折后价添加到已显示字段里，然后点击确认。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/4dfebb2812e0e2883b5c24043f3b4507.png)

（3）开进货单即可输入单个商品的折扣率。

![Description](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202311/533829751e744d29d2274363674f679e.png)
