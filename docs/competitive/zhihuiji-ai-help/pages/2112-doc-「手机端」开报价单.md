# 「手机端」开报价单

官方页面: https://www.zhihuiji.cn/help/doc/2112

**操作路径：** 【更多】→ 【报价】→ 右下角【报价】→ 选择客户与商品 →【保存】

![开报价单流程](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/57961244653c6d6aae54972afc63fa7f.png)

**保存后支持操作：**

  * **再来一单** ：继续开报价单
  * **转销售** ：直接转为正式销售单
  * **打印/分享** ：打印单据或分享给客户
  * **查看详情** ：进入详情页进行修改、作废等操作



![报价单详情](https://ks3-cn-beijing.ksyun.com/zhjwebsite/uploads/202512/ebdf4d2a85a442d8d893c0532c6e6220.png)

**💡 温馨提示：**

报价单仅用于记录报价信息，不影响商品库存。
